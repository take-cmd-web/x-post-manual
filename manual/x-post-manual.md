# X投稿マニュアル

てっぺい氏のX運用は、フォロワー13万人という実績に裏打ちされた再現性の高い戦略に基づいています。特に「図解ポスト」と「AI活用」を軸に、時流に合わせた投稿形式の最適化を追求している点が特徴です。以下に、てっぺい氏のメルマガ群を横断分析し、再現性のあるX投稿マニュアルをまとめました。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びるネタには明確な共通点があります。フォロワーを増やすためには、単なる興味関心だけでなく、読者の「知りたい」という欲求に応える「有益性」が重要です。

### 1-1. 読者の「知りたい」欲求を刺激するテーマ
*   **「なんとなく聞いたことあるけど、よくわからない」を優しく解説する**
    *   多くの人が耳にしたことはあるが、内容が複雑で理解しづらいテーマは、分かりやすく解説することで高い需要を生みます。
    *   **実例:**
        *   **エプスタイン事件:** 「なんとなく聞いたことあるけどよくわからない」というテーマで、**1ポストで1652名**のフォロワー増（メルマガ4, 32）。「闇が深い」陰謀論的要素も加えることで興味を引きました。
        *   **選挙の「青木率」:** 「とっつきづらいけど、ちょっと知っておいた方がいいよな」という政治系の解説で、**234万インプレッション、1581名**のフォロワー増（メルマガ1）。
        *   **「残クレ」アルファード:** 「よく聞くけどよくわからない、ちょっと気になること」をテーマにし、**65万インプレッション、532名**のフォロワー増（メルマガ30）。
        *   **UAEのOPEC脱退:** 「聞いたことある」「大切そう」「でも、よくわからない」を満たし、**60万インプレッション、2010名**のフォロワー増（メルマガ12）。
        *   **韓国大統領の逮捕理由:** 「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問をトレンドに乗せて発信し、**78万インプレッション、447名**のフォロワー増（メルマガ27）。

*   **トレンド・時事ネタを迅速に解説する**
    *   Xは流動性の高いメディアであり、タイムリーな情報が特に注目を集めます。ニュース解説はフォロワー増に直結しやすい傾向があります。
    *   **実例:**
        *   **海外メディアのイラン攻撃報道:** ポッドキャストからの一次情報とトレンドを組み合わせ、**184万インプレッション、2951名**のフォロワー増（メルマガ26）。てっぺい氏の過去最高記録です。
        *   **ナフサ不足とポテトチップスの白黒袋:** トレンドワードに「インパクトの強さ」を組み合わせ、**182万インプレッション、603名**のフォロワー増（メルマガ10）。
        *   **マイナンバーカードの名前とデザイン変更:** タイムリーな話題で、初回投稿時に**655万インプレッション、1114名**のフォロワー増（メルマガ36）。

*   **「東スポ」要素を取り入れる**
    *   インプレッションを最大化するためには、日経新聞のような堅い情報だけでなく、ゴシップや下世話な話題も有効です。
    *   **実例:**
        *   **女子アナフリー転向年収ランキング:** 「女子アナ」「フリー転向」「年収」という下世話なネタを盛り込み、**92万インプレッション**を記録（メルマガ18）。ただし、発信軸とのズレからフォロワーは30名減となりました。

*   **一次情報や自身の経験・学びを発信する**
    *   自身の体験や学びを元にした情報は、独自性があり、読者に共感を呼びやすいです。
    *   **実例:**
        *   **GW明けのホテルが空く時期:** 自身のホテル勤務経験から得た「本業のちょっとした知識」を発信し、**60万インプレッション、8513いいね、206名**のフォロワー増（メルマガ9）。
        *   **為替介入の解説:** 自身が「はっきりわかってなかった」ことを調べて発信。インプレッションは7万と伸び悩んだものの、「わかりやすい」と評価され**90名**のフォロワー増に繋がりました（メルマガ11）。

### 1-2. ネタ探しの効率化と具体的な要素
*   **毎朝トレンドワードを確認する**
    *   Xのトレンドから伸びそうなネタを探し、優先的に発信します（メルマガ10）。
*   **AIをリサーチに活用する**
    *   ChatGPT, Gemini, Perplexity, Grok, Claudeなどの複数のAIに質問し、回答を比較・統合することで、リサーチ時間を大幅に短縮し、質の高い情報を効率的に収集します（メルマガ10, 12, 14, 20, 22, 26, 38）。
*   **固有名詞や数字、パワーワードを盛り込む**
    *   具体的な情報やインパクトのある言葉は、読者の目を引きつけ、興味を深めます。
    *   **実例:** 「55億円」「地面師」「Netflix」「2017年」といった要素を盛り込んだ地面師事件のポストは、**368万インプレッション、1425名**のフォロワー増を記録しました（メルマガ38）。
*   **「知ってるものとつなげる」解説**
    *   難しいテーマも、読者がすでに知っている身近な情報と比較したり、関連付けたりすることで、理解しやすくなります。
    *   **実例:** 「残クレアルファード」のポストで、通常のローンとの比較を入れることで、読者が「支払い方法の話ね」と理解しやすくしました（メルマガ30）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

てっぺい氏の投稿は、Xのアルゴリズムとユーザーの行動特性を深く理解した上で、様々な構成や型を試行しています。特に「冒頭文」と「リプへの誘導」が重視されています。

### 2-1. 冒頭文の絶対的優位性
*   **Xは「流し読みされる媒体」であることを意識する**
    *   ユーザーはXを「一生懸命勉強しよう！」と開くのではなく、スキマ時間に「なんとなく見る」人が多いため、冒頭のインパクトが全てです（メルマガ2, 35）。
*   **読み手の興味を引き付ける具体的な言葉を使う**
    *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」など、断言、損失回避、実績提示の言葉で読者の足を止めます（メルマガ2, 35）。
    *   **実例:** 「マイナンバーカード」のポストでは、「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という煽り気味の書き出しで、**595万インプレッション、407名**のフォロワー増に貢献しました（メルマガ36）。

### 2-2. ポスト形式の使い分けとリプへの誘導
*   **「1枚目を文字ポスト、2枚目以降を図解」の型**
    *   最近のアルゴリズムでは、1枚目に図解を置くと伸びづらい傾向があるため、最初のポストは文字で興味を引き、リプ（返信スレッド）に誘導して図解を見てもらう構成が推奨されています（メルマガ3, 8, 14, 39）。
    *   **実例:**
        *   「地面師事件」のポストは、過去に伸びた図解ポストを1枚目文字の会話ポストに変えて再投稿したところ、**204万インプレッション、170名**のフォロワー増を達成しました（メルマガ39）。以前の図解1枚目ポストは15万インプレッション、10名フォロワー減でした。
        *   「妻のパートと社会保険の扶養」のポストでは、1枚目を会話の文字ポスト、2枚目以降を図解にし、**170万インプレッション、307名**のフォロワー増を記録しました（メルマガ7）。
*   **流行りの構文を積極的に活用する**
    *   メダル構文、会話構文、◯×構文、国旗構文、Tier、ランキングなど、流行りの構文はインプレッションを伸ばす強力な手段です。
    *   **実例:**
        *   「個人向け国債 変動10年」のポストで、普段伸びなかった有益な内容を流行りのメダル構文の力を借りて発信したところ、**334万インプレッション、417名**のフォロワー増を達成しました（メルマガ6）。これをてっぺい氏は「ロールキャベツ系ポスト」と呼んでいます。
        *   会話調のポストは、読みやすく、文字を少なめにして気になるところで切ることで、リプへの誘導を最大化します（メルマガ38）。
*   **図解ポストの重要性**
    *   てっぺい氏が13万フォロワーを達成した最大の秘密は「図解ポスト」であり、文字だけのポストでは想像できないほどのインプレッション数とフォロワー増が得られると断言しています（メルマガ5, 37）。
    *   **「Nano Banana Pro」**などのAIツールを活用することで、図解作成のハードルが劇的に下がり、高速で質の高い図解を作成できます（メルマガ1, 5, 12, 16, 21, 26, 30, 32, 37）。
    *   **図解のデザイン:** 「パッと見でなんのポストかわかるようにする」ことが大切です（メルマガ30）。1枚目の図解は特にこだわり、2枚目以降はそこまでこだわらないようにしています（メルマガ38）。
    *   **図解の情報量:** 最初のポストにつける図解の情報量は少なめにして、リプに誘導する構成が良いとされています（メルマガ26）。文字を多く入れすぎると伸び悩む原因になります（メルマガ11）。
*   **マンガポストの活用**
    *   文字ポストでは伸び悩んだネタも、マンガにすることで爆発的に伸びる可能性があります。AIツールを使えば簡単に作成でき、発信の幅が広がります。
    *   **実例:** 娘の実話であるバレンタインのネタは、文字ポストでは7.4万インプレッション、34名フォロワー減でしたが、マンガにすることで**240万インプレッション、586名**のフォロワー増を達成しました（メルマガ29）。
*   **1秒動画の添付**
    *   X社が動画を優遇する傾向があるため、1秒の短い動画を添付することでポストが爆発的に伸びる可能性があります。
    *   **実例:** マイナンバーカードのポストに赤い矢印が点滅する1秒動画を添付し、**595万インプレッション**に貢献しました（メルマガ36）。

### 2-3. 漢字の比率と読みやすさ
*   てっぺい氏のメルマガでは「漢字の比率」について直接的な言及はありませんが、「やさしく解説」「わかりやすく」「読みやすく」という言葉が頻繁に登場します。これは、専門用語を避け、平易な言葉で、視覚的に理解しやすいように工夫していることを示唆しています。特に冒頭文やリプへの誘導を意識したテキストでは、簡潔で分かりやすい表現が重要です。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも連動せず、それぞれ異なる要因で伸びる傾向があります。てっぺい氏は両者を意識して投稿戦略を立てています。

### 3-1. インプレッションを伸ばす投稿の傾向
*   **冒頭文のインパクトと流行りの構文**
    *   「断言します」「これを知らないと大損します」のような強い冒頭文や、メダル構文、会話構文などの流行りの型は、Xの流し読み文化においてユーザーの目を止め、インプレッションを大きく伸ばします（メルマガ2, 6, 35, 36）。
    *   **実例:** 「個人向け国債 変動10年」のポストでメダル構文を活用し、**334万インプレッション**を達成（メルマガ6）。
    *   **実例:** バレンタインのマンガポストは、いつものジャンルと異なるにもかかわらず、**240万インプレッション**を記録（メルマガ29）。
*   **「東スポ」要素や下世話なネタ**
    *   世間の興味を引くゴシップやランキングは、インプレッションを稼ぎやすいです（メルマガ18）。
    *   **実例:** 「女子アナフリー転向年収ランキング」は**92万インプレッション**を記録（メルマガ18）。
*   **1秒動画の活用**
    *   Xのアルゴリズムが動画を優遇するため、短い動画を添付することでインプレッションが爆発的に伸びる可能性があります（メルマガ36）。
    *   **実例:** マイナンバーカードのポストに1秒動画を添付し、**595万インプレッション**を達成（メルマガ36）。
*   **リプへの誘導を意識した構成**
    *   ポストを簡潔にし、続きをリプに誘導する構成は、ユーザーの滞在時間を延ばし、アルゴリズムに評価されやすいため、インプレッションが伸びます（メルマガ7, 14, 26）。

### 3-2. フォロワー増につながる投稿の傾向
*   **「有益性」と「分かりやすさ」**
    *   「とっつきづらいけど、ちょっと知っておいた方がいいよな」というテーマを「やさしく解説」する投稿は、読者の学習欲求を満たし、フォローに繋がりやすいです（メルマガ1, 23）。図解ポストは、この「分かりやすさ」を最大化する手段です（メルマガ5, 37）。
    *   **実例:** 「海外メディアの立ち位置」の解説で、**184万インプレッション、2951名**のフォロワー増を記録（メルマガ26）。
    *   **実例:** 「エプスタイン事件」の解説で、**1652名**のフォロワー増（メルマガ4, 32）。
    *   **実例:** 「UAEのOPEC脱退」の解説で、**2010名**のフォロワー増（メルマガ12）。
*   **トレンドに乗ったニュース解説**
    *   時事性の高いニュースを分かりやすく解説する投稿は、情報収集目的のユーザーに刺さり、フォロワー増に直結しやすいです（メルマガ8, 10, 23）。特に海外のニュースが伸びる傾向があります（メルマガ8）。
    *   **実例:** てっぺい氏が1000名以上フォロワーが増えた5本のポストは全て「トレンドに乗ったニュース解説」でした（メルマガ8）。
*   **発信軸との一貫性**
    *   インプレッションは伸びても、発信軸から大きくズレた投稿はフォロワー増に繋がりにくく、むしろフォロワー減に繋がる可能性があります（メルマガ1, 17, 18）。
    *   **実例:** 「女子アナフリー転向年収ランキング」は**92万インプレッション**を記録しましたが、発信軸とのギャップからフォロワーは**30名減**となりました（メルマガ18）。
    *   **実例:** 「お金・お得情報」でも「ニュース解説」でもない投稿で**113万インプレッション**を記録したものの、フォロワーは**69名減**となりました（メルマガ17）。
*   **図解ポストの活用**
    *   てっぺい氏の経験上、図解を使った方がフォローされる数が多い印象があるとのことです（メルマガ8）。Nano Banana Proなどのツールで作成した図解は、視覚的な分かりやすさでフォロワー獲得に貢献します。

### 3-3. インプレッションは伸びたがフォロワーは減った事例からの示唆
*   **発信軸とのズレはフォロワー減に直結する**
    *   インプレッションを稼ぐための「東スポ」要素や、普段の発信軸と異なるテーマは、一時的に注目を集めても、アカウントの専門性や期待値と合致しないため、フォローに繋がらず、既存フォロワーの離脱を招くことがあります（メルマガ17, 18）。
    *   **実例:** 「女子アナフリー転向年収ランキング」は92万インプレッションを記録したが、フォロワーは30名減（メルマガ18）。
    *   **実例:** 「お金・お得情報」でも「ニュース解説」でもない投稿で113万インプレッションを記録したが、フォロワーは69名減（メルマガ17）。
*   **内容の質や深さの不足**
    *   AIにネタ出しを依頼したポストで24万インプレッションを記録しながら、フォロワーが10名減となった事例があります（メルマガ13）。これは、表面的な情報や、読者の期待に応えられない内容だった場合に発生します。
    *   **実例:** 「投資用語解説」で「用語が簡単すぎた」「用語が少なすぎた」と反省しており、次回はより専門的で数の多い用語で図解を作成する予定です（メルマガ34）。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

てっぺい氏の経験から導き出される成功と失敗の原則は、X運用において非常に重要です。

### 4-1. 刺さった理由（成功要因）
1.  **「知りたいけど難しい」を「分かりやすく」解説**
    *   多くの人が関心はあるものの、自分では調べるのが億劫なテーマを、図解や平易な言葉で丁寧に解説することで、高い価値を提供します（メルマガ1, 4, 12, 23, 30, 33）。
    *   **実例:** 「青木率」や「エプスタイン事件」の解説がフォロワー増に貢献（メルマガ1, 4）。
2.  **トレンド・時事ネタへの迅速な対応**
    *   Xの特性を活かし、話題のニュースや出来事をいち早く解説することで、情報の鮮度と需要を捉えます（メルマガ8, 10, 26, 32）。
    *   **実例:** 「海外メディアのイラン攻撃報道」や「ナフサ不足」の解説がバズり、フォロワーを大幅に増やしました（メルマガ10, 26）。
3.  **冒頭文による強力なフック**
    *   「断言します」「これを知らないと大損します」といった煽り気味の言葉や、具体的な数字、固有名詞、パワーワードを冒頭に配置し、流し読みされる中で読者の目を止めます（メルマガ2, 35, 36, 38）。
    *   **実例:** 「マイナンバーカード」のポストの煽り文言（メルマガ36）や、「地面師事件」の「55億円」「Netflix」といったパワーワード（メルマガ38）。
4.  **図解による視覚的な分かりやすさ**
    *   複雑な情報も図解にすることで、直感的に理解しやすくなり、高いエンゲージメントとフォロワー獲得に繋がります（メルマガ5, 16, 30, 37）。特に「パッと見で何かわかる」デザインが重要です（メルマガ30）。
    *   **実例:** 以前文字で伸びなかった「保険は最低限でいい」という内容を図解にしたら伸びた（メルマガ16）。
5.  **リプへの誘導を意識した構成**
    *   最初のポストで全てを語らず、興味を引く内容で区切り、リプに誘導することで、ユーザーの滞在時間を延ばし、アルゴリズムに評価されやすくします（メルマガ3, 7, 14, 26, 38, 39）。
6.  **多様な表現形式の活用（マンガ、会話ポスト、1秒動画）**
    *   同じ内容でも見せ方を変えることで、飽きさせずに新しい反応を引き出します。マンガや会話ポスト、1秒動画など、Xのアルゴリズムが優遇する形式を積極的に取り入れます（メルマガ6, 7, 29, 36）。
    *   **実例:** 文字ポストでは伸びなかったバレンタインのネタをマンガにしたら爆伸び（メルマガ29）。
7.  **「知ってるものとつなげる」解説**
    *   読者にとって馴染みのない概念も、既知の事柄と比較したり関連付けたりすることで、理解のハードルを下げます（メルマガ30）。
    *   **実例:** 「残クレ」を通常のローンと比較して解説（メルマガ30）。
8.  **発信者自身の「楽しむ」姿勢**
    *   自分が「そうなんだ」「学んだこと」を楽しく発信することは、長く続けるコツであり、結果的に質の高い投稿に繋がります（メルマガ1, 11, 22, 23, 29）。

### 4-2. 刺さらなかった理由（失敗・反省点）
1.  **発信軸からの過度なズレ**
    *   インプレッションは伸びても、普段の発信軸と大きく異なるテーマは、フォロワーの期待と合致せず、フォローに繋がりにくく、むしろフォロワー減を招きます（メルマガ1, 17, 18）。
    *   **実例:** 「女子アナフリー転向年収ランキング」は92万インプレッションを記録したが、フォロワーは30名減（メルマガ18）。
2.  **1枚目の図解に情報量が多すぎる**
    *   最初の図解に文字を詰め込みすぎると、リプへの誘導が阻害され、インプレッションが伸び悩む原因になります（メルマガ11）。
    *   **実例:** 「為替介入」のポストで1枚目の図解に文字を多く入れすぎたことを反省点として挙げています（メルマガ11）。
3.  **「自分とは関係なさそう」なテーマ**
    *   読者にとって身近に感じられないテーマは、たとえ有益な情報であっても、興味を持たれにくく、伸び悩む可能性があります（メルマガ11）。
    *   **実例:** 「為替介入」というテーマが読者にとって遠いと感じられたため、インプレッションが伸び悩んだ（メルマガ11）。
4.  **図解を最初のポストに置くことのアルゴリズム的な不利**
    *   最近のXアルゴリズムでは、1枚目に図解を置くよりも、文字ポストでリプに誘導する方が伸びやすい傾向があります（メルマガ3, 8, 39）。
    *   **実例:** 過去に伸びた図解ポストをそのまま再投稿したらフォロワーが減ったが、1枚目を文字ポストに変えて再投稿したら伸びた（メルマガ39）。
5.  **内容の深さや具体性の不足**
    *   簡単な用語ばかり、または用語の数が少ない図解は、読者の知的好奇心を満たせず、フォローに繋がりにくい可能性があります（メルマガ34）。
    *   **実例:** 「投資用語解説」で用語が簡単すぎた、少なすぎたことを反省（メルマガ34）。

## 5. 投稿前チェックリスト（具体的な確認項目）

てっぺい氏の成功事例と反省点を踏まえ、投稿前に確認すべき項目をまとめました。

### 5-1. ネタ・テーマに関するチェック
*   [ ] **「なんとなく聞いたことあるけど、よくわからない」**テーマか？（例: エプスタイン事件、残クレアルファード）
*   [ ] **トレンドや時事ネタ**に乗っているか？（例: 海外メディアの報道、ナフサ不足、マイナンバーカード変更）
*   [ ] 読者にとって**「とっつきづらいけど、知っておいた方がいい」**情報か？（例: 青木率、中東情勢）
*   [ ] 自身の**一次情報や経験・学び**が含まれているか？（例: ホテル勤務経験、為替介入を自分で調べた経験）
*   [ ] **固有名詞、具体的な数字、パワーワード**を効果的に盛り込んでいるか？（例: 「55億円」「Netflix」「2017年」）
*   [ ] **「東スポ」要素**（下世話な話題、ランキングなど）を取り入れることで、インプレッションを最大化できるか？（フォロワー増とのバランスを考慮）
*   [ ] 読者が**「知ってるものとつなげる」**形で解説できているか？（例: 残クレと通常のローンの比較）
*   [ ] **発信軸と大きくズレていないか？**（フォロワー増を狙う場合、特に重要）
*   [ ] 過去に伸びたポストの**再利用**を検討したか？（見せ方を変えるなど）
*   [ ] **AI（ChatGPT, Gemini等）**でリサーチやネタ出しの候補を効率的に収集したか？

### 5-2. 投稿の構成・型に関するチェック
*   [ ] **冒頭文はインパクトがあるか？** 読者の指を止められるか？
    *   [ ] 「断言します」「これを知らないと大損します」「私コレで月10万円得しました」などの**強い言葉**を使っているか？
    *   [ ] 煽り気味の言葉で興味を引きつけているか？（例: 「知らない人が多すぎる」）
*   [ ] **1枚目のポストは文字（会話構文、メダル構文など）**で、リプに誘導する構成か？（図解を1枚目に置くと伸びづらい傾向を考慮）
    *   [ ] 会話ポストの場合、極力シンプルに、気になるところで切ってリプへ誘導しているか？
*   [ ] **図解ポスト**を活用しているか？（特に複雑な内容や分かりやすさを重視する場合）
    *   [ ] 図解は**「パッと見で何かわかる」**デザインになっているか？（例: アルファードのイラスト）
    *   [ ] 1枚目の図解は特にこだわり、情報量を詰め込みすぎていないか？（リプへの誘導を妨げないか）
    *   [ ] **Nano Banana Pro**などのAIツールで効率的に作成したか？
*   [ ] **マンガポスト**の形式で、文字では伝わりにくいストーリー性や感情を表現できないか？
*   [ ] X社が優遇する**1秒動画**を添付しているか？
*   [ ] **漢字の比率**は適切か？（「やさしく」「わかりやすく」を意識し、平易な言葉で読みやすくしているか）

### 5-3. 投稿後の運用に関するチェック
*   [ ] 投稿後30分～60分は、**リプへの返信**をできるだけ早く、多く行う準備はできているか？（アルゴリズムで交流が重視されるため）
*   [ ] Xで伸びた図解ポストを、**インスタグラム、スレッズ、TikTok、YouTubeショート**など他のSNSにも流用する計画があるか？（特にインスタは動画形式に変換することで爆伸びの可能性）
*   [ ] 投稿作成プロセス自体を**楽しめているか？**（長く続けるためのモチベーション維持）
*   [ ] ポストの伸びが悪い場合でも、**焦らず**、長距離走として継続する心構えがあるか？
