# X投稿マニュアル

X(旧Twitter)運用専門家「てっぺい」氏のメルマガ群を横断分析し、再現性のあるX投稿マニュアルを作成しました。てっぺい氏の13万フォロワー達成の秘訣は、AIツールを駆使した図解ポストと、アルゴリズムの変化に合わせた柔軟な投稿戦略にあります。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏が最も重要視するのは「ネタ」の選定です。流行りの構文や図解の型よりも、ネタの質がポストの伸びを左右すると繰り返し述べています（メルマガ49, 60, 61）。

### 伸びやすいネタの共通法則
1.  **「聞いたことあるけどよくわからない」テーマ**
    *   多くの人が関心を持ちつつも、詳しく調べるのが面倒だと感じるテーマは、わかりやすく解説することで高いエンゲージメントを得られます。
    *   **実例:**
        *   「選挙の『青木率』」（メルマガ1: 234万インプレッション、1581名増）
        *   「闇が深いエプスタイン事件」（メルマガ4, 32, 33: 144万/110万インプレッション、1652名増）
        *   「ナフサ不足とポテトチップスの白黒袋」（メルマガ10: 182万インプレッション、603名増）
        *   「残クレアルファード」（メルマガ30: 65万インプレッション、532名増）
        *   「韓国大統領が逮捕される謎」（メルマガ27: 78万インプレッション、447名増）
        *   「インドカレー屋さんがガラガラな秘密」（メルマガ41: 317万インプレッション、492名増）
        *   「為替介入」（メルマガ11: 7万インプレッション、90名増）
    *   てっぺい氏自身も「為替介入がなんとなくしかわかってなかった」ため、調べて発信したところ、インプレッションは伸びなかったものの「わかりやすい」と評価されフォローにつながりました（メルマガ11）。

2.  **「自分ごと」になりやすいテーマ（対象者が広い）**
    *   読者自身やその身近な人に関わるテーマは、高い共感や関心を引き出し、拡散されやすくなります。特に「都道府県別」のデータは効果的です。
    *   **実例:**
        *   「高校受験の名門高校」（メルマガ44: 44,654名増）
        *   「都道府県知事の年収」（メルマガ50: 550万インプレッション、16,940名増）
        *   「全国アウトレットの売上・店舗数」（メルマガ51: 123万インプレッション、5099名増）
        *   「都道府県知事の出身大学」（メルマガ63: 422万インプレッション、11,514名増）
        *   「東大合格高校ランキング」（メルマガ64: 163万インプレッション、7127名増）
        *   「都道府県別ショッピングセンター」（メルマガ57: 194万インプレッション、7428名増）
        *   「世界の血液型分布」（メルマガ59: 114万インプレッション、909名増）
    *   「全員が必ずどこかに属する」血液型や星座のポストは「自分ごと」になりやすいと分析しています（メルマガ59）。

3.  **「下世話」な要素や「意外性」のある情報**
    *   人々の好奇心を刺激する「年収」や「事件の闇」といった要素、あるいは常識を覆すような意外な事実は、インプレッションとフォロワー増の両方に貢献します。
    *   **実例:**
        *   「闇が深いエプスタイン事件」（メルマガ4, 32, 33: 1652名増）
        *   「女子アナのフリー転向年収ランキング」（メルマガ18: 92万インプレッション、30名減）
        *   「都道府県知事の年収」（メルマガ50: 550万インプレッション、16,940名増）
        *   「新内閣の大臣の年収・資産額」（メルマガ52: 141万インプレッション、7805名増）
        *   「東大が世界ランキング27位という意外性」（メルマガ55: 124万インプレッション、3728名増）
    *   てっぺい氏は「Xでインプレッションを取るには、基本的には日経新聞に載ってるようなことより東スポに載ってることの方がいい」と述べています（メルマガ18）。

4.  **「トレンド」に乗った時事ネタ・ニュース解説**
    *   XのトレンドワードやYahoo!ニュースから最新の話題をキャッチし、それを分かりやすく解説することで、多くの人にリーチできます。特に海外のニュースはフォロワー増につながりやすい傾向があります。
    *   **実例:**
        *   「国会の冒頭解散と選挙の『青木率』」（メルマガ1: 234万インプレッション、1581名増）
        *   「エプスタイン事件の新たなファイル公開」（メルマガ4, 32, 33: 1652名増）
        *   「海外メディアのイラン攻撃報道」（メルマガ8: 2951名増）
        *   「UAEのOPEC脱退」（メルマガ8, 12: 3067名増、2010名増）
        *   「ナフサ不足」（メルマガ10: 182万インプレッション、603名増）
        *   「中東情勢の解説」（メルマガ23: 58万インプレッション、1075名増）
        *   「韓国大統領の厳しい判決」（メルマガ27: 78万インプレッション、447名増）
    *   「1ポストで1000名以上の方にフォローいただいたポストはすべてトレンドに乗ったもの」と分析しています（メルマガ10）。

5.  **「一次情報」や「自分の経験」に基づく情報**
    *   自身が体験したり、本業で得た知識は、他にはない独自性があり、読者に価値を提供できます。
    *   **実例:**
        *   「ホテルが一番空く時期」（メルマガ9: 60万インプレッション、206名増）
        *   「自分が為替介入を調べて分かったこと」（メルマガ11: 7万インプレッション、90名増）
        *   「社会保険の扶養について妻に伝えたこと」（メルマガ7: 170万インプレッション、307名増）
        *   「個人向け国債 変動10年」（メルマガ6: 334万インプレッション、417名増）
    *   「自分で学んだことを発信するというのは、発信が楽しくなっていい」（メルマガ11）と、楽しんで継続することの重要性も強調しています。

### ネタ探しの具体的な方法
*   **Xのトレンドワード、Yahoo!ニュース:** 最新の時事ネタや話題のキーワードをチェック（メルマガ49）。
*   **ポッドキャストの経済ニュース、Googleのレコメンドニュース:** トレンドと関係ないが興味深いネタを発見（メルマガ49）。
*   **AIの活用（リサーチ段階）:** ChatGPT, Gemini, Perplexity, Grok, Claudeなどを使い、ネタの深掘りや情報収集を効率化（メルマガ10, 12, 14, 20, 22, 38, 51, 55）。
    *   特にニュース系はGeminiが良いと評価（メルマガ55）。
    *   AIにネタ出しをさせる試みも行っていますが、まだ検証段階で「いいかも」と思うのは一部でした（メルマガ13）。
*   **日常会話やYouTube、自身の疑問から:** 普段の生活の中で「へー」と思ったことや疑問に感じたことをメモする（メルマガ38, 51）。
*   **再利用:** 過去に伸びたポストのネタは、見せ方を変えて何度も再投稿する（メルマガ36, 39）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xのアルゴリズムは常に変化しており、てっぺい氏はそれに合わせて投稿の「見せ方」を柔軟に変えています（メルマガ40, 41）。

### 冒頭文の作り方：インパクト勝負
Xは「流し読みされる媒体」であるため、冒頭文で読者の興味を引きつけることが最重要です（メルマガ2, 35）。
*   **断言、煽り、具体的な数値で引きつける:**
    *   「断言します」
    *   「これを知らないと大損します」
    *   「私コレで月10万円得しました」
    *   「『マイナンバーカード』がなくなることを知らない人が多すぎる。」（メルマガ36: 595万インプレッション、407名増）
*   **会話調で親近感を持たせる:**
    *   「娘が言ってたんだけどさ…」（メルマガ38: 368万インプレッション、1425名増）
    *   「西松屋っていつもガラガラだよね…」（メルマガ40: 148万インプレッション、95名増）
*   **文字数を少なく、気になるところで切る:**
    *   リプ（スレッド）に誘導するため、1枚目の文字ポストは「題名」くらいの気持ちで、内容を詰め込みすぎないことが重要です（メルマガ38, 40, 41）。

### 投稿形式の使い分けと最新トレンド
てっぺい氏の投稿の基本は「図解ポスト」ですが、アルゴリズムの変化に合わせて様々な形式を試しています。

1.  **1枚目文字ポスト + 2枚目以降図解ポスト（最新トレンド）**
    *   最近のXアルゴリズムは「リプにいってもらう」ことを重視しているため、1枚目に図解を置くと伸びづらい傾向があります（メルマガ3, 7, 14, 39, 40）。
    *   **戦略:** 1枚目を文字ポスト（会話構文、メダル構文など）にして読者の興味を引き、リプ（スレッド）に誘導して2枚目以降で詳細な図解を見せる「ロールキャベツ系ポスト」が最強と分析しています（メルマガ6, 38）。
    *   **実例:**
        *   「メダルの構文」を使った個人向け国債の解説（メルマガ6: 334万インプレッション、417名増）
        *   「会話の文字ポスト」から社会保険の扶養を解説（メルマガ7: 170万インプレッション、307名増）
        *   「会話調の軽いポスト」から地面師事件を解説（メルマガ38: 368万インプレッション、1425名増）
        *   過去に伸びなかった図解ポストを1枚目文字ポストに再構成して成功（メルマガ39: 204万インプレッション、170名増）

2.  **図解ポストの活用**
    *   てっぺい氏のフォロワー爆増の最大の秘密は「図解ポスト」です（メルマガ5, 37）。
    *   **利点:**
        *   文字だけのポストでは想像できないほどのインプレッション数が得られる（メルマガ5）。
        *   とっつきづらい情報をわかりやすく視覚的に伝えられる（メルマガ1, 30）。
        *   Nano Banana ProなどのAIツールを活用することで、作成時間を大幅に短縮できる（メルマガ1, 4, 12, 14, 16）。
        *   InstagramやTikTok、YouTubeショートなど他のSNSへの流用が容易（メルマガ16, 19, 25, 28, 29）。
    *   **作成のポイント:**
        *   パッと見でなんのポストかわかるようにする（メルマガ30）。
        *   イラストや画像を活用し、視覚的インパクトを重視（メルマガ10, 30）。
        *   リサーチ結果に「面白い、意外性がある」要素があれば、図解に落とし込む（メルマガ51, 55）。
        *   図解作成前に一度文字で内容を整理し、反応を見るのも有効（メルマガ51）。
        *   「漢字の比率」については直接言及はないものの、図解や冒頭文の「わかりやすさ」「読みやすさ」を重視していることから、過度な漢字の使用は避け、平易な言葉で伝える意識が伺えます。

3.  **マンガポスト**
    *   文字ポストでは伸びなかった内容も、マンガ化することで爆伸びする可能性があります。
    *   **実例:** 3年連続で文字ポストとして投稿し、昨年はフォロワー34名減だったバレンタインの実話が、マンガ化で240万インプレッション、586名増を達成（メルマガ29）。
    *   **作成方法:** ChatGPTでシナリオを作成し、専用ツールでマンガを生成（メルマガ29, 58）。短いマンガなら5分で作成可能（メルマガ58）。

4.  **1秒動画**
    *   Xは動画を優遇する傾向があるため、ポストに1秒動画を添付することでインプレッションが爆発的に伸びる可能性があります（メルマガ36）。
    *   **実例:** マイナンバーカードのポストに赤い矢印が点滅する1秒動画を添付し、595万インプレッション、407名増を達成（メルマガ36）。

### AIツールの活用
*   **Nano Banana Pro/2:** 図解作成のスピードと質を劇的に向上させる（メルマガ1, 4, 5, 12, 14, 16, 21, 23, 26, 30, 32）。
*   **ChatGPT, Gemini, Perplexity, Grok, Claude:** ネタのリサーチ、情報収集、図解の元となる文章作成、マンガのシナリオ作成などに活用（メルマガ1, 10, 12, 14, 20, 22, 26, 27, 29, 38, 44, 50, 51, 52, 55, 58）。
    *   複数のAIに質問し、良い回答を組み合わせることで質の高いコンテンツを作成（メルマガ10, 12, 14, 22, 38）。
*   **Canva:** 図解のデザイン調整、1枚目の画像作成、図解の動画化（リール動画）に活用（メルマガ10, 16, 25, 27, 28, 44, 52）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

てっぺい氏はインプレッションとフォロワー増を明確に区別し、それぞれの目標に応じた戦略を立てています。

### インプレッションを伸ばす投稿
インプレッションはX収益に直結するため、てっぺい氏は最近インプレッションを伸ばすことも意識しています（メルマガ3）。
*   **「東スポ」要素の強い下世話なネタ:** 人々の好奇心を刺激するゴシップやランキングは、インプレッションを大きく伸ばします。
    *   **実例:**
        *   「女子アナのフリー転向年収ランキング」（メルマガ18: 92万インプレッション、30名減）
        *   「都道府県知事の年収」（メルマガ50: 550万インプレッション、16,940名増）
        *   「新内閣の大臣の年収・資産額」（メルマガ52: 141万インプレッション、7805名増）
*   **流行りの構文や1秒動画:** アルゴリズムに優遇される形式を取り入れることで、拡散力が向上します。
    *   **実例:**
        *   「メダル構文」の個人向け国債ポスト（メルマガ6: 334万インプレッション、417名増）
        *   「1秒動画」付きマイナンバーカードポスト（メルマガ36: 595万インプレッション、407名増）
*   **発信軸から少しズレたネタ:** 普段の発信内容と異なる意外性のあるネタは、幅広い層にリーチし、インプレッションを伸ばすことがあります。
    *   **実例:**
        *   「ホテルが一番空く時期」のポスト（メルマガ9: 60万インプレッション、206名増）
        *   「バレンタインのマンガポスト」（メルマガ29: 240万インプレッション、586名増）
*   **リプ誘導を意識した構成:** 1枚目を文字ポストにしてリプに誘導する形式は、Xのアルゴリズムに優遇され、インプレッションが伸びやすいです（メルマガ3, 7, 14, 39, 40）。

### フォロワー増につながる投稿
フォロワー増はアカウントの長期的な成長に不可欠です。
*   **発信軸に沿った「有益な情報」:** 読者が「知っておいて損はない」と感じる、専門性のある情報はフォローにつながりやすいです。
    *   **実例:**
        *   「選挙の『青木率』解説」（メルマガ1: 1581名増）
        *   「エプスタイン事件解説」（メルマガ4, 32, 33: 1652名増）
        *   「海外メディアの立ち位置解説」（メルマガ26: 2951名増）
        *   「中東情勢の解説」（メルマガ23: 1075名増）
        *   「UAEのOPEC脱退解説」（メルマガ8, 12: 3067名増、2010名増）
    *   てっぺい氏の基本軸は「お金とお得情報」と「ニュース解説」です（メルマガ1, 23）。
*   **「自分ごと」になりやすいテーマ:** 読者自身やその身近な人に関わるテーマは、共感を呼び、フォローにつながりやすいです。
    *   **実例:**
        *   「高校受験の名門高校」（メルマガ44: 44,654名増）
        *   「都道府県知事の年収」（メルマガ50: 16,940名増）
        *   「全国アウトレットの売上・店舗数」（メルマガ51: 5099名増）
        *   「都道府県知事の出身大学」（メルマガ63: 11,514名増）
        *   「東大合格高校ランキング」（メルマガ64: 7127名増）
        *   「都道府県別ショッピングセンター」（メルマガ57: 7428名増）
*   **トレンドに乗ったニュース解説:** 特に海外のニュース解説はフォロワー増につながる傾向があります（メルマガ8）。
*   **図解ポスト:** 「図解を使った方がフォローいただく数は多くなる印象」と述べています（メルマガ8）。Nano Banana Proの活用により、図解作成のハードルが下がり、フォロワー増に貢献しています（メルマガ4, 5, 32, 33, 37）。

### インプレッションは伸びたがフォロワーは減った/伸び悩んだ事例
インプレッションとフォロワー増は必ずしも連動しません。てっぺい氏は、インプレッションが伸びてもフォロワーが減る/伸び悩む事例を重視して分析しています。
*   **発信軸とのズレ:** 普段の発信内容と大きく異なるネタは、インプレッションは稼げても、アカウントのテーマに興味がない層に届くため、フォローにはつながりにくい、あるいはフォロー解除につながることがあります。
    *   **実例:**
        *   「女子アナのフリー転向年収ランキング」（メルマガ18: 92万インプレッション、30名減）。「発信軸とのズレ」と「下世話なネタ」が原因と分析。
        *   「ワールドカップで4ゴール」のポスト（メルマガ43: 17万インプレッション、17名減）。
        *   「日本代表の年俸」のポスト（メルマガ43: 176万インプレッション、119名減）。
        *   「お金・お得情報」でも「ニュース解説」でもないポスト（メルマガ17: 113万インプレッション、69名減）。
*   **ネタの質や見せ方の問題:**
    *   **実例:**
        *   AIにネタ出しをさせたポスト（メルマガ13: 24万インプレッション、10名減）。「おそらくフォローはいただいてると思うが、それ以上に減る数が多かった」。ネタ選びのAI活用はまだ検証中。
        *   過去に文字ポストで伸びなかったバレンタインネタ（メルマガ29: 7.4万インプレッション、34名減）。マンガ化で改善。
        *   「関東の家賃比較」のポスト（メルマガ54: 826万インプレッション、10,666名増 *ただしこの日の他のポストの影響も含む*）。「関東に絞ったことで対象者が限られた」と反省。
        *   「関東の住みやすい街ランキング」（メルマガ56: 81万インプレッション、1584名増）。「関東だけなので全国を網羅してない」「自分ごと化が弱くなる」と分析。
*   **Xの凍結増加:** 最近はXの凍結が増えており、フォロワーが減りやすい傾向にあることも指摘しています（メルマガ17, 18）。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

### 刺さった理由（成功の原則）
1.  **とっつきづらい話を優しく解説**
    *   専門的で難解なテーマを、初心者にも理解できるよう平易な言葉と図解で解説することで、高い価値を提供します。
    *   **実例:** 「政治系の、とっつきづらい話をやさしく解説する発信は、一定の需要がある」（メルマガ1）。
2.  **「闇が深い」「陰謀論的」要素の盛り込み**
    *   人々の根源的な好奇心を刺激する要素は、強い関心を引きつけます。
    *   **実例:** 「エプスタイン事件」に「トランプ大統領の疑惑」「事件から目をそらすためのベネズエラ・グリーンランド」という陰謀論的要素を入れた（メルマガ4, 33）。
3.  **タイムリーな情報提供**
    *   旬の話題や、読者が「今知りたい」と感じる情報を迅速に発信します。
    *   **実例:** 「国会の冒頭解散」に合わせて選挙の「青木率」を解説（メルマガ1）。「ゴールデンウィーク明けはホテルが一番空く時期」というタイムリーな情報（メルマガ9）。
4.  **「自分も『へー』と思った」意外な事実**
    *   発信者自身が驚きや発見を感じた内容は、その熱量が読者にも伝わりやすいです。
    *   **実例:** 「都道府県知事の年収」で小池都知事が最下位だったこと（メルマガ50）。「アウトレットがない都道府県がかなり多い」こと（メルマガ51）。
5.  **具体的な数字や固有名詞の活用**
    *   抽象的な表現ではなく、「55億円」「2017年」「Netflix」といった具体的な情報を用いることで、リアリティと説得力が増します（メルマガ38）。
6.  **AIによる効率的なリサーチと図解作成**
    *   AIを活用することで、これまで時間がかかっていたリサーチや図解作成の時間を大幅に短縮し、質の高いポストを量産できるようになりました（メルマガ12, 51）。これにより「発信したいことが発信できるようになった」と述べています（メルマガ12）。
7.  **アンチのリプはチャンス**
    *   「あおり気味の文言」でアンチのリプが増えることがあっても、「勝手にポストを拡散してくれる」ため、よほど炎上しない限りは恐れる必要はないと捉えています（メルマガ36）。

### 刺さらなかった理由・反省点（失敗からの学び）
1.  **発信軸とのズレ**
    *   インプレッションは伸びてもフォロワーが減る主な原因です。アカウントのテーマと大きく異なる内容は、一時的な注目は集めても、長期的なフォロワー獲得にはつながりません（メルマガ17, 18）。
2.  **1枚目の図解に文字を多く入れすぎた**
    *   読者がスクロールせずに内容を理解できてしまうと、リプ（スレッド）への誘導が弱まります。1枚目は興味を引く程度に留め、詳細はリプで展開するべきです（メルマガ11）。
    *   **実例:** 「為替介入」のポストで「1枚目の図解に文字を多く入れすぎた」ことを反省点として挙げています（メルマガ11）。
3.  **対象範囲が狭い（全国を網羅していない）**
    *   「自分ごと」化が弱まり、ポストのリーチが限定されます。
    *   **実例:** 「関東の家賃比較」や「関東の住みやすい街ランキング」で、全国を網羅しなかったことを反省しています（メルマガ54, 56）。
4.  **見せ方のマンネリ化**
    *   Xは「飽きを嫌う傾向がある」ため、同じようなポストや構文を使い続けると反応が落ちます。見せ方を変える工夫が必要です（メルマガ16）。
    *   **実例:** 過去に文字ポストで伸びなかったバレンタインネタをマンガ化して成功した事例（メルマガ29）。
5.  **ネタが身近でない、あるいは簡単すぎる/少なすぎる**
    *   読者が自分事として捉えにくいテーマや、情報量が少なすぎるポストは、エンゲージメントが低くなります。
    *   **実例:** 「為替介入」が「自分とは関係なさそうに感じる」ため伸び悩んだ（メルマガ11）。「手書きメモ風」図解で「用語が簡単すぎた」「用語が8つしかないのは少な過ぎた」ことを反省（メルマガ34）。

### 継続の原則
*   **楽しむこと:** 「ポストを作っていて楽しくて、それを喜んでもらえる人がいるというのが理想」（メルマガ23）。「楽しむことは長く続けるコツ」（メルマガ11）。
*   **健康:** 「風邪で、頭が動かないとポストをまったく作る気がおきない」（メルマガ64）。健康が大切。
*   **試行錯誤:** 「フォロワーさんが10万人を超えてもまだまだ試行錯誤の毎日」（メルマガ34）。アルゴリズムの変化に合わせて見せ方を変化させる（メルマガ40）。

## 5. 投稿前チェックリスト（具体的な確認項目）

てっぺい氏の成功事例と反省点から導き出された、投稿前の具体的な確認項目です。

### ネタ・テーマに関するチェック
*   [ ] **「聞いたことあるけどよくわからない」**という読者の知的好奇心を刺激するテーマか？
*   [ ] 読者にとって**「自分ごと」**になりやすいテーマか？（例: 都道府県別、生活に密着した情報）
*   [ ] **「下世話」な要素**（年収、事件の闇など）や**「意外性」**のある情報を含んでいるか？
*   [ ] **Xのトレンドワードや時事ネタ**に乗っているか？（特にフォロワー増を狙う場合）
*   [ ] **一次情報や自身の経験**に基づいた独自性のある内容か？
*   [ ] 読者が**「調べるのが面倒」**なことを代わりに解説しているか？
*   [ ] 自分自身が「へー」と思った、**興味深い内容**か？
*   [ ] **具体的な数字や固有名詞**を効果的に使用しているか？
*   [ ] 発信軸と大きくズレていないか？（インプレッション優先か、フォロワー増優先か、目的を明確にする）
*   [ ] 他者のポストの**パクリではないか？**（同じネタを使う場合は事前に確認する）

### 投稿の構成・型に関するチェック
*   [ ] **冒頭文はインパクトがあるか？**（「断言します」「これを知らないと大損します」「私コレで月10万円得しました」のような煽りや具体的な言葉を使っているか）
*   [ ] **1枚目のポストは文字ポストで、リプ（スレッド）への誘導を意識した構成か？**（文字は少なめに、気になるところで切っているか）
*   [ ] **2枚目以降の図解は、有益な情報をわかりやすく視覚的に伝えているか？**
*   [ ] 図解は**パッと見で内容がわかる**ようにデザインされているか？（イラストや画像を効果的に使用）
*   [ ] **AIツール（Nano Banana Pro, ChatGPT, Canvaなど）**を効率的に活用し、作成時間を短縮できているか？
*   [ ] **マンガポストや1秒動画**など、Xのアルゴリズムに優遇される形式を取り入れているか？
*   [ ] 過去に伸びたポストの再投稿の場合、**見せ方を変える工夫**（文字→図解、文字→マンガ、構文変更など）をしているか？
*   [ ] ポスト全体を通して、**読みやすさ**を意識しているか？（漢字の比率、句読点、改行など）

### 数値実績・目的に関するチェック
*   [ ] このポストで**インプレッションを伸ばしたいのか、フォロワーを増やしたいのか、目的は明確か？**
*   [ ] インプレッションを伸ばしたい場合、**「下世話な要素」「流行りの構文」「1秒動画」**などを盛り込んでいるか？
*   [ ] フォロワーを増やしたい場合、**発信軸に沿った「有益な情報」や「自分ごと」化しやすいテーマ**を選んでいるか？
*   [ ] ポスト発信後の**30分〜60分は交流（リプへの返信など）**を積極的に行う準備ができているか？
