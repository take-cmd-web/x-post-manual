# X投稿マニュアル

X(旧Twitter)でフォロワー13万人を達成した「てっぺい」氏の運用実績と考察に基づき、再現性のある投稿マニュアルを作成しました。インプレッションの最大化とフォロワー増加、両面からのアプローチを解説します。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる最も重要な要素は「ネタ」であると繰り返し強調されています。以下の法則を意識してネタを選定しましょう。

### 1-1. 「なんとなく聞いたことあるけど、よくわからない」テーマ
多くの人が興味を持ちつつも、深掘りする手間を惜しむようなテーマは、わかりやすく解説することで高いエンゲージメントを得られます。
*   **例1: 選挙の「青木率」解説**
    *   インプレッション：234万、フォロワー：1581名増 (メルマガ1)
    *   「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってること」を優しく解説。
*   **例2: エプスタイン事件の闇**
    *   インプレッション：144万、フォロワー：1652名増 (メルマガ4)
    *   「なんとなく聞いたことあるけどよくわからない」事件を解説。
*   **例3: 「ナフサ不足」とポテトチップス**
    *   インプレッション：182万、フォロワー：603名増 (メルマガ10)
    *   「聞いたことある」「大切そう」「でもよくわからない」を満たし、かつ「ポテチの白黒袋」というインパクトある事象と結びつけたことで爆伸び。
*   **例4: 「残クレ」アルファードの仕組み**
    *   インプレッション：65万、フォロワー：532名増 (メルマガ30)
    *   「よく聞くけどよくわからない、ちょっと気になること」をテーマに。

### 1-2. トレンドに乗った時事ネタ・ニュース解説
Xのリアルタイム性を活かし、話題になっているニュースや社会情勢を解説する投稿は、インプレッションとフォロワー増加の両方に繋がりやすい傾向があります。特に「海外のニュース」は反応が良いとされています。
*   **例1: 海外メディアの立ち位置解説**
    *   インプレッション：184万、フォロワー：2951名増 (メルマガ26)
    *   「CNNは左寄り」というポッドキャスト情報から着想。
*   **例2: UAEのOPEC脱退**
    *   インプレッション：60万、フォロワー：2010名増 (メルマガ12)
    *   「トレンドになっていた」ニュースを解説。
*   **例3: 韓国大統領の逮捕歴**
    *   インプレッション：78万、フォロワー：447名増 (メルマガ27)
    *   「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問をトレンドに乗せて発信。
*   **例4: 新内閣の大臣の年収・資産額**
    *   インプレッション：141万、フォロワー：7805名増 (メルマガ52)
    *   内閣発表という時事ネタに「下世話な要素」を組み合わせた成功例。

### 1-3. 「自分ごと」化しやすい普遍的なテーマ
多くの人が自分自身や身近なこととして捉えられるテーマは、共感を呼びやすく、フォロワー増加に直結します。
*   **例1: 都道府県別の高校受験「名門校」**
    *   1ポストで44,654名増 (メルマガ44, 46, 47)
    *   「高校受験をしてる人は圧倒的に多い」「名門といわれる高校を卒業してる人は、このポストが気になる」というターゲットの広さが成功要因。
*   **例2: 都道府県別の知事の年収**
    *   インプレッション：550万、フォロワー：16,940名増 (メルマガ50)
    *   「自分の県の知事、意外と知らない人いるんじゃないか」という疑問から着想。
*   **例3: 都道府県別アウトレット/ショッピングセンター**
    *   アウトレット：インプレッション：123万、フォロワー：5099名増 (メルマガ51)
    *   ショッピングセンター：インプレッション：194万、フォロワー：7428名増 (メルマガ57)
    *   「身近でみんなわかるもの、みんな好きなもの」が伸びる。
*   **例4: 血液型と国の分布**
    *   インプレッション：114万、フォロワー：909名増 (メルマガ59)
    *   「全員が必ずどこかに属する」ため「自分ごと」になりやすい。

### 1-4. 「下世話な要素」や「意外性」の組み合わせ
真面目なテーマに、多くの人が関心を持つ「お金」「ランキング」「裏側」といった下世話な要素や、意外な事実を組み合わせることで、興味を惹きつけやすくなります。
*   **例1: 女子アナのフリー転向と年収ランキング**
    *   インプレッション：92万、フォロワー：30名減 (メルマガ18)
    *   「女子アナ」「フリー転向」「年収」という下世話なネタを盛り込み、インプレッションは大きく伸びた。ただし、発信軸とのズレからフォロワーは減少。
*   **例2: 知事の年収**
    *   インプレッション：550万、フォロワー：16,940名増 (メルマガ50)
    *   「年収」という要素を加えることで、知事一覧が爆伸び。東京の小池都知事が最下位という「意外性」も効果的。
*   **例3: 新内閣の大臣の年収・資産額**
    *   インプレッション：141万、フォロワー：7805名増 (メルマガ52)
    *   有益な内閣解説に「年収」「資産額」という下世話な要素を組み合わせた。
*   **例4: 都道府県別大学出身知事**
    *   インプレッション：422万、フォロワー：11,514名増 (メルマガ63)
    *   「大学は東京に集中するからつまらないかと思ったが、東大出身が想像以上に多くて、むしろそれが良かった」という意外性。

### 1-5. 「言われてみれば不思議」なこと
日常の中で誰もが疑問に思うが、深く考えないような事柄を解明する投稿も効果的です。
*   **例: インドカレー屋さんがいつもガラガラな理由**
    *   インプレッション：317万、フォロワー：492名増 (メルマガ41)
    *   「自分でも不思議に思ってたので、なるほどと思った人が多かったのではないか」。

### 1-6. 一次情報・具体的な数値・固有名詞の活用
信頼性や具体性を高めるために、ニュースソース、具体的な数字、人物名、地名などを積極的に取り入れましょう。
*   **例: エプスタイン事件**
    *   「1月30日に新たにファイルが350万ページ公開された」という具体的な情報 (メルマガ4, 33)。
*   **例: 「地面師たち」事件**
    *   「55億円」「Netflix」「2017年」といった具体的な数字や固有名詞で興味を引く (メルマガ38)。

### 1-7. 自身の「一次情報」や「学び」を活かす
自分が「へー」と思ったこと、学んだことは、発信者自身が楽しみながら継続できるだけでなく、読者にもその熱量が伝わりやすくなります。
*   **例1: ホテルのオフシーズン情報**
    *   インプレッション：60万、フォロワー：206名増 (メルマガ9)
    *   「本業のちょっとした知識」で、一般には知られていない情報を提供。
*   **例2: 為替介入の仕組み解説**
    *   インプレッション：7万、フォロワー：90名増 (メルマガ11)
    *   「じつは自分がはっきりわかってなかったので調べて、それを発信した」。伸びは控えめだが、フォロー率は高かった。
*   **てっぺい氏曰く:** 「自分が『そうなんだ』と思ったこと、『学んだこと』をわかりやすく発信することは自分の学びにもなるので楽しく発信ができてるんだと改めて思った。『楽しむ』ことは長く続けるコツ」（メルマガ11）。

### 1-8. 当たったネタの「周辺」を攻める
一度バズったネタは、その周辺の関連テーマも伸びやすい傾向にあります。
*   **例: ワールドカップネタ**
    *   ワールドカップのネタが当たった後、6日連続でワールドカップ関連のポストを投稿し、高いインプレッションを維持 (メルマガ42)。
    *   「ネタが続く限り、日本が勝ってる間は続けようと思ってる」。

### 1-9. AIをリサーチツールとして活用
ネタ出し自体は人間が行うことが多いものの、リサーチや情報整理にはAIを積極的に活用することで、効率と質を高めることができます。
*   **てっぺい氏曰く:** 「どういうネタにするかは自分で考えてるが、リサーチにAIを使ってる」（メルマガ51）。
*   **活用例:**
    *   ChatGPT, Gemini, Perplexity, Grok, Claudeなど複数のAIに質問し、回答を比較・統合して図解の元を作成 (メルマガ10, 12, 14, 20, 26, 38, 55)。
    *   「以前はリサーチが絶対に30分で終わらなかったし、図解も40分はかかってたのが、圧倒的にスピードが早くなった」（メルマガ12）。
    *   「リサーチの結果が、面白い、意外性があるという場合は、ポストとして伸びる可能性がある」（メルマガ55）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xのアルゴリズムの変化に対応し、投稿の「見せ方」を常に最適化することが重要です。

### 2-1. 冒頭文のインパクト勝負
Xは「流し読みされる媒体」であるため、冒頭文でいかに読者の興味を引きつけられるかが、ポストが伸びるかどうかの鍵となります。
*   **てっぺい氏曰く:** 「どれだけ良い内容を書いていても書き出しがつまらないとポストは伸びない」（メルマガ2, 35）。
*   **具体的な表現例:**
    *   「断言します」
    *   「これを知らないと大損します」
    *   「私コレで月10万円得しました」
    *   「『マイナンバーカード』がなくなることを知らない人が多すぎる。」（あおり気味の文言でインプレッション：595万、フォロワー：407名増、メルマガ36）
*   **原則:** アンチを恐れず、強い言葉で興味を引く。

### 2-2. 「1枚目文字ポスト＋2枚目以降図解」の型
最近のXアルゴリズムでは「リプに行ってもらう」ことが重視される傾向にあります。そのため、図解をいきなり見せるのではなく、1枚目で興味を引き、リプへ誘導する構成が効果的です。
*   **てっぺい氏曰く:** 「1枚目に図解をおくと、伸びづらくなってる印象。1枚目は文字にして、とにかくリプにいってもらうポストが、インプレッションも増えて内容が有益であれば、フォローもしていただける」（メルマガ3）。
*   **成功事例:**
    *   **過去の伸びた図解ポストを1枚目だけ文字にして再投稿** (メルマガ3, 39)。
        *   例: 2月に伸びたポスト（図解）を6月に「文字の会話」で再投稿したところ、インプレッション：204万、フォロワー：170名増と大きく改善 (メルマガ39)。
    *   **会話構文の活用:**
        *   1枚目を会話の文字ポストにし、2枚目以降を図解にする (メルマガ7, 38, 39, 40, 42)。
        *   「極力シンプルに、気になるところで切って、リプへ」（メルマガ7）。
        *   「題名ぐらいの気持ちで今は、最初の会話ポストを作ってる」（メルマガ40）。
        *   例: 「地面師たち」事件の解説ポストは、会話調の1枚目で「55億円」「地面師」「Netflix」「2017年」といったパワーワードと具体的な数字を使い、リプ誘導に成功。インプレッション：368万、フォロワー：1425名増 (メルマガ38)。
    *   **メダル構文・流行りの構文の活用:**
        *   1枚目に流行りの構文を使い、2枚目以降で有益な図解を見せる「ロールキャベツ系ポスト」を提唱 (メルマガ6)。
        *   例: 「個人向け国債 変動10年」の解説にメダル構文を使い、インプレッション：334万、フォロワー：417名増 (メルマガ6)。
*   **原則:** 導入は軽く、中身は図解でわかりやすく。

### 2-3. 図解ポストの重要性
てっぺい氏のフォロワー増加の最大の秘密は「図解ポスト」であるとされています。Nano Banana Proなどのツールを活用することで、質の高い図解を効率的に作成できます。
*   **てっぺい氏曰く:** 「文字だけのポストでは想像できないほどのインプレッション数が得られる」（メルマガ5）。「図解を使った方がフォローいただく数は多くなる印象」（メルマガ8）。
*   **デザインの工夫:**
    *   **「パッと見でなんのポストかわかるようにする」** (メルマガ30)。
        *   例: 「残クレ」アルファードのポストでは、アルファードのイラストを大きく配置。
    *   **「知ってるものとつなげる」** (メルマガ30)。
        *   例: 残クレアルファードの解説で、通常のローンとの比較を入れることで理解を促進。
    *   **「手書きメモ風」など見せ方を変える** (メルマガ34)。
    *   **「細かすぎて見えないので、図解を拡大してくれる」**ような要素も有効 (メルマガ44)。
    *   **ツッコミどころもOK:** 「世界地図の形がかなり怪しかったが、大まかにはあってたのでそのままいきました。かえってツッコミどころがあってよかったのかも」（メルマガ59）。
*   **AI活用による効率化:**
    *   Nano Banana Pro (Nano Banana 2) を使うことで、図解作成のスピードが劇的に向上 (メルマガ1, 4, 5, 10, 12, 14, 16, 21, 23, 26, 27, 30, 32, 37)。
    *   ChatGPTなどでリサーチした内容をNano Banana Proで図解化。

### 2-4. マンガポストの活用
文字ポストでは伸び悩んだ内容も、マンガ化することで大きく改善する可能性があります。
*   **例: バレンタインの文字ポストをマンガ化**
    *   文字ポスト時：インプレッション：7.4万、フォロワー：34名減 (メルマガ29)
    *   マンガ化後：インプレッション：240万、フォロワー：586名増 (メルマガ29)
    *   ChatGPTでシナリオを作成し、専用ツールでマンガ化。

### 2-5. 1秒動画の活用
Xは動画を優遇する傾向があるため、短い動画を添付することでポストの拡散力を高めることができます。
*   **例: マイナンバーカードのポストに赤い矢印が点滅する1秒動画を添付**
    *   インプレッション：595万、フォロワー：407名増 (メルマガ36)
    *   「X社は動画を優遇しているので、1秒の動画をつけることでポストが爆発的に伸びる」。

### 2-6. リプへの返信と交流
ポスト発信後の初期エンゲージメントは、Xのアルゴリズムにおいて重要です。
*   **てっぺい氏曰く:** 「ポスト発信後の30分、60分は特に交流が大切」（メルマガ7）。
*   **原則:** いただいたリプには、できるだけ早く返信する。
*   **効果:** 伸びそうなポストにリプすると、リプ自体のインプレッションも伸びる傾向がある (メルマガ42)。

### 2-7. 漢字の比率と読みやすさ
メルマガには直接的な言及はないが、てっぺい氏のポストはひらがなを多用し、句読点や改行を適切に使うことで、Xの流し読み文化に合わせた読みやすい文章を心がけていると推測される。図解も文字量を抑え、視覚的に訴えかける工夫が見られる。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増加は必ずしも一致しません。それぞれの目標に応じた戦略が必要です。

### 3-1. インプレッションを伸ばす投稿の傾向
インプレッションは、ポストがどれだけ多くの人のタイムラインに表示されたかを示す指標であり、X収益に直結します。
*   **冒頭のインパクトが強い投稿:**
    *   「断言します」「これを知らないと大損します」などの煽り文句や、具体的な数字・固有名詞で興味を引く冒頭文 (メルマガ2, 35, 36)。
    *   **例:** 「マイナンバーカード」がなくなることを知らない人が多すぎる。→ インプレッション：595万 (メルマガ36)。
*   **流行りの構文や動画を活用した投稿:**
    *   メダル構文、会話構文、1秒動画など、アルゴリズムに優遇されやすい形式 (メルマガ6, 36, 42)。
    *   **例:** 個人向け国債の解説にメダル構文 → インプレッション：334万 (メルマガ6)。
    *   **例:** ワールドカップネタに会話構文＋箇条書き＋図解 → インプレッション：532万 (メルマガ42)。
*   **「下世話な要素」や「東スポ要素」が強い投稿:**
    *   多くの人が本能的に興味を持つゴシップ、ランキング、裏話的な内容 (メルマガ18, 50, 52)。
    *   **例:** 女子アナのフリー転向と年収ランキング → インプレッション：92万 (メルマガ18)。
*   **「なんとなく聞いたことあるけど、よくわからない」を扱う投稿:**
    *   多くの人が「知りたい」と感じるが、調べるのが面倒なテーマ (メルマガ1, 4, 10, 12, 30, 33)。
    *   **例:** エプスタイン事件 → インプレッション：234万 (メルマガ1)。
*   **図解ポスト全般:**
    *   文字ポストよりも視覚的に訴えかけやすく、インプレッション数が伸びやすい傾向 (メルマガ5)。

### 3-2. フォロワー増加に繋がりやすい投稿の傾向
フォロワー増加は、アカウントの専門性や信頼性を高め、長期的な影響力構築に繋がります。
*   **発信軸に合致した、質の高い「有益情報」:**
    *   てっぺい氏の基本軸である「お金とお得情報」や「ニュース解説」はフォロワー増加に直結 (メルマガ1, 23)。
    *   **例:** 政治系のとっつきづらい話を優しく解説 → インプレッション：234万、フォロワー：1581名増 (メルマガ1)。
    *   **例:** 中東情勢の解説 → インプレッション：58万、フォロワー：1075名増 (メルマガ23)。
*   **「自分ごと」化しやすい、対象者の広いテーマ:**
    *   多くの人が自分に関係あると感じる普遍的なテーマは、フォローを促しやすい (メルマガ44, 50, 51, 54, 55, 57, 59, 63)。
    *   **例:** 都道府県別の高校受験「名門校」 → 1ポストで44,654名増 (メルマガ44)。
    *   **例:** 都道府県別の知事の年収 → インプレッション：550万、フォロワー：16,940名増 (メルマガ50)。
*   **「難しそうなことをわかりやすく解説」する図解ポスト:**
    *   図解は情報の理解度を高め、アカウントの価値を認識させやすい (メルマガ8, 23)。
    *   **てっぺい氏曰く:** 「図解を使った方がフォローいただく数は多くなる印象」（メルマガ8）。
    *   **例:** 為替介入の仕組み解説 → インプレッション：7万、フォロワー：90名増 (伸びは控えめだが、わかりやすさが評価されフォローに繋がった、メルマガ11)。
*   **トレンドに乗ったワードを含む投稿:**
    *   話題性のあるテーマは、新規ユーザーの目に留まりやすく、フォローに繋がりやすい (メルマガ10)。
    *   **例:** 「ナフサ不足」のトレンドワード → インプレッション：182万、フォロワー：603名増 (メルマガ10)。

### 3-3. インプレッションは伸びたがフォロワーが減った示唆的な事例
インプレッションとフォロワー増加は必ずしも比例しません。特に以下のケースでは注意が必要です。
*   **発信軸との大きなズレ:**
    *   **例:** 女子アナのフリー転向と年収ランキング (普段は「お金とお得情報」「ニュース解説」)
        *   インプレッション：92万、フォロワー：30名減 (メルマガ18)
        *   てっぺい氏曰く: 「発信軸とのズレがある」「さすがにギャップがあったのかも」。
    *   **例:** 「お金・お得情報」でも「ニュース解説」でもない投稿
        *   インプレッション：113万、フォロワー：69名減 (メルマガ17)
        *   てっぺい氏曰く: 「フォロワー様が減った要因になってる」。
*   **流行りの構文を使いすぎた場合:**
    *   インプレッションは伸びるが、内容が薄いとフォローに繋がりにくい (メルマガ6)。
    *   **てっぺい氏曰く:** 「流行りの構文を使って、インプレッションはでるけどフォローされないという話をよく聞く。この構文は、ややアルゴリズムをハックしてる感があるので、その傾向はある」。
*   **図解の文字が多すぎる場合:**
    *   **例:** 為替介入のポスト
        *   インプレッション：7万、フォロワー：90名増 (メルマガ11)
        *   てっぺい氏の反省点: 「1枚目の図解に文字を多く入れすぎたこと。『スマホを離さずに』『最後の退避勧告』ぐらいにしておいた方が、リプにいってもらえたかな」。
*   **「自分ごと」化しにくいテーマ:**
    *   **例:** AIにネタ出しさせたポスト (テーマは不明だが、てっぺい氏が「いいかも」と思ったのは1つだけだったと述べている)
        *   インプレッション：24万、フォロワー：10名減 (メルマガ13)
        *   てっぺい氏曰く: 「おそらくフォローはいただいてると思うが、それ以上に減る数が多かったのだと思う」。
*   **Xの凍結増加:**
    *   最近はXの凍結が増えており、フォロワーの減少が起こりやすい環境にあることも考慮する (メルマガ17, 18)。

### 3-4. 再投稿の有効性
反応の良かったポストは、時期をずらしたり、見せ方を変えたりして何度も再投稿することで、継続的にインプレッションとフォロワーを獲得できます。
*   **てっぺい氏曰く:** 「同じポストは何度も使い回してOK。というか、どんどん使い回してください。当たるか分からないポストを闇雲に投稿し続けるなんて費用対効果が悪過ぎる」（メルマガ36）。
*   **例1: マイナンバーカードのポスト**
    *   初回：インプレッション：655万、フォロワー：1114名増
    *   2回目：インプレッション：213万、フォロワー：125名増
    *   3回目：インプレッション：595万、フォロワー：407名増
    *   合計で1646名増 (メルマガ36)。
*   **例2: 過去の図解ポストを1枚目文字ポストに変更して再投稿**
    *   インプレッション：204万、フォロワー：170名増 (メルマガ39)。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功事例と失敗事例から、再現性のある原則を抽出します。

### 4-1. 刺さった理由（成功原則）

1.  **普遍的な疑問の解消:**
    *   「なんとなく聞いたことあるけど、よくわからない」ことを、専門家の視点から優しく解説する (メルマガ1, 4, 10, 12, 30, 33)。
    *   「言われてみれば不思議」なことの裏側を解き明かす (メルマガ41)。
2.  **時事性とトレンドへの対応:**
    *   XのトレンドワードやYahoo!ニュースを常にチェックし、話題のネタを迅速に投稿する (メルマガ8, 10, 14, 49)。
    *   特に「海外のニュース」は反応が良い傾向 (メルマガ8)。
    *   当たったネタは、その周辺テーマを深掘りして連続投稿する (メルマガ42)。
3.  **「自分ごと」化と共感の喚起:**
    *   多くの人が自分自身や身近なこととして捉えられるテーマを選ぶ (メルマガ44, 50, 51, 54, 55, 57, 59, 63)。
    *   「全員が必ずどこかに属する」ようなテーマ（都道府県別、血液型など）は特に効果的 (メルマガ59)。
4.  **「下世話」と「意外性」のスパイス:**
    *   真面目なテーマに「年収」「資産額」「ランキングの意外な順位」といった下世話な要素や意外な事実を組み合わせる (メルマガ18, 50, 51, 52, 63)。
    *   「みんなが『えっ』と思う結果」は拡散されやすい (メルマガ51)。
5.  **冒頭文による強力なフック:**
    *   「断言します」「これを知らないと大損します」などの断定的な言葉や、煽り気味の文言で読者の興味を瞬時に引きつける (メルマガ2, 35, 36)。
6.  **リプ誘導を意識した構成:**
    *   1枚目を文字ポスト（会話構文、メダル構文など）にし、読みやすく文字量を抑え、続きをリプに誘導する (メルマガ3, 7, 14, 26, 38, 39, 40, 41)。
    *   「気になるところで切って、リプへ」というテクニック (メルマガ7, 38, 41)。
7.  **図解による「わかりやすさ」の追求:**
    *   複雑な情報を視覚的に整理し、直感的に理解できるよう図解を活用する (メルマガ4, 5, 7, 8, 12, 16, 23, 30, 32, 37, 40, 41)。
    *   「パッと見で何かわかる」デザインを心がける (メルマガ30)。
    *   「知ってるものとつなげる」ことで、新規の概念も理解しやすくする (メルマガ30)。
8.  **具体的な数値・固有名詞・一次情報の提示:**
    *   信頼性と説得力を高めるために、具体的なデータや情報源を明記する (メルマガ1, 4, 10, 38, 50, 51, 52)。
9.  **AIによる効率的なリサーチと制作:**
    *   Nano Banana ProなどのAIツールを活用し、図解作成やリサーチの時間を大幅に短縮する (メルマガ1, 4, 5, 10, 12, 14, 16, 21, 23, 26, 27, 30, 32, 37)。
    *   複数のAIを使い分け、最適な回答を組み合わせる (メルマガ10, 12, 14, 20, 26, 38, 55)。
10. **発信者自身の「楽しさ」:**
    *   自分が「へー」と思ったことや、調べていて楽しいと感じるテーマを発信することで、継続性と熱量が生まれる (メルマガ11, 22, 23, 27, 52, 63)。

### 4-2. 刺さらなかった理由（反省点）

1.  **発信軸とのズレ:**
    *   インプレッションは伸びても、アカウントの専門性や読者の期待と異なるテーマは、フォローに繋がりにくい (メルマガ1, 17, 18)。
    *   **例:** 女子アナの年収ランキングはインプレッション92万だが、フォロワー30名減 (メルマガ18)。
2.  **図解の文字量過多:**
    *   1枚目の図解に文字を多く入れすぎると、読者がリプに進む前に離脱してしまう (メルマガ11)。
    *   **例:** 為替介入のポストは、図解の文字が多すぎたためインプレッションが伸び悩んだ (メルマガ11)。
3.  **ネタのインパクト不足:**
    *   同じテーマでも、視覚的なインパクトや話題性が弱いと伸びにくい (メルマガ10)。
    *   **例:** 以前発信した「ナフサ」のポストは伸びなかったが、「ポテトチップスの白黒袋」というインパクトとトレンドを組み合わせることで爆伸びした (メルマガ10)。
4.  **情報量の不足・簡単すぎた内容:**
    *   読者が期待する情報量や深さに達していないと、物足りなさを感じさせてしまう (メルマガ34)。
    *   **例:** 投資用語の図解で「用語が簡単すぎた」「用語が8つしかないのは少な過ぎた」と反省 (メルマガ34)。
5.  **対象者の限定性:**
    *   特定の地域や属性に限定されたテーマは、全体的なインプレッションやフォロワー増加に繋がりにくい (メルマガ54, 56)。
    *   **例:** 「関東の家賃」比較は伸びたが、「全国」の方が強い印象。迷ったら全国でやるべき (メルマガ54, 56)。
6.  **図解の質の問題:**
    *   AI生成の図解で「日本地図が歪んでいる」「知事の顔が違う」といった不正確さがあると、読者の信頼を損ねる可能性もある (メルマガ44, 50)。ただし、ツッコミどころとして機能する場合もある (メルマガ59)。
7.  **「パクリ」と見なされるリスク:**
    *   他者の投稿をそのまま模倣することは、倫理的な問題だけでなく、オリジナリティの欠如として評価されない (メルマガ15, 51)。
    *   **てっぺい氏曰く:** 「同じネタを使う場合は基本的にはそのポストをした方に事前に確認してます」（メルマガ51）。
8.  **アルゴリズムの変化への対応遅れ:**
    *   Xのアルゴリズムは常に変化するため、過去の成功パターンに固執すると伸び悩む (メルマガ3, 39, 40)。
    *   **例:** 「最初のポストに図解」の構成が伸びづらくなったことに対応し、「1枚目文字ポスト」に切り替えた (メルマガ3, 39, 40)。

### ネタ・テーマに関するチェック
*   [ ] **「なんとなく聞いたことあるけど、よくわからない」**テーマか？
*   [ ] **XのトレンドワードやYahoo!ニュース**に乗っているか？（時事性）
*   [ ] **「自分ごと」**として多くの人が捉えられるテーマか？（例: 都道府県別、普遍的な悩み）
*   [ ] **「下世話な要素」や「意外性」**を組み合わせられないか？（例: 年収、ランキングの意外な結果）
*   [ ] **「言われてみれば不思議」**なことの解明か？
*   [ ] 自身の**「一次情報」や「学び」**を活かせるテーマか？
*   [ ] **具体的な数値、固有名詞、一次情報**が含まれているか？

*   [ ] ポストを作成していて**「楽しい」**と感じるか？（継続性のために重要）

*   [ ] **冒頭文はインパクトがあるか？**（「断言します」「これを知らないと大損します」「あおり気味」な言葉、具体的な数字など）

    *   [ ] 1枚目の文字量は**読みやすく、少なめ**に抑えられているか？
    *   [ ] 「気になるところで切って、リプへ」という工夫があるか？

*   [ ] 図解は**「知ってるものとつなげる」**工夫があるか？
*   [ ] 図解の**文字量は適切**か？（多すぎないか）
*   [ ] **1秒動画**を添付して、ポストの拡散力を高められないか？
*   [ ] 必要に応じて**マンガポスト**の形式を検討したか？（特に文字ポストで伸び悩んだ内容）

*   [ ] **句読点や改行**を適切に使い、流し読みしやすい文章になっているか？
