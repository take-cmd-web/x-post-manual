# X投稿マニュアル

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の成功事例から見ると、Xで伸びるネタ・テーマには明確な法則があります。自身の発信軸（「お金とお得情報」）から外れる政治・時事ネタも、特定の条件を満たせば大きく伸び、フォロワー増加に繋がっています。

### 1.1. 普遍的な興味・関心と「自分ごと化」できるテーマ
多くの人が「自分ごと」として捉えられる、あるいは「知っておきたい」と感じるテーマが強いです。

*   **「なんとなく聞いたことあるけど、よくわからない」を優しく解説**
    *   例：「選挙の『青木率』解説」（234万インプレッション、1581名増）、「闇が深いエプスタイン事件」（144万インプレッション、1652名増）、「残クレアルファード」（65万インプレッション、532名増）など。
    *   とっつきづらい、難しそうなテーマでも、てっぺい氏のように「やさしく解説」することで、多くの読者に届きます。
*   **「言われてみれば不思議」な日常の疑問**
    *   例：「インドカレー屋さんの秘密」（317万インプレッション、492名増）のように、多くの人が経験しているが理由を知らないようなネタは共感を呼びやすいです。
*   **身近でみんながわかる・好きなもの**
    *   例：「都道府県別のショッピングセンターの比較」（194万インプレッション、7,428名増）は、多くの人が利用し、関心があるため大きく伸びました。アウトレットの比較も同様に「見たことない」という意外性で「122万インプレッション、5099名増加」を記録しています。
*   **対象者が広く、みんなが知りたいと思っていること**
    *   例：「高校受験の名門高校」（1ポストで44,654名増加）は、高校受験経験者やその保護者など、非常に広い層に刺さるテーマでした。

### 1.2. トレンド・時事性に乗る
Xはリアルタイム性が高いため、トレンドや時事ネタは非常に強力なフックとなります。

*   **XやYahoo!ニュースのトレンドワード**
    *   例：「ナフサ不足とポテトチップスの白黒袋」（182万インプレッション、603名増）は、トレンドワードから着想を得て、インパクトのあるニュースと結びつけることで大きく伸びました。
    *   「UAEのOPEC脱退」（60万インプレッション、2010名増）も、トレンドワードから発信されました。
*   **現在進行形の事件やニュース**
    *   例：「エプスタイン事件」は、「現在進行形で1月30日に新たにファイルが350万ページ公開された」というタイムリーな情報がフォロワー増加に繋がりました。
    *   「国会の冒頭解散」に合わせて「青木率」を解説したポストも同様です。
*   **海外のニュース解説**
    *   てっぺい氏のフォロワー1000名以上増加ポスト5本中、4本が海外ニュース解説でした。
        *   「海外メディアのイラン攻撃報道」（184万インプレッション、2951名増）
        *   「中東情勢の解説」（58万インプレッション、1075名増）
        *   「UAEがOPECを脱退」（60万インプレッション、3067名増）
        *   「韓国大統領の逮捕」（78万インプレッション、447名増）
    *   日本のメディアで取り扱いが少ない、あるいは深掘りされていない海外ニュースは、一次情報としての価値が高く、需要があります。

### 1.3. 意外性・「下世話」な要素
読者の好奇心を刺激する意外な事実や、少し「下世話」に感じる要素は、インプレッションとエンゲージメントを高めます。

*   **意外なリサーチ結果**
    *   例：「都道府県知事の年収」（550万インプレッション、16,940名増）で、東京の小池都知事が給与カットにより47都道府県で最下位という意外性が大きな反響を呼びました。
    *   「全国のアウトレット」で「御殿場の売上だけやたら高い」「アウトレットがない都道府県がかなり多い」といった結果の意外性も重要です。
*   **「下世話」なランキングや情報**
    *   例：「女子アナフリー転向年収ランキング」（92万インプレッション、30名減）は、発信軸とズレてフォロワーは減ったものの、インプレッションは大きく伸びました。てっぺい氏自身も「東スポ要素が強いので伸びると思った」と述べています。
    *   「年収」「資産額」といった具体的な数字は、有益な情報と組み合わせることで強力なフックになります（例：新内閣の年収・資産額解説で141万インプレッション、7805名増）。

### 1.4. 自身の経験・一次情報
てっぺい氏が「自分の勉強にもなるので発信も楽しくなる」と述べるように、自身が「へー」と思ったことや、本業の知識、実体験から得た一次情報は、オリジナリティと熱量を伴い、読者に響きやすいです。

*   例：「ゴールデンウィーク明けはホテルが一番空く時期」（60万インプレッション、206名増）は、ホテル勤務経験からの一次情報でした。
*   「為替介入」や「妻の扶養パート探し」など、自身が調べて学んだことや、リアルな生活の疑問を解決する過程を発信することで、共感と信頼を得ています。

### 1.5. 伸びたネタは「こすり続ける」
一度伸びたネタは、形を変えたり、周辺情報を深掘りしたりして、何度も再利用することが推奨されています。

*   例：ワールドカップネタは「6日連続で、ワールドカップネタ」を発信し、「優勝国が8カ国しかない」（1077万インプレッション、744名増）など、周辺ネタも活用しました。
*   「マイナンバーカードの名前とデザインが変わる」というネタは3回再投稿され、合計で1646名のフォロワー増加に貢献しています。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭文のインパクトと投稿の「型」が非常に重要です。てっぺい氏はアルゴリズムの変化に合わせて、投稿の「見せ方」を柔軟に変化させています。

### 2.1. 冒頭文の作り方：インパクト勝負
「書き出しが命」であり、読み手の興味を引き付けることが最優先です。

*   **断言・煽り・実績アピール**
    *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」といった強い言葉で、読み手の注意を一瞬で掴みます。
    *   例：「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という煽り気味の書き出しで、595万インプレッション、407名増を記録しました。
*   **具体的な数字や固有名詞の提示**
    *   「55億円」「地面師」「Netflix」「2017年」といった具体的な数字や固有名詞を冒頭に盛り込むことで、興味を惹きつけます（例：地面師事件のポストで368万インプレッション、1425名増）。
*   **読みやすさの追求**
    *   「読みやすく、文字は少なめになるようにして気になるところで切る」ことを意識し、リプへの誘導を促します。

### 2.2. 投稿の型：アルゴリズムの変化への対応
てっぺい氏は、アルゴリズムの変化に合わせて、図解ポストと文字ポストの組み合わせ方や、流行りの構文を積極的に取り入れています。

*   **「1枚目文字ポスト＋2枚目以降図解」の「ロールキャベツ系ポスト」**
    *   最近のXアルゴリズムは「リプに行ってもらう」ことを重視しているため、1枚目に図解を置くと伸びづらい傾向があります。
    *   **成功事例：**
        *   「図解ポストの最初を文字ポストに」（59万インプレッション、283名増）
        *   「会話調のポストで146万インプレッション」（148万インプレッション、95名増）
        *   「地面師事件」のポストは「会話調の軽いポスト」を1枚目にして、2枚目以降に有益な図解をつけることで「368万インプレッション、1425名増」を達成。
        *   過去に伸びなかった図解ポストも、1枚目を文字の会話ポストに変えて再投稿することで「204万インプレッション、170名増」と大きく伸びました。
    *   **目的：** 冒頭文で興味を引き、リプに誘導して図解を見てもらうことで、インプレッションとフォローの両方を狙います。
*   **流行りの構文の活用**
    *   「メダル構文」「会話構文」「◯×構文」「国旗構文」「Tier」「ランキング」など、流行りの構文を積極的に試しています。
    *   「流行りのメダルを使った構文」で、普段伸びなかった「個人向け国債 変動10年」のポストが「334万インプレッション、417名増」を記録しました。
    *   「会話構文＋箇条書き＋図解」の組み合わせも有効です（例：ワールドカップネタで532万インプレッション、315名増）。
*   **文字ポストと図解ポストの使い分け**
    *   「図解の方がわかりやすいこと」は図解で伝えるという本質は変えませんが、インプレッションを伸ばすためには文字ポストも有効です。
    *   「難しいことをわかりやすく解説するポスト」は図解が適していますが、「Xの収益を伸ばす」目的でインプレッションを重視する場合は文字ポストも選択肢に入ります。
    *   てっぺい氏は「飽きを嫌う傾向」があるXにおいて、同じようなポストや構文ばかりでなく、文字と図解を使い分けることを推奨しています。
*   **漫画ポストの活用**
    *   「バレンタインの漫画ポスト」（240万インプレッション、586名増）のように、文字ポストで伸び悩んだネタも、漫画にすることで「よみがえる」ことがあります。
    *   ChatGPTでシナリオを作成し、専用ツールで簡単に漫画を作成できるため、発信の幅が広がります。
*   **1秒動画の添付**
    *   X社が動画を優遇しているため、ポストに「赤い矢印が点滅する1秒動画」を添付することで、インプレッションが爆発的に伸びる効果があります（例：マイナンバーカードのポストで595万インプレッション、407名増）。

### 2.3. 図解のデザインと情報量
図解は「パッと見でなんのポストかわかるようにする」ことが重要です。

*   **視覚的インパクト**
    *   「アルファードのイラストを大きく」するなど、メインテーマを視覚的に強調します。
    *   「トランプ大統領、高市首相のイラストは反応が良い」という経験則も。
*   **情報量の調整**
    *   「最初のポストにつける図解の情報量は、少し少なめにして、誘導に持っていった方が良い」という検証結果があります。リプで詳細を解説する構成が効果的です。
*   **知っているものとつなげる**
    *   「残クレアルファード」のポストで「通常のローンとの比較」を入れることで、読者が内容を理解しやすくなります。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

### 3.1. インプレッションを伸ばす投稿の傾向
インプレッションは、Xの収益に直結するため、てっぺい氏も重視しています。

*   **トレンド・時事ネタ**
    *   「マイナンバーカードの名前とデザイン変更」（595万インプレッション）、「ワールドカップネタ」（1077万インプレッション）など、タイムリーな話題は圧倒的なインプレッションを叩き出します。

    *   「メダル構文」「会話構文」「1秒動画」など、アルゴリズムに優遇される見せ方を活用すると、インプレッションが大きく伸びます。
    *   例：「個人向け国債 変動10年」は、メダル構文の力を借りて「334万インプレッション」を記録。

    *   1枚目を文字ポストにしてリプに誘導する構成は、インプレッションを伸ばす上で非常に有効です。

### 3.2. フォロワー増加につながる投稿の傾向
フォロワー増加は、アカウントの成長と長期的な影響力に繋がります。

*   **「とっつきづらいけど、ちょっと知っておいた方がいい」有益な解説**
    *   「選挙の『青木率』解説」（234万インプレッション、1581名増）、「エプスタイン事件解説」（144万インプレッション、1652名増）など、難解な情報をわかりやすく解説するポストは、読者の「知りたい」欲求を満たし、フォローに繋がりやすいです。
    *   「ニュース解説」は「めんどくさそうだけど、ざっくり知っておいた方が良い」というニーズに応え、フォロー率が高い傾向にあります。
*   **「図解ポスト」の活用**
    *   てっぺい氏自身、「13万フォロワーを達成した最大の秘密はズバリ『図解ポスト』」と断言しています。
    *   「図解を使った方がフォローいただく数は多くなる印象」と述べており、特に「図解の方がわかりやすいこと」を図解で説明するポストはフォロワー増加に貢献します。
    *   例：「高校受験の名門高校」の図解ポストは「1ポストで44,654名増加」という驚異的な実績を誇ります。
*   **トレンドに乗った「ニュース解説」**
    *   フォロワー1000名以上増加ポスト5本はすべて「トレンドにのっている」「ニュース解説」「すべて図解ポスト」という共通点がありました。特に「海外のニュースが多い」という特徴も指摘されています。
*   **「自分ごと化」しやすい地域・生活関連ネタ**
    *   「都道府県別のショッピングセンター」（194万インプレッション、7,428名増）や「関東の家賃比較」（826万インプレッション、10,666名増）のように、読者が自身の生活や地域と関連付けて考えられるネタは、フォローに繋がりやすいです。
*   **質の高い一次情報・深い洞察**
    *   「自分で学んだことを発信する」楽しさが、結果的に質の高い情報提供となり、フォロワー増加に繋がります。

### 3.3. インプレッションは伸びたがフォロワーは減った事例
この示唆的な事例は、発信軸の重要性を浮き彫りにします。

*   **発信軸とのズレ**
    *   例：「女子アナフリー転向年収ランキング」（92万インプレッション、30名減）や、テーマ不明のポスト（113万インプレッション、69名減）は、てっぺい氏の普段の発信軸である「お金・お得情報」や「ニュース解説」から外れたことがフォロワー減少の要因と分析されています。
    *   インプレッションを伸ばすことは「アカウントを育てる」意味で悪くないものの、フォロワー増加には軸との整合性が求められます。
*   **エンタメ寄りすぎた内容**
    *   「生類憐れみの令」のような「有益と見せかけてネタ」のポストは、インプレッションは伸びても、フォロワー増加には繋がりにくい場合があります（Xで75万インプレッション、510名増、インスタで3195名増と、インスタでは伸びた例外もあり）。
*   **Xの凍結やアルゴリズムの変化**
    *   てっぺい氏自身、「毎日基本的にフォロワー様は減ってる」「Xの凍結も増えている」と述べており、外部要因によるフォロワー減少も考慮する必要があります。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

### 4.2. 刺さらなかった理由・反省点（失敗からの原則）

1.  **発信軸とのズレ**
    *   インプレッションは伸びても、普段の発信軸と大きく異なるテーマ（例：女子アナ年収ランキング）は、フォロワー増加に繋がりにくく、むしろ減少する可能性があります。
    *   「一般的には、発信軸からズレてるといいねやインプレッションは伸びてもフォローはされない」という原則を再確認しています。

    *   「1枚目の図解に文字を多く入れすぎた」ポスト（例：為替介入の解説）は、リプへの誘導がうまくいかず、インプレッションが伸び悩みました。
    *   冒頭はシンプルに、興味を引くことに特化し、詳細はリプで展開する構成が望ましいです。
3.  **テーマの「自分ごと化」の弱さ**
    *   「為替介入」のように、読者が「自分とは関係なさそうに感じる」テーマは、たとえ分かりやすく解説しても、広くは響きにくい傾向があります。
    *   「関東だけなので全国を網羅してない」家賃比較のポスト（81万インプレッション、1584名増）も、「自分ごと化が弱くなる」ため、思ったほど伸びなかったと分析されています。全国規模のテーマの方が強いです。
4.  **図解の質とオリジナリティの欠如**
    *   「日本地図がうまく作成できない」など、図解の質が低いと、せっかく良いネタでも効果が半減します。てっぺい氏は「きちんとした図解を作れば必ず伸びると思っていた」ため、2〜3時間かけてCanvaで自作する努力を惜しみませんでした。
    *   「誰か別な人が発信していて伸びてるものをやる」のは極力避け、オリジナリティを追求することが重要です。
5.  **アルゴリズムの変化への対応遅れ**
    *   「図解を最初のポストにつけると伸びづらくなってる」というアルゴリズムの変化に気づかず、過去の成功体験に固執すると、伸び悩むことがあります。常に最新のトレンドを意識し、見せ方を変える柔軟性が必要です。
6.  **ネタの「鮮度」の喪失**
    *   「以前に一度発信したことがあったのですが伸びなかった」ナフサのポストのように、インパクトが弱いと、同じネタでも伸びません。新しい切り口や、トレンドとの組み合わせが必要です。
7.  **用語の簡単すぎ・少なすぎ**
    *   「用語が簡単すぎた」「用語が8つしかないのは少な過ぎた」投資用語のポストは、インプレッションはあったものの、改善の余地があると反省しています。ターゲット層の知識レベルに合わせた情報量と深さが求められます。
