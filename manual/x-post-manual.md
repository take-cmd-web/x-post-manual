# X投稿マニュアル

X(旧Twitter)運用の専門家であるてっぺい氏のメルマガ群を横断分析し、再現性のあるX投稿の原則と具体的な手法をまとめました。てっぺい氏が13万フォロワーを達成した秘訣は、「図解ポスト」を軸に、時流に合わせた投稿形式やネタ選び、AIの活用を徹底している点にあります。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる傾向にあるのは、以下の法則に基づいたネタ選びがされているためです。

### 1-1. 「なんとなく聞いたことあるけど、よくわからない」テーマを優しく解説する
多くの人が興味はあるものの、難解でとっつきにくいと感じているテーマを、わかりやすく解説することで高いエンゲージメントとフォロワー増に繋がります。
*   **成功事例1：政治・時事ネタの解説**
    *   「国会の冒頭解散、選挙の『青木率』」（メルマガ1）：**234万インプレッション、1581名増**。政治的なネタだが、情報をわかりやすく提供し「とっつきづらいけど、ちょっと知っておいた方がいい」という需要に応えた。
    *   「闇が深いエプスタイン事件」（メルマガ4, 33）：**144万インプレッション、1652名増**（メルマガ4）。「なんとなく聞いたことあるけどよくわからない」というテーマに、トランプ大統領や陰謀論的要素を絡めたことで、非常に興味を引いた。
    *   「残クレアルファード」（メルマガ30）：**65万インプレッション、532名増**。「よく聞くけどよくわからない、ちょっと気になること」というテーマ設定が奏功。
    *   「為替介入」（メルマガ11）：**7万インプレッション、90名増**。インプレッションは伸びなかったものの、「わかりやすい」と評価されフォロワー増に繋がった。

### 1-2. トレンド・時事ネタを積極的に取り入れる（特に海外ニュース）
Xはリアルタイム性が重視されるため、トレンドワードや最新のニュースをいち早く解説する投稿はインプレッションとフォロワー増の両方に貢献します。特に海外のニュースは、日本のメディアでの取り扱いが少ないため、独自性が出やすい傾向があります。
*   **成功事例1：海外メディアの立ち位置**（メルマガ26）：**184万インプレッション、2951名増**。ポッドキャストで「CNNは左寄り」という話から着想し、「海外メディアは立ち位置を明確にしてるので、見るときは知っておいた方がいい」という有益情報を提供。
*   **成功事例2：UAEのOPEC脱退**（メルマガ8, 12）：**60万インプレッション、2010名増**（メルマガ12）。娘から聞いたニュースがトレンドワードになっていたため、即座に発信。
*   **成功事例3：イラン攻撃報道**（メルマガ8）：**2951名増**。トレンドに乗ったニュース解説。
*   **成功事例4：ナフサ不足**（メルマガ10）：**182万インプレッション、603名増**。トレンドワードに「ナフサ不足」があった際、ポテトチップスの白黒袋というインパクトのあるニュースと結びつけ発信。以前伸びなかったネタも、インパクトとトレンドを組み合わせることで成功した。
*   **成功事例5：韓国大統領の逮捕**（メルマガ27）：**78万インプレッション、447名増**。「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問をトレンドに乗せて解説。

### 1-3. 固有名詞や数字、インパクトのある言葉を効果的に使う
具体的な固有名詞（人物名、企業名、事件名など）や数字は、ユーザーの目を引き、興味を喚起する強力な要素です。
*   **成功事例1：女子アナのフリー転向・年収ランキング**（メルマガ18）：**92万インプレッション**。「女子アナ」「フリー転向」「年収」という下世話なネタを盛り込み、インプレッションを大きく伸ばした。ただし、発信軸とズレたためフォロワーは30名減。
*   **成功事例2：マイナンバーカード**（メルマガ36）：**595万インプレッション、407名増**。「マイナンバーカードがなくなることを知らない人が多すぎる」という煽り気味の書き出しで強いインパクトを与えた。
*   **成功事例3：冒頭文の型**（メルマガ2, 35）：
    *   「断言します」
    *   「これを知らないと大損します」
    *   「私コレで月10万円得しました」
    などの言葉で、読み手の興味を引き付ける。

### 1-4. 一次情報や自身の経験・学びを共有する
自身が「そうなんだ」「学んだこと」と感じたことをわかりやすく発信することは、楽しんで継続できる秘訣であり、結果的にオリジナリティのある有益な情報となります。
*   **成功事例1：ホテル業界の知識**（メルマガ9）：**60万インプレッション、206名増**。元ホテル勤務の経験から「ゴールデンウィーク明けはホテルが一番空く時期」というタイムリーで意外な情報を発信。
*   **成功事例2：為替介入の学び**（メルマガ11）：**7万インプレッション、90名増**。自分が理解していなかった「為替介入」について調べ、わかりやすく解説したポスト。伸びは控えめだが、フォロワー増に繋がり「わかりやすい」と評価された。
*   **成功事例3：妻のパート探しから得た知識**（メルマガ7）：**170万インプレッション、307名増**。「あまり働きたくない妻が今、パートを探してます」というリアルな体験から、社会保険の扶養について調べ発信。

### 1-5. AIを活用してネタを深掘り・効率化する
複数のAIツール（ChatGPT, Gemini, Perplexity, Grok, Claude）を使い分け、リサーチや情報整理の時間を大幅に短縮しています。
*   **活用例1：情報収集とまとめ**（メルマガ10, 12, 14, 20, 22, 26）：複数のAIに同じ質問を投げかけ、それぞれの良い部分を組み合わせたり、特定のAIのユニークな視点を取り入れたりして、内容を充実させている。
*   **活用例2：リサーチ時間の短縮**（メルマガ12）：以前は30分以上かかっていたリサーチが、AIの活用により圧倒的に短縮され、発信したいことをタイムリーに発信できるようになった。
*   **失敗事例：AIによるネタ出し**（メルマガ13）：AIに過去の伸びたポストを分析させてネタ出しを試みたが、20個の候補から「いいかも」と思えるネタは1つのみで、そのポストも**24万インプレッションで10名減**という結果に。「ネタ選びにAI、使えるのかもしれないけどやり方はもう少し考えなくては」と反省している。

## 2. 投稿の構成・型

てっぺい氏の投稿は、ユーザーの流し読みを意識し、冒頭で興味を引き、リプ（返信スレッド）への誘導を重視する構成が特徴です。

### 2-1. 冒頭文のインパクトを最大化する
Xは「流し読みされる媒体」であり、「冒頭のインパクト勝負」です。読み手の興味を引き付ける強い言葉を使い、スクロールを止めさせることが重要です。
*   **原則1：断言・煽り・具体的な数字で興味を引く**（メルマガ2, 35）
    *   「断言します」
    *   「これを知らないと大損します」
    *   「私コレで月10万円得しました」
    *   「『マイナンバーカード』がなくなることを知らない人が多すぎる。」（メルマガ36）
*   **原則2：アンチを恐れない**（メルマガ36）
    *   煽り気味の文言はアンチのリプを増やすこともあるが、それは「チャンス」であり、ポストの拡散に繋がるため、よほど炎上しない限り恐れる必要はない。

### 2-2. 投稿形式の使い分けとリプへの誘導
図解ポストが基本軸ですが、アルゴリズムの変化に合わせて文字ポストや動画、漫画など多様な形式を試しています。共通するのは「いかにリプに行ってもらうか」を意識した構成です。

*   **図解ポスト（基本軸）**
    *   「13万フォロワーを達成した最大の秘密はズバリ『図解ポスト』」（メルマガ5）。「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
    *   **「Nano Banana Pro」**を活用することで、高品質な図解を高速で作成し、発信のハードルを劇的に下げている（メルマガ1, 5, 12, 16, 21, 23, 26, 30, 32, 33, 34, 37）。
    *   図解は「パッと見でなんのポストかわかるようにする」ことが重要（メルマガ30）。例として、残クレアルファードのポストでは「アルファードのイラストを大きくした」。
    *   「知ってるものとつなげる」ことで、よりわかりやすく説明する（メルマガ30）。例として、残クレアルファードのポストで通常のローンとの比較を入れた。

*   **1枚目文字ポスト＋2枚目以降図解（最新トレンド）**
    *   最近のアルゴリズムは「リプに行ってもらう」ことを重視しているため、1枚目に図解を置くと伸びづらい傾向がある（メルマガ3, 7, 14, 15, 26）。
    *   1枚目を文字にして、リプに誘導し、2枚目以降で図解を見せる構成が有効。
    *   1枚目の文字は「メダル構文」や「会話構文」が良い（メルマガ3, 6, 7）。
        *   **成功事例1：メダル構文＋個人向け国債**（メルマガ6）：**334万インプレッション、417名増**。普段伸びなかった有益な内容を、流行りのメダル構文の力を借りて多くの人に届けた。
        *   **成功事例2：会話ポスト＋社会保険の扶養**（メルマガ7）：**170万インプレッション、307名増**。会話は極力シンプルに、気になるところで切ってリプへ誘導。
    *   最初のポストの図解の情報量は少なめにして、リプに誘導する（メルマガ26）。

*   **漫画ポスト**
    *   文字ポストを漫画化することで、大幅にインプレッションとフォロワー数を伸ばせる可能性がある（メルマガ29）。
    *   **成功事例：バレンタインの文字ポストを漫画化**（メルマガ29）：
        *   文字ポスト時：**7.4万インプレッション、34名減**。
        *   漫画化後：**240万インプレッション、586名増**。
    *   ChatGPTに文字ポストを読み込ませて漫画のシナリオを作成できる。

*   **動画の活用**
    *   X社は動画を優遇しており、「1秒動画」はインプレッションを爆発的に伸ばす有効なテクニック（メルマガ36）。
    *   **成功事例：マイナンバーカードのポスト**（メルマガ36）：**595万インプレッション、407名増**。赤い矢印が点滅する1秒動画を添付したことで、インプレッションが大きく伸びた。

### 2-3. 投稿の使い回し（再投稿）
一度反応の良かったポストは、時期を置いて何度も再投稿することで、継続的にインプレッションとフォロワーを獲得できます。
*   **原則：費用対効果が高い**（メルマガ36）
    *   「当たるか分からないポストを闇雲に投稿し続けるなんて費用対効果が悪過ぎる」。
    *   「反応が出るポストは1ヶ月置けば同じような反応が出る」。
*   **成功事例：マイナンバーカードのポスト**（メルマガ36）：
    *   1回目：**655万インプレッション、1114名増**
    *   2回目：**213万インプレッション、125名増**
    *   3回目：**595万インプレッション、407名増**
    *   合計で**1646名**のフォロワー増に貢献。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも連動せず、それぞれ異なる要因で伸びる傾向があります。

### 3-1. インプレッションを伸ばす投稿の傾向
*   **冒頭文のインパクトと煽り文句**（メルマガ2, 35, 36）：
    *   「断言します」「これを知らないと大損します」「マイナンバーカードがなくなることを知らない人が多すぎる」など、強い言葉でユーザーの目を引きつける。
*   **1秒動画の活用**（メルマガ36）：
    *   X社が動画を優遇しているため、1秒の動画を添付するだけでインプレッションが爆発的に伸びる。
    *   例: 「マイナンバーカード」のポストで**595万インプレッション、407名増**。
*   **流行りの構文の活用**（メルマガ6, 7）：
    *   メダル構文や会話構文など、Xで流行している形式を取り入れることで、アルゴリズムに乗りやすくなる。
    *   例: メダル構文を使った「個人向け国債」のポストで**334万インプレッション、417名増**。
*   **「東スポ要素」の強い下世話なネタ**（メルマガ18）：
    *   多くの人の興味を引くゴシップ性の高いネタはインプレッションを稼ぎやすい。
    *   例: 「女子アナのフリー転向・年収ランキング」で**92万インプレッション**を記録。ただし、フォロワーは30名減。
*   **文字ポストの傾向**（メルマガ3, 8, 14）：
    *   最近は図解よりも文字ポストの方がインプレッションが伸びやすい傾向がある。X収益を狙う場合は文字ポストも有効。

### 3-2. フォロワー増につながる投稿の傾向
*   **発信軸との合致と有益性**（メルマガ1, 6, 17, 18）：
    *   インプレッションを伸ばすだけではフォロワー増には繋がりにくい。ユーザーが「有益」と感じ、かつ発信者の専門性や軸と合致している内容がフォローに繋がりやすい。
    *   例: 「政治系の解説」はてっぺい氏の軸（お金・お得情報）から少し外れるが、「とっつきづらい話を優しく解説」という点で有益性が高く、フォロワー増に繋がりやすい（メルマガ1）。
    *   **示唆的な事例1：発信軸とのズレによるフォロワー減**
        *   「女子アナのフリー転向・年収ランキング」（メルマガ18）：**92万インプレッション**と大きく伸びたが、発信軸とのギャップから**フォロワーは30名減**。
        *   「お金・お得情報」でも「ニュース解説」でもないテーマ（メルマガ17）：**113万インプレッション**と伸びたが、**フォロワーは69名減**。
*   **「とっつきづらいけど、ちょっと知っておいた方がいい」情報の優しい解説**（メルマガ1, 12, 23, 30）：
    *   ユーザーの知的好奇心を満たし、学びを提供することで信頼を獲得し、フォローに繋がる。
    *   例: 「エプスタイン事件」（メルマガ4）：**144万インプレッション、1652名増**。
    *   例: 「海外メディアの立ち位置」（メルマガ26）：**184万インプレッション、2951名増**。
    *   例: 「UAEのOPEC脱退」（メルマガ12）：**60万インプレッション、2010名増**。
*   **図解ポストの活用**（メルマガ5, 8, 37）：
    *   「図解ポスト」はフォロワー増加の最大の秘密とされており、視覚的なわかりやすさがフォローに直結する。
    *   「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
*   **トレンドに乗ったニュース解説**（メルマガ8, 10）：
    *   タイムリーで有益な情報提供は、フォロワー増に大きく貢献する。
    *   例: 5本のトレンドニュース解説ポストで合計**10,326名増**（メルマガ8）。
*   **「わかりやすい」と感じてもらえる内容**（メルマガ11）：
    *   インプレッションが低くても、内容が「わかりやすい」と評価されればフォローに繋がる。
    *   例: 「為替介入」のポストは**7万インプレッション**と控えめだったが、**90名増**。

### 3-3. インプレッションとフォロワー増の乖離
*   **フォロワーは毎日減る傾向**（メルマガ13, 17, 18）：
    *   「基本的に、毎日フォロワー数は減る」ため、その日のポストでそれを上回る数のフォローを獲得しないと、フォロワー数は減少する。Xの凍結増加も影響している可能性がある。
*   **示唆的な事例2：AIによるネタ出しポスト**（メルマガ13）：
    *   AIに過去の伸びたポストを分析させてネタ出ししたポストは**24万インプレッション**とまずまずだったが、**フォロワーは10名減**。ネタ選びのAI活用にはまだ課題があることを示唆。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗の分析から、再現性のある原則を抽出します。

### 4-1. 刺さった理由（成功原則）
1.  **「なんとなく知りたい」欲求への対応:**
    *   多くの人が「なんとなく聞いたことはあるけど、よくわからない」と感じているテーマを、専門的すぎず、かつ正確に「やさしく解説」することで、幅広い層の知的好奇心を刺激し、共感を得る。
    *   **例:** エプスタイン事件、残クレアルファード、為替介入、韓国大統領の逮捕など。
2.  **時事性・トレンドとの融合:**
    *   Xのリアルタイム性を最大限に活用し、話題のニュースやトレンドワードと関連付けて情報を発信する。特に、日本のメディアで取り扱いが少ない海外の時事ネタは、独自性と希少価値を生む。
    *   **例:** 国会冒頭解散、イラン攻撃報道、UAEのOPEC脱退、ナフサ不足など。
3.  **視覚的なわかりやすさ（図解・漫画・動画）:**
    *   複雑な情報を「図解」で簡潔かつ視覚的に表現することで、流し読みされやすいXにおいてユーザーの理解を深める。Nano Banana Proなどのツールで図解作成のハードルが下がった今、ネタ選定の重要性が増している。
    *   文字ポストを漫画化したり、1秒動画を添付したりと、多様な表現形式で飽きさせない工夫も重要。
    *   **例:** バレンタインの文字ポストを漫画化で大成功、マイナンバーカードの1秒動画。
4.  **冒頭文のフックとリプへの誘導設計:**
    *   「断言します」「これを知らないと大損します」といった煽りや具体的な数字、固有名詞で冒頭のインパクトを最大化し、ユーザーの目を引きつける。
    *   最初のポストで全てを語らず、リプ（スレッド）に誘導する構成は、Xのアルゴリズムに評価されやすい。
    *   **例:** 1枚目を文字ポスト、2枚目以降を図解にするハイブリッド型。
5.  **一次情報・実体験に基づく発信:**
    *   自身が「学びになった」「面白い」と感じたことを発信することで、オリジナリティと熱量が伝わりやすくなる。これは発信を継続するモチベーションにも繋がる。
    *   **例:** 元ホテル勤務の経験からの情報、妻のパート探しから得た社会保険の知識。
6.  **投稿の「使い回し」と「見せ方の変更」:**
    *   一度成功したポストは、見せ方を変えたり、時期を置いたりして再投稿することで、継続的に効果を得られる。Xは「飽きを嫌う傾向」があるため、同じネタでも見せ方を変える工夫が有効。
    *   **例:** マイナンバーカードのポストの複数回再投稿、文字ポストの図解化・漫画化。

### 4-2. 刺さらなかった理由（失敗・反省点）
1.  **発信軸との大きなズレ:**
    *   インプレッションは稼げても、アカウントの専門性や主要テーマと大きく異なる内容は、フォロワーの獲得や維持に繋がりにくい。
    *   **例:** 「女子アナのフリー転向・年収ランキング」（92万インプレッションで30名減）、「お金・お得情報」でも「ニュース解説」でもないテーマ（113万インプレッションで69名減）。
2.  **1枚目の情報過多:**
    *   最初の図解に文字を多く入れすぎると、ユーザーがリプ（スレッド）に進む前に離脱してしまう可能性がある。リプへの誘導を意識し、1枚目の情報は簡潔にまとめるべき。
    *   **例:** 「為替介入」のポストで「1枚目の図解に文字を多く入れすぎた」ことを反省点として挙げている（メルマガ11）。
3.  **ネタのインパクト不足（再投稿時）:**
    *   同じネタでも、インパクトが弱いと伸び悩む。特に再投稿の際は、時流に合わせたインパクトのある切り口や見せ方の工夫が必要。
    *   **例:** 以前伸びなかった「ナフサ不足」のポストは、ポテトチップスの白黒袋というインパクトを加えて再投稿し成功した（メルマガ10）。
4.  **AIによるネタ出しの限界:**
    *   AIは情報収集や構成の効率化には優れるが、ユーザーの心を掴む「ネタの選定」においては、まだ人間の判断が必要な場合がある。
    *   **例:** AIにネタ出ししてもらったポストでフォロワーが減少した事例（メルマガ13）。
5.  **アルゴリズムハック的な構文のみに依存:**
    *   流行りの構文はインプレッションを伸ばす効果があるが、内容が伴わないとフォローに繋がりにくい傾向がある。「有益」だと感じられる内容と組み合わせることが重要。
    *   **例:** メダル構文は「ややアルゴリズムをハックしてる感がある」ため、インプレッションは伸びるがフォローされにくい傾向がある（メルマガ6）。

### 4-3. 長期的な視点
*   **Xは長距離走**（メルマガ17）：
    *   一喜一憂せず、コツコツと発信を続けることが重要。焦らず、自身のペースで「楽しむ」ことを意識する。

## 5. 投稿前チェックリスト

てっぺい氏の成功法則に基づき、投稿前に確認すべき具体的な項目をまとめました。

### 5-1. ネタ・テーマに関するチェック
*   [ ] **「なんとなく聞いたことあるけど、よくわからない」テーマか？** (例: エプスタイン事件、残クレ)
*   [ ] **トレンドや時事ネタに乗っているか？** (特に海外ニュースは独自性が出やすい)
*   [ ] **固有名詞や数字を効果的に使っているか？** (例: トランプ大統領、月10万円)
*   [ ] **自身の経験や学びから得た一次情報か？** (オリジナリティと熱量が伝わるか)
*   [ ] **「有益」だと感じる内容か？** (見る人が「知っておいてよかった」と思うか)
*   [ ] **発信軸と大きくズレていないか？** (インプレッション優先の場合は例外あり)
*   [ ] **過去に伸びたポストの「見せ方を変えて」再投稿できないか？** (図解化、漫画化など)
*   [ ] **AI（ChatGPT, Gemini等）でリサーチ・情報整理を効率化したか？**

### 5-2. 投稿の構成・型に関するチェック
*   [ ] **冒頭文はインパクトがあるか？** (例: 「断言します」「これを知らないと大損します」「〜を知らない人が多すぎる」などの煽り文句)
*   [ ] **1枚目のポストはリプに誘導する構成か？** (文字ポスト、情報量少なめなど)
*   [ ] **1枚目の文字ポストは「メダル構文」や「会話構文」など、流行りの型を使っているか？**
*   [ ] **図解は「パッと見で何かわかる」デザインか？** (大きなイラスト、簡潔なタイトルなど)
*   [ ] **図解は「知っているものとつなげて」わかりやすくしているか？** (例: ローンとの比較)
*   [ ] **1秒動画を添付しているか？** (インプレッションを伸ばしたい場合)
*   [ ] **内容が「やさしく解説」されており、読みやすいか？** (専門用語の多用を避け、平易な言葉で)
*   [ ] **リプ（スレッド）に続く内容が、ユーザーの興味を引き続けるか？** (続きが気になる構成か)

### 5-3. 投稿後の運用に関するチェック
*   [ ] **投稿後30分〜60分はリプへの返信を早く行う準備はできているか？** (交流がアルゴリズムで重視される)
*   [ ] **他のSNS（Instagram, Threads, TikTok, YouTubeショート）への展開を考慮しているか？** (特に図解は動画化して流用可能)
*   [ ] **楽しく発信できる内容か？** (継続のために重要)
