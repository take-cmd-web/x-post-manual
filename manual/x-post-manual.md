# X投稿マニュアル

X(旧Twitter)でフォロワー13万人を達成した「てっぺい」氏の成功事例と考察に基づき、再現性のある投稿マニュアルを作成しました。インプレッションとフォロワー増加のメカニズムを理解し、効率的かつ効果的なX運用を目指しましょう。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる最大の要因は、**「ネタの選定」**にあります。以下の法則を意識してテーマを選びましょう。

### 1-1. 「なんとなく聞いたことあるけど、よくわからない」を優しく解説する
多くの人が興味はあるものの、調べるのが面倒だと感じるテーマは、高い需要があります。
*   **事例:**
    *   **選挙の「青木率」解説**（メルマガ1）：234万インプレッション / 1581名増。「とっつきづらいけど、ちょっと知っておいた方がいいよな」という政治系テーマを優しく解説。
    *   **エプスタイン事件解説**（メルマガ4, 32, 33）：144万インプレッション / 1652名増（最終）。「なんとなく聞いたことあるけどよくわからない」闇の深い事件。
    *   **「残クレ」アルファード解説**（メルマガ30）：65万インプレッション / 532名増。「よく聞くけどよくわからない、ちょっと気になること」をテーマに。
    *   **UAEのOPEC脱退解説**（メルマガ12）：60万インプレッション / 2010名増。「聞いたことある、大切そう、でもよくわからない」を満たす。
    *   **韓国大統領の逮捕理由解説**（メルマガ27）：78万インプレッション / 447名増。「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問に答える。

### 1-2. トレンド・時事ネタを捉える（特に海外ニュース）
タイムリーな話題はインプレッションとフォロワー増加の両方に大きく寄与します。特に海外のニュースは競合が少ないため狙い目です。
*   **事例（フォロワー1000名以上増加ポスト5本）**（メルマガ8より）：
    *   **1/23 高市首相の解散総選挙**：1581名増
    *   **2/3 エプスタイン事件**：1652名増
    *   **3/2 海外メディアのイラン攻撃報道**：2951名増
    *   **3/15 中東情勢の解説**：1075名増
    *   **4/29 UAEがOPECを脱退**：3067名増
    *   これらのポストは全て「トレンドに乗っている」「ニュース解説」「図解ポスト」「海外のニュースが多い」という共通点があります。
*   **その他の事例:**
    *   **ナフサ不足とポテトチップス**（メルマガ10）：182万インプレッション / 603名増。トレンドワード「ナフサ不足」とインパクトのあるニュース（ポテチの白黒袋）を組み合わせ。
    *   **マイナンバーカードの名前とデザイン変更**（メルマガ36）：初回655万インプレッション / 1114名増。来年変わるという時事ネタ。

### 1-3. 自身の一次情報や本業の知識を活かす
誰もが知らない「意外な常識」は、有益な情報として評価されます。
*   **事例:**
    *   **ゴールデンウィーク明けのホテルが空く時期**（メルマガ9）：60万インプレッション / 206名増。ホテル勤務経験からのタイムリーな情報。
    *   **妻のパート探しと社会保険の扶養**（メルマガ7）：170万インプレッション / 307名増。リアルな実体験に基づく情報。

### 1-4. インパクトのある固有名詞や数字、下世話なネタ（東スポ要素）
人々の好奇心を刺激する要素は、インプレッションを大きく伸ばします。
*   **事例:**
    *   **女子アナフリー転向年収ランキング**（メルマガ18）：92万インプレッション / 30名減。「女子アナ」「フリー転向」「年収」という下世話なネタを盛り込み、インプレッションは大きく伸びた。
    *   **トランプ大統領、高市首相のイラスト**（メルマガ30）：反応が良い傾向。
    *   **「マイナンバーカード」**（メルマガ36）：固有名詞と「なくなる」というインパクト。

### 1-5. AIを活用したネタ出しとリサーチ
AIはネタ出しの候補を広げ、リサーチ時間を大幅に短縮します。
*   **活用例:** ChatGPT, Gemini, Perplexity, Grok, Claudeなど複数のAIに同じプロンプトを投げかけ、回答を比較・統合してコンテンツを作成（メルマガ10, 12, 14, 15, 20, 22, 26, 30）。
*   **注意点:** AIが出したネタでも、最終的な選定は自身の判断で行う。「AIにネタ出しさせたポスト」でフォロワーが10名減った事例（メルマガ13）もあり、AIの提案を鵜呑みにせず検証が必要です。

### 1-6. 失敗から学ぶネタ選びの反省点
*   **「自分とは関係なさそう」なテーマは伸びづらい:** 「為替介入」のポストは、自身は勉強になったものの「自分とは関係なさそう」と感じる人が多く、7万インプレッション / 90名増と伸び悩んだ（メルマガ11）。
*   **発信軸とのズレはフォロワー減少に繋がる:** インプレッションは伸びても、普段の発信軸と大きく異なるテーマはフォロワー減少の原因になることがあります。
    *   **女子アナ年収ランキング**（メルマガ18）：92万インプレッション / 30名減。発信軸とのギャップが原因。
    *   **お金・お得情報でもニュース解説でもないポスト**（メルマガ17）：113万インプレッション / 69名減。発信軸とのズレが原因。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭のインパクトと、読み手を惹きつける構成が重要です。

### 2-1. 冒頭文の作り方（インパクト勝負）
てっぺい氏が最重要視する要素の一つです。
*   **原則:** 読み手の興味を引き付け、スクロールを止めさせる強い言葉を使う。
*   **具体的な表現例**（メルマガ2, 35より）：
    *   「断言します」
    *   「これを知らないと大損します」
    *   「私コレで月10万円得しました」
    *   「マイナンバーカードがなくなることを知らない人が多すぎる。」（メルマガ36）のような「あおり気味の文言」も有効。アンチのリプは拡散のチャンスと捉える。
*   **効果:** 冒頭文を変えるだけで、インプレッションやいいね数が数倍になったケースを多数経験（メルマガ2, 35）。

### 2-2. 投稿の型：文字ポストと図解ポストの使い分け
てっぺい氏の基本は「図解ポスト」ですが、最近のアルゴリズムの変化に対応したハイブリッド型も試行しています。
*   **図解ポストの重要性:**
    *   てっぺい氏が13万フォロワーを達成した最大の秘密は「図解ポスト」（メルマガ5）。
    *   「難しいことをわかりやすく解説するポスト」には図解が最適（メルマガ8）。
    *   Nano Banana Proなどのツールを活用することで、図解作成のハードルが劇的に低下（メルマガ1, 5, 12, 16, 21, 26, 30, 32）。
    *   図解はInstagramなど他のSNSへの流用も容易で、効率的な運用が可能（メルマガ16, 19, 25, 28, 29）。
*   **文字ポストの活用:**
    *   最近の傾向として、図解よりも文字ポストの方がインプレッションが伸びやすいと感じている（メルマガ3, 8）。
    *   Xの収益を伸ばすためには、インプレッションを重視し、文字ポストも活用する（メルマガ3, 8）。
*   **ハイブリッド型（1枚目文字ポスト + 2枚目以降図解）:**
    *   「1枚目を文字ポストにして2枚目から図解にするポスト」を試行中（メルマガ3, 8）。
    *   1枚目の文字ポストには「メダル構文」や「会話構文」が有効（メルマガ3）。
    *   「日本が10人の村だったら」のポスト（メルマガ14）や投資の鉄板組み合わせポスト（メルマガ15）も、最初のポストを文字のみにしてリプ誘導を狙った。
    *   **会話ポスト:** 1枚目を会話形式の文字ポストにし、気になるところで切ってリプへ誘導する（メルマガ7）。極力シンプルに作成。

### 2-3. リプ誘導を意識した構成
現在のXアルゴリズムでは「リプに行ってもらう」ことが重視されています。
*   **原則:** 最初のポストの情報量をあえて少なめにし、詳細や図解はリプに回すことで、ユーザーのエンゲージメントを促す。
*   **事例:**
    *   「海外メディアの立ち位置」ポスト（メルマガ26）：イラン攻撃の報道の仕方まで一覧表に入れようとしたが、情報が多くなりすぎるためリプに回した。
    *   「ナフサ不足」ポスト（メルマガ10）：1枚目の画像は目に止まるようにし、難しいことは書かず、リプで「ナフサ」を解説。
    *   「為替介入」ポストの反省点（メルマガ11）：1枚目の図解に文字を多く入れすぎたため、リプに行ってもらえなかった可能性を指摘。

### 2-4. 画像・動画の活用
視覚的な要素は、ユーザーの目を引き、投稿の拡散力を高めます。
*   **1枚目の画像:** 「とにかく目に止まるようにしたいので、難しいことは書かず、ほぼ画像に」（メルマガ10）。イラストではなく、画像が良い場合もある。
*   **1秒動画:** 「赤い矢印が点滅する1秒動画」はインプレッションを爆発的に伸ばす有効なテクニック（メルマガ36）。X社が動画を優遇しているため。賛否両論あるが、伸びるネタを加速させるために活用する。
*   **パッと見でわかる図解:** 図解は「パッと見でなんのポストかわかるようにする」ことが重要（メルマガ30）。例: アルファードのイラストを大きくする。

### 2-5. 流行りの構文の活用
メダル構文、会話構文、◯×構文、国旗構文、Tier、ランキングなど、流行りの構文はインプレッションを伸ばすのに有効です。
*   **事例:**
    *   **メダル構文**（メルマガ6）：普段伸びなかった「個人向け国債」のポストを334万インプレッション / 417名増に押し上げた。
    *   **ランキング形式**（メルマガ18, 22）：女子アナ年収ランキングや歴代総理・大統領ランキングなど、続きが気になる形でインプレッションを伸ばす。
*   **原則:** 流行りの構文はアルゴリズムをハックする側面もあるが、内容が有益であればフォローにも繋がる（メルマガ6）。

### 2-6. 過去ポストの再投稿
一度伸びたポストは、時期を置いて何度も再投稿することで、継続的に効果を得られます。
*   **原則:** 「同じポストは何度も使い回してOK」（メルマガ36）。費用対効果が高く、運用が楽になる。
*   **事例:**
    *   **マイナンバーカードのポスト**（メルマガ36）：3回の投稿で合計1646名増加。初回655万インプレッション / 1114名増、2回目213万インプレッション / 125名増、3回目595万インプレッション / 407名増。
    *   **文字ポストの漫画化**（メルマガ29）：過去に伸びなかったバレンタインの文字ポスト（7.4万インプレッション / 34名減）を漫画化することで、240万インプレッション / 586名増と復活させた。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増加は異なる指標であり、それぞれを伸ばすための戦略も異なります。

### 3-1. インプレッションを伸ばす投稿の傾向
*   **インパクトと好奇心:**
    *   **「東スポ要素」の強い下世話なネタ**（メルマガ18）：女子アナフリー転向年収ランキングで92万インプレッションを記録。
    *   **あおり気味の書き出し**（メルマガ36）：マイナンバーカードのポストで初回655万インプレッション。
    *   **インパクトのある画像や1秒動画**（メルマガ36）：1秒動画の添付でインプレッションが爆発的に伸びる。
*   **流行りの構文:**
    *   **メダル構文**（メルマガ6）：個人向け国債のポストで334万インプレッション。
*   **トレンドワードとの組み合わせ:**
    *   **ナフサ不足とポテトチップス**（メルマガ10）：トレンドワードと視覚的インパクトで182万インプレッション。
*   **リプ誘導を意識した構成:**
    *   最初のポストで全てを語らず、リプに誘導する構成は、Xアルゴリズムに優遇されインプレッションが伸びやすい（メルマガ14, 26）。

### 3-2. フォロワー増加につながる投稿の傾向
*   **「有益性」と「わかりやすさ」:**
    *   **「なんとなく聞いたことあるけど、よくわからない」を「やさしく解説」する投稿**がフォロワー増加に直結します（メルマガ1, 4, 12, 27, 30）。
        *   例: 選挙の「青木率」解説（234万インプレッション / **1581名増**）
        *   例: エプスタイン事件解説（144万インプレッション / **1652名増**）
        *   例: UAEのOPEC脱退解説（60万インプレッション / **2010名増**）
        *   例: 海外メディアのイラン攻撃報道（184万インプレッション / **2951名増**）
    *   **図解ポスト**は難しい内容をわかりやすく伝えるのに最適であり、フォロワー増加に貢献する傾向があります（メルマガ5, 8）。
*   **発信軸との一貫性:**
    *   てっぺい氏の基本軸は「お金とお得情報」ですが、そこから少し外れた「政治系の解説」や「時事ネタ」も、わかりやすく解説することでフォロワー増加に繋がっています（メルマガ1）。
    *   ただし、発信軸と大きくズレた投稿は、インプレッションが伸びてもフォロワー減少に繋がるリスクがあります（後述）。
*   **特に海外のニュース解説:**
    *   フォロワー1000名以上増加したポスト5本中、多くが海外のニュース解説でした（メルマガ8）。競合が少なく、独自性を出しやすい可能性があります。

### 3-3. 「インプレッションは伸びたがフォロワーは減った」示唆的な事例
インプレッションとフォロワー増加は必ずしも連動しません。フォロワー減少の事例から、発信軸の一貫性の重要性がわかります。
*   **事例1: 女子アナフリー転向年収ランキング**（メルマガ18）
    *   **数値:** 92万インプレッション / 831いいね / **30名減**
    *   **考察:** 「女子アナ」「フリー転向」「年収」という下世話なネタでインプレッションは伸びたものの、普段の「お金とお得情報」「ニュース解説」という発信軸とのギャップが大きく、フォローに繋がらなかった。アカウントを育てる意味では悪くないが、フォロワー増加を狙う場合は注意が必要。
*   **事例2: AIにネタ出しさせたポスト**（メルマガ13）
    *   **数値:** 24万インプレッション / 416いいね / **10名減**
    *   **考察:** AIによるネタ出しは効率的だが、フォロワー増加に繋がる「有益性」や「独自性」が不足していた可能性。AIの提案をそのまま使うのではなく、自身のフィルターを通す重要性を示唆。
*   **事例3: お金・お得情報でもニュース解説でもないポスト**（メルマガ17）
    *   **数値:** 113万インプレッション / 1042いいね / **69名減**
    *   **考察:** 具体的なテーマは不明だが、発信軸から外れた投稿はインプレッションが伸びてもフォロワー減少に繋がりやすいことを示している。フォロワーは基本的に毎日減る傾向があるため、それを上回るフォローがないと減少する。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗の分析から、再現可能な原則を抽出します。

### 4-1. 刺さった理由（成功原則）
*   **知的好奇心を刺激する「やさしい解説」:**
    *   多くの人が「知りたいけど、難しそう」「なんとなく聞いたことあるけど、よくわからない」と感じるテーマを、専門用語を使わず、具体的な例え（例: 「日本が10人の村だったら」で経済を説明、メルマガ14）を用いてわかりやすく解説する。
    *   **事例:** 「青木率」「エプスタイン事件」「残クレアルファード」「UAEのOPEC脱退」「韓国大統領の逮捕理由」など。
*   **タイムリーな情報とトレンドの活用:**
    *   ニュースや時事ネタ、季節ごとの話題（例: GW明けのホテル、メルマガ9）など、今まさに人々が関心を持っているテーマは強く刺さります。
    *   特に、日本のメディアで取り扱いが少ない海外の大きなニュースは、独自の情報源として価値が高い（メルマガ4）。
*   **インパクトのある冒頭と視覚的訴求:**
    *   「書き出しが命」であり、強い言葉で興味を引きつける（メルマガ2, 35）。
    *   1枚目の画像や図解で「パッと見で何かわかる」ように工夫し、目を止める（メルマガ30）。
    *   1秒動画や漫画形式など、見せ方を変えることで飽きさせない（メルマガ29, 36）。
*   **一次情報・実体験の独自性:**
    *   自身の本業の知識や、個人的な経験・学び（例: 自分が為替介入を調べて理解したこと、メルマガ11）は、他にはない価値を提供し、共感を呼びます。
*   **AIによる効率的な情報収集と構成:**
    *   複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）を使い分け、多角的な情報収集と構成案の作成を短時間で行うことで、質の高いポストを量産できる（メルマガ10, 12, 20）。

### 4-2. 刺さらなかった理由（失敗原則・反省点）
*   **発信軸との大きなズレ:**
    *   インプレッションは伸びても、普段のフォロワーが求める情報と大きく異なる投稿は、フォローに繋がらず、むしろフォロワー減少の原因となる（メルマガ17, 18）。
*   **ユーザーにとっての「自分ごと」感の欠如:**
    *   テーマが難しすぎたり、自分とは関係なさそうだと感じられたりすると、インプレッションが伸び悩む（メルマガ11「為替介入」）。
*   **1枚目の情報過多による離脱:**
    *   最初の図解や画像に文字を詰め込みすぎると、ユーザーが「読むのが面倒」と感じてリプに進まず離脱してしまう（メルマガ11「為替介入」の反省点）。
*   **情報の深さ・量の不足:**
    *   「用語が簡単すぎた」「用語が少なすぎた」という反省点（メルマガ34「投資用語解説」）。専門性を求める層には物足りず、フォローに繋がりにくい。
*   **インパクトの欠如（再投稿時）:**
    *   一度伸びたネタでも、見せ方を変えずに再投稿すると反応が落ちることがある（メルマガ29「バレンタインの文字ポスト」）。Xは「飽きを嫌う傾向」があるため、同じ内容でも見せ方の工夫が必須（メルマガ16）。

## 5. 投稿前チェックリスト（具体的な確認項目）

投稿前に以下の項目を確認し、効果的なポストを目指しましょう。

### 5-1. ネタ・テーマの確認
*   [ ] **「なんとなく聞いたことあるけど、よくわからない」**というテーマか？（例: 青木率、エプスタイン事件、残クレアルファード）
*   [ ] **トレンドや時事ネタ**に乗っているか？（特に海外ニュース、最新の出来事）
*   [ ] 自身の**一次情報や本業の知識**を活かせるか？
*   [ ] **固有名詞や数字**が含まれており、インパクトがあるか？（例: 女子アナ、年収、マイナンバーカード）
*   [ ] **「東スポ要素」**のような下世話な好奇心を刺激する要素があるか？（インプレッション重視の場合）
*   [ ] **発信軸と大きくズレていないか？**（フォロワー増加を狙う場合）
*   [ ] 過去に伸びたポストの**再投稿**を検討しているか？（見せ方を変える工夫も）

### 5-2. 冒頭文の確認
*   [ ] **強い言葉**で読み手の興味を引き付けているか？（例: 「断言します」「これを知らないと大損します」）
*   [ ] **「あおり気味」**の文言でインパクトがあるか？
*   [ ] **流し読み**しているユーザーの目を止められるか？

### 5-3. 投稿の構成・型の確認
*   [ ] **1枚目のポストは文字**（メダル構文、会話構文など）で、リプへの誘導を意識しているか？（メルマガ3, 7, 14）
*   [ ] **図解**を使用する場合、Nano Banana Proなどのツールで**わかりやすく、デザイン性高く**作成されているか？
*   [ ] 1枚目の画像や図解は**「パッと見で何かわかる」**ように工夫されているか？（例: アルファードのイラストを大きく）
*   [ ] **1秒動画**を添付しているか？（インプレッション重視の場合、メルマガ36）
*   [ ] **リプで詳細を解説する**構成になっているか？（最初のポストの情報量をあえて抑える）
*   [ ] 複雑な内容は、ユーザーが**「知っているものとつなげて」**解説しているか？（例: 通常のローンと残クレの比較）
*   [ ] **漢字の比率**は適切か？（メルマガには直接言及がないが、一般的にXでは読みやすさのため漢字を減らす傾向がある）

### 5-4. AI活用とリサーチの確認
*   [ ] 複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）で**リサーチ・構成案作成**を効率化しているか？
*   [ ] AIの回答をそのまま使うのではなく、**自身の解釈や一次情報**を加えて独自性を出しているか？
*   [ ] リサーチに時間をかけすぎず、**効率的に情報収集**できているか？（AI活用で30分程度を目指す、メルマガ12）

### 5-5. 投稿後の運用と継続の確認
*   [ ] 投稿後**30分～60分はリプ返信**など交流を意識しているか？（メルマガ7）
*   [ ] Xだけでなく、**Instagram, スレッズ, TikTok, YouTubeショート**など他のSNSへの流用を検討しているか？（特に図解ポストは動画化して流用、メルマガ16, 19, 25, 28, 29）
*   [ ] ポスト作成を**楽しんで**行えているか？（継続のコツ、メルマガ11, 22）
*   [ ] X運用は**長距離走**であると認識し、必要以上に焦っていないか？（メルマガ17）
