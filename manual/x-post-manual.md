# X投稿マニュアル

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる最も重要な要素は「ネタ」であると繰り返し強調されています。以下の法則に基づき、ネタを選定しましょう。

### 1.1. 潜在的ニーズを刺激するテーマ
多くの人が「なんとなく聞いたことあるけど、よくわからない」「とっつきづらいけど、ちょっと知っておいた方がいいよな」「言われてみれば不思議」と感じるテーマは、高い関心を引きつけます。
*   **事例:**
    *   **政治系の解説:** 「青木率」の解説ポストは「234万インプレッション、1581名増加」（メルマガ1）。「政治系の、とっつきづらい話をやさしく解説する発信は、一定の需要がある」と分析されています。
    *   **闇が深い事件:** 「エプスタイン事件」の解説は「144万インプレッション、1652名増加」（メルマガ4）。「なんとなく聞いたことあるけどよくわからない」というニーズと、「陰謀論的な要素」が興味を引きました。
    *   **身近な疑問:** 「インドカレー屋さんの秘密」は「317万インプレッション、492名増加」（メルマガ41）。「言われてみれば不思議」という内容が多くの共感を呼びました。

### 1.2. トレンド性・時事性のあるテーマ
XのトレンドワードやYahoo!ニュースなど、その時々の大きな話題に乗ることで、インプレッションとフォロワー増の両方を狙えます。特に「海外のニュース」は伸びやすい傾向があります。
*   **事例:**
    *   **国会冒頭解散:** 「高市首相の解散総選挙」は「1581名増加」（メルマガ8）。
    *   **エプスタイン事件:** 「1月30日に新たにファイルが350万ページ公開された」という「現在進行形」のトレンドが影響し、「1652名増加」（メルマガ4, 32, 33）。
    *   **海外メディアの報道:** 「海外メディアのイラン攻撃報道」は「2951名増加」（メルマガ8）。「海外のニュースが多い」とてっぺい氏も分析しています。
    *   **ナフサ不足:** 「ポテトチップスの袋が白黒になるニュース」というインパクトのあるトレンドワードに乗り、「182万インプレッション、603名増加」（メルマガ10）。
    *   **ワールドカップ:** 「ワールドカップネタ」は「1077万インプレッション、744名増加」を記録し、その後も「6日連続で、ワールドカップネタにしてる」（メルマガ42）。「当たったら、その周辺のネタを使うというのは有効」です。

### 1.3. 「下世話」な要素や「意外性」を含むテーマ
人の興味を強く引く「下世話」な話題や、常識を覆すような「意外な結果」は、インプレッションを大きく伸ばし、拡散につながります。
*   **事例:**
    *   **女子アナの年収ランキング:** 「女子アナ」「フリー転向」「年収」という「下世話なネタを3つ盛り込んだランキング」で「92万インプレッション」を記録（メルマガ18）。
    *   **知事の年収ランキング:** 「あなたの県の知事の年収、知ってますか？」という「下世話」な問いかけと、「東京の小池都知事が、給与をカットしていて47都道府県で最下位」という「意外性」が重なり、「550万インプレッション、16,940名増加」（メルマガ50）。
    *   **大臣の年収・資産額:** 新内閣の解説に「年収」「資産額」を盛り込むことで、「有益っぽいポストに下世話な要素」を加え、「141万インプレッション、7805名増加」（メルマガ52）。

### 1.4. 一次情報・自身の経験・専門知識
「本業のちょっとした知識で誰かの役に立つような情報」や、自身が「へー」と思った学びは、オリジナリティと熱量を伴い、読者に響きやすくなります。
*   **事例:**
    *   **ホテルのオフシーズン:** 元ホテル勤務の経験から「ゴールデンウィーク明けはホテルが一番空く時期」というタイムリーな情報を発信し、「60万インプレッション、206名増加」（メルマガ9）。
    *   **為替介入の解説:** 自身が「はっきりわかってなかった」為替介入を調べて発信。「ポストがあまり伸びてないのにフォローいただいてるというのは『わかりやすい』と思ってもらえたのかなと」分析されています（メルマガ11）。
    *   **妻の社会保険扶養:** 妻のパート探しをきっかけに調べた社会保険の知識を「会話ポスト」で発信し、「170万インプレッション、307名増加」（メルマガ7）。

### 1.5. 「まだ見たことない」独自性
他の人が発信していない、新しい切り口のネタは、差別化につながります。
*   **事例:**
    *   **都道府県別アウトレット:** 「アウトレット、あまり見たことない」という着眼点から発信し、「123万インプレッション、5099名増加」（メルマガ51）。

### 1.6. AIをリサーチに活用し、ネタの質を高める
AI（ChatGPT, Gemini, Perplexity, Grok, Claudeなど）はリサーチの時間を大幅に短縮し、多角的な情報収集を可能にします。ただし、ネタ出し自体は人間が行う方が良いとされています。
*   **事例:**
    *   **ナフサ不足の解説:** 5つのAIに質問し、それぞれの良い点を組み合わせて図解を作成。「リサーチの時間が圧倒的に短くなったのでロス時間がかなり少なくなった」（メルマガ10）。
    *   **OPEC脱退の解説:** 複数のAIに聞き、Claudeの方向性でChatGPTにまとめさせ、図解化。「以前だったら、リサーチが絶対に30分で終わらなかった」（メルマガ12）。
    *   **AIによるネタ出しの反省:** 「AIにネタを出してもらった」が、「いいかも」と思ったのは一つだけ。「ネタ選びにAI、使えるのかもしれないけどやり方はもう少し考えなくては」（メルマガ13）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xのアルゴリズムの変化に対応し、読者の興味を引きつけ、リプ（返信）への誘導を促す構成が重要です。

### 2.1. 冒頭文の作り方：インパクト勝負
Xは「流し読みされる媒体」であるため、「書き出しが命」です。冒頭文で読者の興味を瞬時に引きつけましょう。
*   **原則:**
    *   **断言・煽り:** 「断言します」「これを知らないと大損します」「私コレで月10万円得しました」などの強い言葉で興味を引く（メルマガ2, 35）。
    *   **具体的な数字・固有名詞:** 「55億円」「地面師」「Netflix」「2017年」など、具体的な情報で引きつける（メルマガ38）。
    *   **あおり気味の文言:** 「マイナンバーカードがなくなることを知らない人が多すぎる」のように、少し煽ることで反応を高める（メルマガ36）。アンチのリプも「勝手にポストを拡散してくれるのでチャンス」と捉えましょう。
    *   **文字数は少なめに:** 「読みやすく、文字は少なめになるようにして気になるところで切る」（メルマガ38）。「題名ぐらいの気持ちで今は、最初の会話ポストを作ってる」（メルマガ40）。

### 2.2. 投稿の型：1枚目文字ポスト + 2枚目以降図解（リプ誘導型）
最近のXアルゴリズムは「リプに行ってもらう」ことを重視しています。そのため、1枚目を文字ポストで興味を引き、リプで詳細な図解を見せる構成が効果的です。
*   **原則:**
    *   **1枚目文字ポスト:** 「1枚目を文字ポストにして2枚目から図解にするポスト」が「伸びやすくなってる」（メルマガ3）。「最初のポストは文字にして、とにかくリプにいってもらうポストが、インプレッションも増えて内容が有益であれば、フォローもしていただける」（メルマガ3）。
    *   **リプ誘導の徹底:** 「ポストは簡単にしてリプにいってもらって図解を見てもらう構成」（メルマガ14）。「最初のポストにつける図解の情報量は、少し少なめにして、誘導に持っていった方が良いような印象」（メルマガ26）。
    *   **会話構文・メダル構文の活用:** 「会話調の軽いポスト」「メダルを使った、軽いポストを1枚目にして2枚目以降に、有益な図解をつけるというのが最強」（メルマガ38, 39）。
    *   **「ロールキャベツ系ポスト」:** 「一見、流行りにのってるようで、実は図解で有益なことを伝える」という構成（メルマガ6）。

### 2.3. 図解ポストの活用
てっぺい氏の「13万フォロワー」達成の最大の秘密は「図解ポスト」です（メルマガ5）。
*   **原則:**
    *   **わかりやすさ重視:** 「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
    *   **Nano Banana Proの活用:** 図解作成のハードルを劇的に下げ、高品質な図解を高速で作成できます（メルマガ1, 5, 12, 16, 21, 26, 30, 32）。
    *   **パッと見のわかりやすさ:** 「パッと見でなんのポストかわかるようにする」（メルマガ30）。アルファードのイラストを大きくするなど。
    *   **文字の量:** 1枚目の図解に文字を多く入れすぎると伸びづらい（メルマガ11の反省点）。
    *   **飽きさせない工夫:** 「Xは飽きを嫌う傾向がある」ため、「同じようなポスト、同じような構文を使ってる方はたまには、図解を使ってみるのも良い」（メルマガ16）。
    *   **他SNSへの流用:** 図解はInstagram（リール動画化）、TikTok、YouTubeショート、スレッズなど、他のSNSに「思考停止で」流用でき、効率的にフォロワーを増やせます（メルマガ16, 19, 25, 28, 29）。

### 2.4. その他の構文・画像・動画
*   **流行りの構文:** メダル構文、会話構文、◯×構文、国旗構文、Tier、ランキングなど、流行りの構文を積極的に試す（メルマガ6）。
*   **1秒動画:** 「X社は動画を優遇している」ため、「赤い矢印が点滅する1秒動画」を添付することで「ポストが爆発的に伸びる」（メルマガ36）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも連動せず、異なる要素が影響します。

### 3.1. インプレッションを伸ばす投稿の傾向
インプレッションは、より多くのユーザーに投稿が届いたことを示し、X収益に直結します。
*   **冒頭文のインパクト:** 「書き出しがつまらないとポストは伸びません」（メルマガ2）。「冒頭文を変えただけでインプレッション数やいいね数が数倍になった」事例多数。
*   **トレンド性・時事性:** 「トレンドにのるワード」はインプレッションを大きく伸ばします（メルマガ10）。
    *   例: 「マイナンバーカードがなくなる」は「595万インプレッション」（メルマガ36）。
    *   例: 「ワールドカップネタ」は「1077万インプレッション」（メルマガ42）。
*   **「東スポ」要素の強いネタ:** 「日経新聞に載ってるようなことより東スポに載ってることの方がいい」という考え方で、「女子アナ」「フリー転向」「年収」のような「下世話なネタ」はインプレッションを伸ばします（メルマガ18）。
*   **流行りの構文・見せ方:** 「メダルを使った構文」や「会話構文」など、流行りの型を取り入れることで、インプレッションが伸びやすくなります（メルマガ3, 6, 40）。
*   **1秒動画の添付:** 「X社は動画を優遇している」ため、「1秒動画」はインプレッションを「爆発的に伸ばす」効果があります（メルマガ36）。
*   **文字ポストの優位性:** 「図解のポストよりも文字のポストの方がインプレッションが伸びやすい傾向」があるため、X収益を狙う場合は文字ポストも有効です（メルマガ8）。

### 3.2. フォロワー増につながる投稿の傾向
フォロワー増は、アカウントの成長と影響力に直結します。
*   **発信軸との関連性:**
    *   「一般的には、発信軸からズレてるといいねやインプレッションは伸びてもフォローはされない」と言われるが、「政治系の解説は、比較的フォロワー様も増える傾向」がある（メルマガ1）。
    *   「お金とお得情報」が軸のてっぺい氏が「政治系の、とっつきづらい話をやさしく解説する」ことで、「234万インプレッション、1581名増加」（メルマガ1）。
    *   「闇が深いエプスタイン事件」の解説は「144万インプレッション、1652名増加」と「とてもフォローいただく数が多い」（メルマガ4, 33）。
*   **「有益性」と「わかりやすさ」:**
    *   「見る人が有益と感じる内容であればフォローはされる」（メルマガ6）。
    *   「為替介入」のポストはインプレッションは伸びなかったが、「フォローいただく方の数は多くなってます」。「『わかりやすい』と思ってもらえたのかなと」（メルマガ11）。
    *   「めんどくさそうだけど、ざっくり知っておいた方が良いよな～と思うニュース」を「優しく解説する」ことで、「フォローいただく率が高い」（メルマガ23）。
*   **「みんな聞いたことある、大切そう、でもよくわからない」ネタ:** これらを優しく解説する図解ポストは、フォロワー増に繋がりやすい（メルマガ12）。
*   **「結果の意外性」:** 「みんなが『えっ』と思う結果があるとネタが良いと伸びやすくなる」ため、リプや引用リポストが増え、結果的にフォロワー増につながります（メルマガ51）。
*   **特定の層に深く刺さるネタ:**
    *   「高校受験をしてる人は圧倒的に多い」「名門といわれる高校を卒業してる人は、このポストが気になる」「細かすぎて見えないので、図解を拡大してくれる」といった要素が重なり、「1ポストで44,654名増加」という驚異的な成果を達成（メルマガ44, 45, 46, 47, 48）。
*   **図解ポストの優位性:** 「図解を使った方がフォローいただく数は多くなる印象」（メルマガ8）。

### 3.3. インプレッションは伸びたがフォロワーは減った事例（示唆的な分析）
インプレッションとフォロワー増は別物であり、インプレッションが伸びてもフォロワーが減少するケースがあります。
*   **発信軸とのズレ:**
    *   「女子アナ」「フリー転向」「年収」のポストは「92万インプレッション」と伸びたが、「フォロワー様が現時点で30名ほど減ってます」。これは「発信軸とのズレ」が原因と分析されています（メルマガ18）。
    *   「お金・お得情報」でも「ニュース解説」でもないポストは「113万インプレッション」でも「フォロワー様が69名減ってしまった」（メルマガ17）。
*   **インプレッション重視の構文・ネタ:**
    *   AIにネタ出しさせたポストは「24万インプレッション」だが「フォロワー様が10名減」。「おそらくフォローはいただいてると思うのですがそれ以上に、減る数が多かった」（メルマガ13）。
    *   「流行りの構文を使って、インプレッションはでるけどフォローされない」という話はよく聞かれ、「ややアルゴリズムをハックしてる感がある」（メルマガ6）。
    *   ワールドカップネタはインプレッションは伸びるものの、フォロワー増減はバラバラで、「17名減」「119名減」の事例もあります（メルマガ43）。
*   **図解の構成ミス:**
    *   「図解を最初のポストにつけると伸びづらくなってる」状況で、図解を1枚目に置いたポストは「15万インプレッション」で「フォロワー様10名減」（メルマガ39）。
*   **Xの凍結増加:** 「最近は、Xの凍結も増えているのでフォロワー様の減りが、多くなってるようにも思います」（メルマガ17）。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗から学ぶことで、再現性のある投稿戦略を構築できます。

### 4.1. 刺さった理由（成功要因）

1.  **ニーズへの合致とわかりやすい解説:**
    *   「とっつきづらいけど、ちょっと知っておいた方がいいよな」という情報を「やさしく解説」する（メルマガ1）。
    *   「なんとなく聞いたことあるけどよくわからない」ことを解説する（メルマガ4, 30, 33）。
    *   「みんなも『どうして？』と思ってること」をトレンドに乗せて発信する（メルマガ27）。
    *   「知ってるものとつなげる」ことで、より理解を深める（メルマガ30）。
    *   **事例:** 「残クレ」アルファードの解説で「通常のローンとの比較」を入れたことで、「支払い方法の話ね」と理解しやすくなった（メルマガ30）。

2.  **トレンドと時事性への迅速な対応:**
    *   「トレンドにのっている」「ニュース解説」はフォロワー増に直結（メルマガ8）。
    *   「朝起きてポストを作成」し、「トレンドに伸びそうなネタがあるときはそのネタを優先させている」（メルマガ10）。
    *   **事例:** 国会冒頭解散に合わせて「青木率」を解説（メルマガ1）。「エプスタイン事件」の新たなファイル公開に合わせて解説（メルマガ4, 33）。

3.  **インパクトと意外性、固有名詞・数字の活用:**
    *   「冒頭のインパクト勝負」（メルマガ2）。「断言します」「これを知らないと大損します」などの言葉。
    *   「闇が深い」「陰謀論的な要素」は強い興味を引く（メルマガ4, 33）。
    *   「下世話」な要素（年収、資産額など）は、多くの人の関心を集める（メルマガ18, 50, 52）。
    *   **事例:** 「ポテチの白黒袋」という「インパクトの強さ」とトレンドが重なり、大きく伸びた（メルマガ10）。「55億円」「地面師」「Netflix」「2017年」といった固有名詞や数字を冒頭に盛り込む（メルマガ38）。

4.  **投稿形式の工夫とアルゴリズムへの適応:**
    *   「1枚目を文字ポストにして2枚目から図解」というリプ誘導型が現在のアルゴリズムに合致（メルマガ3, 39, 40）。
    *   「流行りの構文」の力を借りて、有益な情報を届ける「ロールキャベツ系ポスト」（メルマガ6）。
    *   **事例:** 伸び悩んでいた「個人向け国債」のポストを「メダルを使った構文」で再投稿し、「334万インプレッション」を達成（メルマガ6）。

5.  **一次情報と「自分ごと」としての発信:**
    *   自分が「そうなんだ」と思ったこと、「学んだこと」をわかりやすく発信することは「自分の学びにもなるので楽しく発信ができる」（メルマガ11）。
    *   「本業のちょっとした知識で誰かの役に立つような情報」は独自性がある（メルマガ9）。

6.  **継続と再利用の戦略:**
    *   「同じポストは何度も使い回してOK」。「当たるか分からないポストを闇雲に投稿し続けるなんて費用対効果が悪過ぎる」（メルマガ36）。
    *   **事例:** 「マイナンバーカード」のポストは3回目の投稿で「595万インプレッション、407名増加」を記録。過去3回合計で「1646名」のフォロワー増に貢献（メルマガ36）。
    *   「過去の伸びたポストを1枚目だけ文字ポストにして再投稿する」手法（メルマガ3）。

7.  **AIによる効率化:**
    *   AI（Nano Banana Pro, ChatGPTなど）を活用することで、「リサーチの時間が圧倒的に短くなった」り、「図解を作るスピードが圧倒的に早くなった」りし、「発信したいことが発信できるようになった」（メルマガ12）。

### 4.2. 刺さらなかった理由・反省点（失敗要因）

1.  **発信軸とのズレ:**
    *   「発信軸からズレるといいねやインプレッションは伸びてもフォローはされない」（メルマガ1）。
    *   **事例:** 「女子アナ」「年収」のポストは「92万インプレッション」と伸びたが、「フォロワー様が現時点で30名ほど減ってます」。「さすがにギャップがあったのかも」（メルマガ18）。

2.  **図解の構成ミス:**
    *   「1枚目の図解に文字を多く入れすぎた」ため、「リプにいってもらえなかった」可能性（メルマガ11）。
    *   「1枚目に図解をおくと、伸びづらくなってる印象」（メルマガ3）。

3.  **ネタの選定ミス:**
    *   「為替介入」という言葉が「自分とは関係なさそうに感じる」ため、あまり伸びなかった（メルマガ11）。
    *   「用語が簡単すぎたこと」「用語が８つしかないのは少な過ぎたこと」が反省点（メルマガ34）。

4.  **情報のインパクト不足:**
    *   「ナフサ」の解説は以前伸びなかったが、「ポテチの白黒袋」というインパクトを加えて伸びた。「インパクトがないから」伸びなかったと分析（メルマガ10）。

5.  **図解の質の問題:**
    *   「知事の顔が違う」という指摘が多かった（メルマガ50）。「地図がゆがんでる」など、図解のクオリティが低いと、伸び悩む原因になる（メルマガ44）。

6.  **AIによるネタ出しの限界:**
    *   AIにネタを出させたが「いいかも」と思ったのは一つだけ。「ネタ選びにAI、使えるのかもしれないけどやり方はもう少し考えなくては」（メルマガ13）。

## 5. 投稿前チェックリスト（具体的な確認項目）

以下の項目を投稿前に確認することで、てっぺい氏の成功法則を再現し、投稿のパフォーマンスを最大化できます。

### 5.1. ネタ・テーマに関するチェック
*   [ ] **潜在的ニーズ:** 「とっつきづらいけど、ちょっと知っておいた方がいいよな」「なんとなく聞いたことあるけど、よくわからない」「言われてみれば不思議」といったニーズを突いているか？
*   [ ] **トレンド性:** XのトレンドワードやYahoo!ニュースなど、時事性のある話題か？（特に海外ニュースは伸びやすい）
*   [ ] **下世話・意外性:** 「年収」「資産額」などの下世話な要素や、常識を覆す「意外な結果」を含んでいるか？
*   [ ] **一次情報・独自性:** 自身の経験や学び、本業の知識など、オリジナリティのある内容か？
*   [ ] **未視感:** 他の人があまり発信していない、新しい切り口のネタか？（パクリにならないか確認）
*   [ ] **対象者の広さ:** 多くの人が関心を持つテーマか？
*   [ ] **自分も「へー」:** 投稿者自身が「へー」と思った内容か？
*   [ ] **再利用の可能性:** 過去に伸びたポストのネタや型を再利用できないか？（見せ方を変える）
*   [ ] **AI活用:** AI（ChatGPT, Gemini等）でリサーチを効率化し、多角的な情報を収集したか？

### 5.2. 投稿の構成・型に関するチェック
*   [ ] **冒頭文のインパクト:**
    *   [ ] 「断言します」「これを知らないと大損します」などの強い言葉で興味を引いているか？
    *   [ ] 具体的な「固有名詞」や「数字」を効果的に使っているか？
    *   [ ] 読みやすく、文字数は少なめに、気になるところで切ってあるか？
*   [ ] **リプ誘導型:**
    *   [ ] 1枚目のポストは「文字」で、リプ（返信ツリー）に誘導する構成になっているか？
    *   [ ] 2枚目以降に詳細な「図解」を配置しているか？
    *   [ ] 「会話構文」や「メダル構文」など、流行りの型を試しているか？
*   [ ] **図解の質:**
    *   [ ] 「パッと見でなんのポストかわかる」デザインか？
    *   [ ] 1枚目の図解に文字を多く入れすぎていないか？
    *   [ ] Nano Banana ProなどAIツールで効率的に作成されているか？
    *   [ ] 図解の誤りや不自然な点（例：顔が違う、地図の歪み）はないか？
*   [ ] **動画・画像:**
    *   [ ] インプレッションを伸ばしたい場合、「1秒動画」を添付しているか？
    *   [ ] 1枚目の画像は「とにかく目に止まるように」、難しいことは書かず、ほぼ画像で構成されているか？
    *   [ ] 固有名詞や人物のイラスト（例：トランプ大統領）を効果的に使っているか？
*   [ ] **漢字の比率:** 読みやすさを考慮し、漢字が多すぎないか？（直接的な言及はないが「読みやすく」の原則から）

### 5.3. 投稿後の運用に関するチェック
*   [ ] **リプへの返信体制:** 投稿後30分～60分は特に、もらったリプにできるだけ早く、多く返信する準備ができているか？（交流によるアルゴリズム優遇）
*   [ ] **他SNSへの展開:** Xで伸びた図解ポストを、Instagram（リール動画化）、TikTok、YouTubeショート、スレッズなど、他のSNSにも流用する予定か？

### 5.4. フォロワー増減に関するチェック
*   [ ] **発信軸とのズレ:** インプレッションは伸びてもフォロワーが減るリスクを考慮し、発信軸と大きくズレていないか？（特にフォロワー増を重視する場合）
*   [ ] **有益性・わかりやすさ:** 投稿内容が読者にとって「有益」で「わかりやすい」と感じられるか？
