# X投稿マニュアル

X(旧Twitter)運用専門家てっぺい氏のメルマガ分析に基づき、再現性のあるX投稿マニュアルを作成しました。てっぺい氏は「1ポストで44,654名増加」「19日間で152,776名増加」「月間最高1億2900万インプレッション」といった驚異的な実績を上げており、その成功と失敗から導き出された原則を体系化しています。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏のポストが伸びるかどうかは「ネタ」で決まると繰り返し強調されています。以下の法則を意識してネタを選定しましょう。

1.  **「聞いたことあるけど、よくわからない」を優しく解説する**
    *   多くの人が関心を持ちつつも、とっつきにくいと感じるテーマは、わかりやすく解説することで高いエンゲージメントとフォロワー増に繋がります。
    *   **成功事例:**
        *   「選挙の『青木率』解説」: **234万インプレッション、1581名増加**（メルマガ1）
        *   「エプスタイン事件」: **144万インプレッション、1652名増加**（メルマガ4）
        *   「ナフサ不足とポテトチップスの白黒袋」: **182万インプレッション、603名増加**（メルマガ10）
        *   「UAEのOPEC脱退」: **60万インプレッション、2010名増加**（メルマガ12）
        *   「残クレアルファード」: **65万インプレッション、532名増加**（メルマガ30）
        *   「中東情勢の解説」: **58万インプレッション、1075名増加**（メルマガ23）
    *   **原則:** 「みんな聞いたことある」「興味がある」「対象者が広い」「知ってるけどよくわからない」「調べるのめんどくさそう」という要素を満たすネタを探しましょう。

2.  **トレンド・時事ネタに乗る**
    *   XのトレンドワードやYahoo!ニュースから、世間の関心が高い時事ネタを選定します。特に海外のニュースは反応が良い傾向にあります。
    *   **成功事例:**
        *   「国会の冒頭解散に合わせた選挙の『青木率』解説」: **234万インプレッション、1581名増加**（メルマガ1）
        *   「エプスタイン事件（新たなファイル公開）」: **144万インプレッション、1652名増加**（メルマガ4）
        *   「海外メディアのイラン攻撃報道」: **1ポストで2951名増加**（メルマガ8）
        *   「ナフサ不足」: **182万インプレッション、603名増加**（メルマガ10）
        *   「ワールドカップネタ」: **1077万インプレッション、744名増加**（メルマガ42）
    *   **原則:** 毎朝トレンドを確認し、伸びそうなネタがあれば優先的に発信します。

3.  **自分ごと化しやすいテーマを選ぶ**
    *   読者全員が必ずどこかに属するテーマや、身近で関心が高いテーマは「自分ごと」として捉えられやすく、高いフォロワー獲得に繋がります。
    *   **成功事例:**
        *   「高校受験の高校名門ランキング（都道府県別）」: **1ポストで44,654名増加**（メルマガ44）
        *   「都道府県別知事の年収」: **550万インプレッション、16,940名増加**（メルマガ50）
        *   「全国のアウトレット」: **123万インプレッション、5099名増加**（メルマガ51）
        *   「関東の家賃比較」: **826万インプレッション、10,666名増加**（メルマガ54）
        *   「都道府県別のショッピングセンターの比較」: **194万インプレッション、7428名増加**（メルマガ57）
        *   「世界の血液型分布」: **114万インプレッション、909名増加**（メルマガ59）
    *   **反省点:** 「関東だけなので全国を網羅してない」ポストは「自分ごと化が弱くなる」ため、全国規模で扱う方が伸びやすい（メルマガ56）。

4.  **意外性や「下世話」な要素を取り入れる**
    *   「へー」と思うような意外な事実や、年収・ランキングといった「下世話」な要素は、Xユーザーの興味を強く引き、インプレッションやフォロワー増に繋がります。
    *   **成功事例:**
        *   「ホテルが一番空く時期（GW明け）」: **60万インプレッション、206名増加**（メルマガ9）
        *   「フジテレビの栄枯盛衰」: **140万インプレッション、565名増加**（メルマガ20）
        *   「歴代総理・大統領のランキング」: **118万インプレッション、524名増加**（メルマガ22）
        *   「都道府県別知事の年収（小池都知事が最下位という意外性）」: **550万インプレッション、16,940名増加**（メルマガ50）
        *   「新しい内閣の解説（大臣の年収・資産額）」: **141万インプレッション、7805名増加**（メルマガ52）
        *   「大学の世界ランキング（会津大学のランクイン）」: **124万インプレッション、3728名増加**（メルマガ55）
    *   **原則:** リサーチ結果に「えっ」と思うような意外な結果があると、リポストや引用リポストが増え、伸びやすくなります。

5.  **一次情報・実体験を元にする**
    *   自身の経験や、身近な人との会話から得た一次情報は、オリジナリティがあり、共感を呼びやすいです。
    *   **成功事例:**
        *   「妻のパート探し（社会保険の扶養）」: **170万インプレッション、307名増加**（メルマガ7）
        *   「ホテルが一番空く時期」: **60万インプレッション、206名増加**（メルマガ9）
        *   「為替介入（自分がわからなかったことを調べて発信）」: **7万インプレッション、90名増加**（メルマガ11）
        *   「バレンタインの娘の実話」: **240万インプレッション、586名増加**（メルマガ29）
        *   「西松屋の戦略（ポッドキャストで聞いた話）」: **148万インプレッション、95名増加**（メルマガ40）
    *   **原則:** 自分が「そうなんだ」「学んだこと」と感じたことをわかりやすく発信すると、楽しく継続できます。思いついたらすぐにメモしましょう。

6.  **過去に伸びたネタを再利用する**
    *   一度反応が良かったポストは、時期を置いて再投稿することで、再び高いエンゲージメントを得られる可能性があります。見せ方を変えることでさらに効果的です。
    *   **成功事例:**
        *   「マイナンバーカードの名称変更」: 3回の投稿で合計**1646名増加**（初回: **655万インプレッション、1114名増加**）（メルマガ36）
        *   「過去の伸びた図解ポストを1枚目文字ポストにして再投稿」: **204万インプレッション、170名増加**（メルマガ39）
        *   「高校受験の高校名門ランキング」: 1回目の**7903名増加**から、図解を改善して**44,654名増加**（メルマガ44）
    *   **原則:** 当たるか分からないポストを闇雲に投稿するより、反応が出たポストは1ヶ月ほど置いて何度も使い回しましょう。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xのアルゴリズムの変化に対応し、インプレッションとフォロワー増の両方を狙うための構成と型を使い分けましょう。

1.  **冒頭文でインパクトを与える**
    *   Xは「流し読みされる媒体」であるため、冒頭文で読み手の興味を引き付けることが最重要です。
    *   **原則:**
        *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」などの強い言葉で興味を引く（メルマガ2, 35）。
        *   「マイナンバーカードがなくなることを知らない人が多すぎる。」のような煽り気味の文言も有効（メルマガ36）。アンチのリプは拡散のチャンスと捉えましょう。
        *   固有名詞や具体的な数字を入れることで、目を引きやすくなります（例: 「55億円」「地面師」「Netflix」「2017年」）（メルマガ38）。

2.  **文字ポストと図解ポストの使い分けと連携**
    *   てっぺい氏の基本は図解ポストですが、アルゴリズムの変化に合わせて見せ方を工夫しています。
    *   **図解ポストの強み:**
        *   「文字だけのポストでは想像できないほどのインプレッション数が得られる」（メルマガ5）。
        *   「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
        *   「図解を使った方がフォローいただく数は多くなる印象がある」（メルマガ8）。
        *   Nano Banana Proなどのツールを使えば、図解作成のハードルが劇的に下がります（メルマガ1, 5, 12, 16, 21, 30, 32, 34）。
    *   **文字ポストのトレンド:**
        *   「最近、図解のポストよりも文字のポストの方がインプレッションが伸びやすい傾向がある」（メルマガ8）。
        *   「文字ポストの方が伸びやすいというトレンドを意識して実験した」結果、インプレッションもフォローも伸びた事例あり（メルマガ7）。
    *   **最新の推奨構成（ロールキャベツ系ポスト）:**
        *   **1枚目を文字ポスト、2枚目以降を図解にする**（メルマガ3, 7, 8, 14, 39, 40, 41）。
        *   1枚目には「メダル構文」「会話構文」などの流行りの型を使用し、**読みやすく文字は少なめ**にする（メルマガ3, 6, 7, 38, 39, 40, 42）。
        *   「とにかくリプにいってもらう」ことを狙い、**気になるところで切ってリプへ誘導**する（メルマガ3, 7, 14, 20, 26, 38, 39, 40, 41）。
        *   リプに誘導された先で、図解を使って有益な情報をわかりやすく伝える（メルマガ6, 41）。

3.  **画像・動画の活用**
    *   視覚的な要素はXで目を引くために不可欠です。
    *   **図解の工夫:**
        *   1枚目の図解は「とにかく目に止まるように」、難しいことは書かず、ほぼ画像にする（メルマガ10）。
        *   イラストではなく画像を使うことも有効（メルマガ10）。
        *   「パッと見でなんのポストかわかるようにする」（メルマガ30）。
        *   AIで作成しづらい複雑な図解（日本地図など）は、Canvaなどで自作する努力も必要（メルマガ44, 50）。
    *   **動画の活用:**
        *   「X社は動画を優遇している」ため、**1秒動画**はインプレッションを爆発的に伸ばすのに有効（メルマガ36）。
        *   図解を動画（紙芝居のような動画）にして、InstagramのリールやYouTubeショート、TikTokに流用することで、他のSNSも伸ばせる（メルマガ16, 19, 25, 28, 29）。

4.  **AIを最大限に活用する**
    *   AIはリサーチ時間の短縮と図解作成の効率化に不可欠なツールです。
    *   **リサーチ:**
        *   ChatGPT, Gemini, Perplexity, Grok, Claudeなど複数のAIに質問し、回答を比較検討する（メルマガ10, 12, 14, 20, 22, 26, 38, 51, 55）。
        *   「ニュース系のリサーチはGeminiの方がいいように感じている」（メルマガ55）。
        *   AIのおかげで「発信したいことが発信できるようになった」（メルマガ12）。
    *   **図解作成:**
        *   Nano Banana Proは「文字化けもない、デザインも優れた図解ができてビビった」と評されており、図解作成の主要ツールとして活用されています（メルマガ1, 4, 5, 10, 12, 16, 21, 23, 26, 30, 32, 33, 34, 37）。
        *   AIで図解を作成する際も、結果の意外性や面白さを意識する（メルマガ51）。
    *   **マンガ作成:**
        *   ChatGPTでシナリオを作成し、専用ツールでマンガ化することで、短時間でストーリー性のあるマンガポストを作成できます（メルマガ29, 58）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも連動しません。それぞれの目標に応じた戦略が必要です。

### インプレッションを伸ばす投稿

インプレッションはX収益に直結するため、アカウントを育てる上で重要です。

*   **トレンド・時事ネタ:**
    *   「ワールドカップネタ」: **1077万インプレッション**（メルマガ42）
    *   「マイナンバーカードの名称変更」: **655万インプレッション**（メルマガ36）
    *   「都道府県別知事の年収」: **550万インプレッション**（メルマガ50）
    *   「関東の家賃比較」: **826万インプレッション**（メルマガ54）
*   **下世話なネタ・興味本位を刺激する内容:**
    *   「女子アナ、フリー転向、年収ランキング」: **92万インプレッション**（メルマガ18）
    *   「都道府県別知事の年収」: **550万インプレッション**（メルマガ50）
    *   「新しい内閣の解説（大臣の年収・資産額）」: **141万インプレッション**（メルマガ52）
    *   **原則:** 「日経新聞に載ってるようなことより東スポに載ってることの方がいい」という考え方で、人々の好奇心を刺激するネタはインプレッションを伸ばしやすいです（メルマガ18）。
*   **視覚的インパクトとアルゴリズムハック:**
    *   **1秒動画:** 「X社は動画を優遇している」ため、1秒動画を添付することでポストが爆発的に伸びる（メルマガ36）。
    *   **流行りの構文:** メダル構文、会話構文などはアルゴリズムをハックする側面があり、インプレッションを伸ばしやすい（メルマガ6, 7, 38, 40, 42）。
    *   **煽り気味の冒頭文:** 強い言葉で興味を引き、流し読みされるXで足を止める効果があります（メルマガ36）。
*   **文字ポストの優位性:**
    *   「最近、図解のポストよりも文字のポストの方がインプレッションが伸びやすい傾向がある」（メルマガ8）。
    *   「文字の方がインプレッションが伸びた可能性もある」（メルマガ7）。

### フォロワー増につながる投稿

フォロワー増はアカウントの信頼性や影響力に直結します。

*   **「とっつきづらいけど、知っておいた方がいい」情報を優しく解説:**
    *   「選挙の『青木率』解説」: **1581名増加**（メルマガ1）
    *   「エプスタイン事件」: **1652名増加**（メルマガ4）
    *   「中東情勢の解説」: **1075名増加**（メルマガ23）
    *   **原則:** 読者が「めんどくさそうだけど、ざっくり知っておきたい」と思うニュースや情報を、わかりやすく解説することで、高いフォロー率に繋がります。
*   **発信軸に沿った有益な内容:**
    *   てっぺい氏の基本軸である「お金とお得情報」「ニュース解説」に沿ったポストは、フォロワー増に繋がりやすいです。
    *   **成功事例:**
        *   「銀行預金より個人向け国債 変動10年」: **334万インプレッション、417名増加**（メルマガ6）。流行りの構文でも、内容が有益であればフォローされる。
        *   「海外メディアの立ち位置」: **184万インプレッション、2951名増加**（メルマガ26）。
    *   **原則:** 「見る人が有益と感じる内容であればフォローはされる」（メルマガ6）。
*   **自分ごと化しやすいテーマと意外性:**
    *   「高校受験の高校名門ランキング（都道府県別）」: **1ポストで44,654名増加**（メルマガ44）。
    *   「都道府県別知事の年収（小池都知事が最下位という意外性）」: **16,940名増加**（メルマガ50）。
    *   「全国のアウトレット（見たことないネタ、意外な結果）」: **5099名増加**（メルマガ51）。
    *   **原則:** 多くの人が自分に関係あると感じ、かつ意外な発見があるテーマは、強いフォロー動機を生み出します。
*   **図解ポストの優位性:**
    *   「図解を使った方がフォローいただく数は多くなる印象がある」（メルマガ8）。
    *   Nano Banana Proを活用した図解ポストは、フォロワー爆増の最大の秘密とされています（メルマガ5）。
*   **リプへの誘導と内容の質:**
    *   「1枚目を文字にして、とにかくリプにいってもらうポストが、インプレッションも増えて内容が有益であれば、フォローもしていただける」（メルマガ3）。
*   **質の高いポストと交流の継続:**
    *   「質の高いポスト」「交流」を継続することが、フォロワー増加の基本的な戦略です（メルマガ46, 61）。

### インプレッションは伸びたがフォロワーは減った事例（両者は別物として分析）

インプレッションが伸びてもフォロワーが減少するケースは、発信軸のズレや内容の質が原因となることが多いです。

*   **発信軸とのズレ:**
    *   「AIにネタを出してもらったポスト」: **24万インプレッション、10名減**（メルマガ13）。「フォローはいただいてると思うが、それ以上に減る数が多かった」。
    *   「お金・お得情報でもニュース解説でもないポスト」: **113万インプレッション、69名減**（メルマガ17）。発信軸とのズレが要因。
    *   「女子アナ、フリー転向、年収ランキング」: **92万インプレッション、30名減**（メルマガ18）。「発信軸とのズレ」と「ギャップ」が原因。下世話なネタはインプレッションを稼ぐが、フォローには繋がりにくい。
    *   「ワールドカップで4ゴール」: **17名減**。「日本代表の年俸」: **176万インプレッション、119名減**（メルマガ43）。ワールドカップ関連のネタはインプレッションが伸びやすいが、発信軸と異なるためか、フォロワー増減はまちまち。特に年俸のような下世話なネタはインプレッションは稼ぐがフォローには繋がりにくい傾向。
    *   **原則:** インプレッションを伸ばすこととフォロワーを増やすことは別物です。フォロワー増を狙うなら、発信軸に沿った有益な情報提供を心がけましょう。インプレッション重視の投稿は「アカウントを育てる」意味では悪くないが、フォローに繋がらない可能性も考慮します。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

### 成功の原則

1.  **ネタの選定が最も重要**
    *   「ポストが伸びるかどうかはやっぱりネタの選別がもっとも大切」（メルマガ30）。
    *   「伸びるポストで大切なのはやっぱり『ネタ』ということ」（メルマガ59）。
    *   **再現可能な原則:** 「聞いたことあるけどよくわからない」「トレンド」「自分ごと化」「意外性」「下世話な要素」「一次情報・実体験」を意識してネタを探す（セクション1参照）。

2.  **冒頭文で興味を引き、リプへ誘導する構成**
    *   「書き出しがつまらないとポストは伸びない」（メルマガ2）。
    *   「最近のアルゴリズムは、『リプに行ってもらう』がかなり重視されている」（メルマガ7）。
    *   **再現可能な原則:** 冒頭文はインパクト勝負の強い言葉で、内容はシンプルに「気になるところで切って」リプに誘導する（メルマガ2, 7, 14, 26, 35, 36, 38, 39, 40, 41）。

3.  **図解でわかりやすく、視覚的に訴える**
    *   「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4）。
    *   「パッと見でなんのポストかわかるようにするのが良い」（メルマガ30）。
    *   **再現可能な原則:** Nano Banana Proなどのツールを活用し、視覚的に魅力的で理解しやすい図解を作成する。1枚目の図解は特に重要で、文字数を抑え、インパクトを重視する（メルマガ10, 38, 51）。

4.  **「有益＋下世話」の組み合わせ**
    *   有益な情報に、年収やランキングといった「下世話」な要素を加えることで、多くの人の関心を引きます。
    *   **成功事例:**
        *   「都道府県別知事の年収」: **550万インプレッション、16,940名増加**（メルマガ50）。
        *   「新しい内閣の解説（大臣の年収・資産額）」: **141万インプレッション、7805名増加**（メルマガ52）。
    *   **再現可能な原則:** 読者にとって役立つ情報に、人々の好奇心を刺激する要素を巧みに組み合わせる。

5.  **AIをリサーチと作成の強力な味方にする**
    *   「AIのおかげで『発信したいことが発信できるようになった』」（メルマガ12）。
    *   **再現可能な原則:** 複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）を使い分け、リサーチの効率を上げる。AIが苦手な部分（地図の正確性、人物の配置など）はCanvaなどで手動で補完する（メルマガ10, 12, 14, 20, 22, 26, 38, 44, 50, 51, 52, 55）。

6.  **飽きさせない工夫と継続**
    *   「Xは飽きを嫌う傾向がある」（メルマガ16）。
    *   「Xは長距離走」（メルマガ17）。
    *   **再現可能な原則:** 同じようなポストや構文ばかりでなく、たまには図解やマンガ、動画など見せ方を変える。伸びるネタは再投稿する。楽しく発信できるテーマを選び、継続する（メルマガ16, 22, 23, 36, 41）。

### 失敗と反省点

1.  **発信軸とのズレはフォロワー減少に繋がる**
    *   インプレッションは伸びても、発信軸と大きく異なる内容だとフォロワーは減る傾向があります。
    *   **失敗事例:**
        *   「AIにネタを出してもらったポスト」: **24万インプレッション、10名減**（メルマガ13）。
        *   「お金・お得情報でもニュース解説でもないポスト」: **113万インプレッション、69名減**（メルマガ17）。
        *   「女子アナ、フリー転向、年収ランキング」: **92万インプレッション、30名減**（メルマガ18）。
        *   「日本代表の年俸」: **176万インプレッション、119名減**（メルマガ43）。
    *   **反省点:** インプレッション重視の「下世話」なネタは、フォロワー増を目的とする場合は発信軸とのバランスを考慮する必要があります。

2.  **1枚目の図解に情報を詰め込みすぎない**
    *   最初の画像や図解に文字が多すぎると、読者の離脱を招き、リプへの誘導がうまくいきません。
    *   **失敗事例:**
        *   「為替介入」ポストの1枚目の図解に文字を多く入れすぎた: **7万インプレッション、90名増加**（メルマガ11）。
    *   **反省点:** 「スマホを離さずに」「最後の退避勧告」くらいの簡潔さで、リプへ誘導する工夫が必要です（メルマガ11）。

3.  **ネタの対象者やインパクトの不足**
    *   テーマがニッチすぎたり、インパクトが弱かったりすると、広く拡散されにくいです。
    *   **失敗事例:**
        *   「為替介入」という言葉が「自分とは関係なさそう」に感じられ、伸び悩んだ（メルマガ11）。
        *   「ナフサ」の解説は以前伸びなかったが、「ポテチの白黒袋」というインパクトを加えて再投稿したら伸びた（メルマガ10）。
        *   「関東の家賃比較」は伸びたが、関東に絞ったことで対象者が限定的になった可能性（メルマガ54）。
    *   **反省点:** ターゲット層が広く、かつインパクトのあるネタを選ぶことが重要です。

4.  **迷ったら「まずやってみる」**
    *   AIでそっくりな図解が簡単に作れる時代だからこそ、迷っている間に他者に先を越される可能性があります。
    *   **失敗事例:** 「関西の家賃比較」を迷っている間に、他者が引用リポストで209万インプレッションを出した（メルマガ54）。
    *   **反省点:** 「迷ったらやらないと」という意識で、スピード感を持って発信することが大切です。

## 5. 投稿前チェックリスト

てっぺい氏の成功原則と反省点を踏まえ、投稿前に以下の項目を確認しましょう。

### ネタ・テーマに関するチェック

*   [ ] **「聞いたことあるけど、よくわからない」を優しく解説しているか？** (例: 青木率、エプスタイン事件、ナフサ)
*   [ ] **XのトレンドワードやYahoo!ニュースなど、時事ネタに乗っているか？** (例: 国会解散、新たなファイル公開、OPECトレンド)
*   [ ] **読者が「自分ごと」として捉えやすいテーマか？** (例: 都道府県別ランキング、家賃比較、血液型)
*   [ ] **「へー」と思うような意外な事実や「下世話」な要素（年収、ランキングなど）が含まれているか？** (例: 知事の年収、大臣の年収・資産額)
*   [ ] **自身の経験や身近な会話から得た一次情報か？** (例: 妻のパート探し、ホテル知識、娘の実話)
*   [ ] **過去に伸びたネタの再利用を検討しているか？** (見せ方を変えるなど)
*   [ ] **発信軸と大きくズレていないか？** (特にフォロワー増を狙う場合)
*   [ ] **他者のポストのパクリではないか？** (同じネタを使う場合は事前に確認)

### 投稿の構成・型に関するチェック

*   [ ] **冒頭文はインパクトがあり、読み手の興味を強く引き付けているか？** (例: 「断言します」「これを知らないと大損します」「煽り気味の文言」)
*   [ ] **固有名詞や具体的な数字を冒頭文や図解に含めているか？** (例: 55億円、2017年、トランプ大統領)
*   [ ] **1枚目のポストは文字で、リプへの誘導を意識した構成か？** (例: 会話構文、メダル構文)
*   [ ] **1枚目の文字ポストは、読みやすく、文字数を抑え、「気になるところで切って」リプへ誘導しているか？**
*   [ ] **図解はNano Banana Proなどのツールで作成し、視覚的にわかりやすいか？**
*   [ ] **図解は「パッと見で何かわかる」デザインか？** (例: アルファードのイラストを大きく)
*   [ ] **図解に意外な結果や面白い事実が盛り込まれているか？** (例: 小池都知事の年収が最下位)
*   [ ] **必要に応じて1秒動画を添付しているか？** (インプレッション増を狙う場合)
*   [ ] **マンガポストで表現の幅を広げることを検討しているか？** (特にストーリー性のあるネタ)
*   [ ] **知っているものとつなげて説明しているか？** (例: 残クレと通常のローンの比較)

### AI活用に関するチェック

*   [ ] **ネタのリサーチに複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）を活用したか？**
*   [ ] **AIの回答を鵜呑みにせず、比較検討し、より分かりやすいものを採用したか？**
*   [ ] **AIが苦手な図解（地図の正確性、人物の配置など）は手動で工夫・修正したか？**

### その他

*   [ ] **投稿時間は適切か？** (朝の投稿が多いが、昼に伸びることもあるため、投稿後の反応を観察)
*   [ ] **投稿後30分～60分はリプへの返信など交流を意識できるか？** (アルゴリズムで交流が重視される傾向)
*   [ ] **このポストは自分が「楽しく発信できる」内容か？** (継続のために重要)
