# X投稿マニュアル

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏のポストが爆発的に伸び、フォロワーを増やした事例から、以下の法則が抽出されます。重要なのは、単なる情報提供ではなく、**「読者の感情や行動を喚起する要素」**をいかに盛り込むかです。

### 1-1. 読者の「知りたい」を刺激するテーマ
多くの人に共通する「なんとなく聞いたことあるけど、よくわからない」というテーマは、高い関心を引きつけます。
- **具体例:**
    - **政治・経済の難解なニュースを優しく解説:**
        - 「選挙の『青木率』」（メルマガ1）：234万インプレッション、1581名増
        - 「闇が深いエプスタイン事件」（メルマガ4, 33）：144万インプレッション、1652名増 / 63万インプレッション、1003名増
        - 「海外メディアの立ち位置」（メルマガ26）：184万インプレッション、2951名増
        - 「為替介入」（メルマガ11）：7万インプレッション、90名増（伸びは限定的だが、わかりやすさが評価されフォローに繋がった）

        - 「西松屋がわざとガラガラな理由」（メルマガ40）：148万インプレッション、95名増

        - 「残クレアルファード」（メルマガ30）：65万インプレッション、532名増

### 1-2. トレンド・時事性のあるテーマ
Xは「流し読みされる媒体」であり、タイムリーな話題はインプレッションを大きく伸ばします。特に、国内外の大きなニュースや社会情勢はフォロワー増に直結しやすい傾向があります。
- **具体例:**
