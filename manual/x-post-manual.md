# X投稿マニュアル

X(旧Twitter)運用専門家であるてっぺい氏のメルマガ群を横断分析し、再現性のあるX投稿マニュアルを作成しました。てっぺい氏が13万フォロワーを達成し、さらに短期間で大幅なフォロワー増加を実現した秘訣を、具体的な数値実績と考察に基づいて解説します。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の成功事例から見えてくるのは、ターゲット層の「知りたい」という欲求を刺激し、かつ「自分ごと」として捉えやすいテーマを選ぶことです。特に以下の法則が抽出されます。

### 1-1. 普遍的な関心事と「知りたい」欲求の刺激
多くの人が「なんとなく聞いたことはあるけど、よくわからない」「めんどくさそうだけど、ざっくり知っておいた方がいい」と感じるテーマは、高い関心を集めます。
*   **事例1：選挙の「青木率」解説**
    *   「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってることをやさしく解説」し、**234万インプレッション、1581名増**を記録（メルマガ1）。
*   **事例2：エプスタイン事件の解説**
    *   「なんとなく聞いたことあるけどよくわからない」というテーマで、**144万インプレッション、1652名増**（メルマガ4）。「闇が深い」「陰謀論的な要素」も興味を引く要因。
*   **事例3：UAEのOPEC脱退**
    *   「聞いたことある、大切そう、でもよくわからない」を満たし、**60万インプレッション、2010名増**を達成（メルマガ12）。
*   **事例4：ナフサ不足とポテトチップスの白黒袋**
    *   「ナフサ」という「聞いたことある」「大切そう」「でもよくわからない」単語に、「ポテチの白黒袋」というインパクトを加え、**182万インプレッション、603名増**（メルマガ10）。
*   **事例5：韓国大統領の逮捕歴**
    *   「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問を解消する形で、**78万インプレッション、447名増**（メルマガ27）。

### 1-2. トレンドとタイムリーな情報
Xはリアルタイム性が重視されるため、トレンドに乗ったタイムリーなネタは爆発的に伸びる可能性を秘めています。
*   **事例1：国会の冒頭解散に合わせた選挙の「青木率」解説**
    *   国会の冒頭解散という時事ネタに合わせ、**234万インプレッション、1581名増**（メルマガ1）。
*   **事例2：エプスタイン事件の新たなファイル公開**
    *   「1月30日に新たにファイルが350万ページ公開された」という現在進行形のトレンドに乗せ、**144万インプレッション、1652名増**（メルマガ4）。
*   **事例3：フォロワー1000名以上増の5ポストの共通点**
    *   「トレンドにのっている」「ニュース解説」「海外のニュースが多い」が挙げられています（メルマガ8）。
*   **事例4：GW明けのホテル情報**
    *   「ゴールデンウィーク明けはホテルが一番空く時期だな～」という「タイムリーなポスト」で、**60万インプレッション、206名増**（メルマガ9）。
*   **事例5：マイナンバーカードの名前とデザイン変更**
    *   「来年マイナンバーカードの名前とデザインが変わる」というトレンドネタで、初回**655万インプレッション、1114名増**を記録（メルマガ36）。

### 1-3. 「自分ごと」として捉えられる身近なテーマ
読者が「自分に関係がある」「自分も知っておきたい」と感じるネタは、高いエンゲージメントとフォロワー増加に繋がります。
*   **事例1：都道府県別の名門高校**
    *   「高校受験をしてる人は圧倒的に多い」「名門といわれる高校を卒業してる人は、このポストが気になる」「細かすぎて見えないので、図解を拡大してくれる」という要素が重なり、**1ポストで44,654名増**という驚異的な結果に（メルマガ44）。
*   **事例2：都道府県知事の年収**
    *   「あなたの県の知事の年収、知ってますか？」という問いかけと「下世話」な要素で、**550万インプレッション、16,940名増**（メルマガ50）。
*   **事例3：全国のアウトレット**
    *   「アウトレット、あまり見たことない」という新規性と、「対象者が広い」「みんな関心がある」「調べるのめんどくさそう」という要素で、**123万インプレッション、5099名増**（メルマガ51）。
*   **事例4：都道府県別のショッピングセンター比較**
    *   「ショッピングセンターは身近で好きな人が多い」ため、「自分ごとととらえてもらえた」ことで、**194万インプレッション、7,428名増**（メルマガ57）。
*   **事例5：世界の血液型分布**
    *   「全員が必ずどこかに属する」ため「自分ごと」になりやすく、**114万インプレッション、909名増**（メルマガ59）。

### 1-4. 意外性や「下世話」な要素
読者の好奇心を刺激する「意外な事実」や、少し「下世話」に感じるテーマは、インプレッションを大きく伸ばす傾向があります。
*   **事例1：女子アナのフリー転向と年収ランキング**
    *   「女子アナ」「フリー転向」「年収」という「下世話なネタを3つ盛り込んだランキング」で、**92万インプレッション**を記録（メルマガ18）。
*   **事例2：都道府県知事の年収**
    *   「年収」という「下世話」な要素と、小池都知事が最下位という「意外性」が組み合わさり、**550万インプレッション、16,940名増**（メルマガ50）。
*   **事例3：新内閣の顔ぶれと年収・資産額**
    *   「有益っぽいポストに下世話な要素を入れている」ことで、**141万インプレッション**（メルマガ52）。大臣の年収への驚きもリプを誘発。
*   **事例4：大学の世界ランキング**
    *   「東大も、世界だとそれほど上位ではない」という既知の事実から、他の大学のランキングに広げたことで、**124万インプレッション、3728名増**（メルマガ55）。リサーチ結果に「面白い、意外性がある」と伸びる。

### 1-5. 一次情報と専門知識の活用
自身の経験や、ポッドキャスト、YouTube、身近な会話から得た一次情報を元に発信することで、独自性と深みが増します。
*   **事例1：GW明けのホテル情報**
    *   てっぺい氏が「もともとホテルで働いていた」経験から、「ホテルが一番空く時期だな～」という「タイムリーなポスト」を作成（メルマガ9）。
*   **事例2：西松屋の戦略**
    *   「以前、ポッドキャストで聴いていて『わざとガラガラにしてる』というのが面白いと思ってた」ネタを発信（メルマガ40）。
*   **事例3：インドカレー屋さんの秘密**
    *   「以前YouTubeで観た『インドカレー屋さんの秘密』がおもしろかった」ネタを発信（メルマガ41）。
*   **事例4：為替介入の解説**
    *   「じつは自分がはっきりわかってなかった」為替介入を「調べて、それを発信」することで、自分の学びにもなり、楽しく発信できる（メルマガ11）。

### 1-6. AIの活用と限界
AIはリサーチの強力な味方ですが、ネタ出しは人間が行うべき、とてっぺい氏は考えています。
*   **リサーチにAIを活用:**
    *   ChatGPT, Gemini, Perplexity, Grok, Claudeなど複数のAIに質問し、回答を比較検討してまとめる（メルマガ10, 12, 14, 38, 51）。これにより、リサーチ時間を大幅に短縮（メルマガ12）。
*   **ネタ出しは人間が主導:**
    *   「ネタ選びにAIを使ってなかった」が、一度試したところ「いいかも」と思ったのは20個中1つだけ（メルマガ13）。「なんとなく、ネタは自分で考えたいと思ってた」と述べ、ネタ出しは自分で考え、AIはリサーチに使うのが効果的と結論づけています（メルマガ49）。
    *   リサーチ結果に「意外な結果」があるかどうかが、ネタの良し悪しを判断する基準の一つ（メルマガ51, 55）。

## 2. 投稿の構成・型

Xのアルゴリズムやユーザーの行動様式に合わせて、投稿の「見せ方」を常に最適化しています。

### 2-1. 冒頭文の重要性
Xは「流し読みされる媒体」であるため、冒頭文でいかに興味を引きつけるかが勝負です。
*   **原則：冒頭のインパクト勝負**
    *   「どれだけ良い内容を書いていても書き出しがつまらないとポストは伸びません」（メルマガ2, 35）。
    *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」など、読み手の興味を引き付ける言葉を使う（メルマガ2, 35）。
    *   「煽り気味の文言」も有効。マイナンバーカードのポストでは「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という書き出しで**595万インプレッション**を獲得（メルマガ36）。

### 2-2. 文字ポストと図解ポストの使い分け
てっぺい氏の基本は「図解ポスト」ですが、アルゴリズムの変化に合わせて柔軟に型を変化させています。
*   **基本は図解ポスト**
    *   「13万フォロワーを達成した最大の秘密はズバリ『図解ポスト』」（メルマガ5, 37）。
    *   「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
    *   Nano Banana ProやCanva、AIを活用することで、図解作成のハードルが劇的に下がった（メルマガ1, 5, 12, 16, 30）。
*   **最新トレンド：1枚目を文字ポスト、2枚目以降を図解**
    *   「最近は図解のポストよりも文字のポストの方がインプレッションが伸びやすい傾向があります」（メルマガ8）。
    *   「1枚目を文字ポストにして2枚目から図解にするポスト」が伸びやすい印象（メルマガ3）。
    *   「リプに行ってもらう」ことがアルゴリズムで重視されているため、最初のポストは文字にして、リプで図解を見せる構成が有効（メルマガ3, 7, 14, 26, 39, 40, 41）。
    *   1枚目の文字ポストは「メダルの構文か会話構文が良い」（メルマガ3）。
    *   「とにかくリプにいってもらうためのポストなので読みやすく、文字は少なめになるようにして気になるところで切る」（メルマガ38）。
    *   「導入は軽く中身は、図解を使ってわかりやすく有益なこと、面白いことを伝える」という発信が今は良い（メルマガ41）。

### 2-3. 流行りの構文・型の活用
アルゴリズムの変化に対応し、流行りの構文を積極的に取り入れています。
*   **メダル構文**
    *   「流行りのメダルを使った構文」で、以前伸びなかった「個人向け国債」のポストが**334万インプレッション**を記録（メルマガ6）。
    *   「一見、流行りにのってるようで、実は図解で有益なことを伝えるというロールキャペツ系ポスト」として活用。
*   **会話構文**
    *   「1枚目 会話の文字ポスト、2枚目～4枚目 図解ポスト」の形式で、**170万インプレッション、307名増**（メルマガ7）。
    *   「会話は、極力シンプルに気になるところで切って、リプへ」誘導。
    *   「会話構文＋箇条書き＋図解」が伸びる型として紹介（メルマガ42）。
*   **ランキング構文**
    *   「気になるランキングで、少し有益なテーマにする」のは有効（メルマガ22）。
    *   「女子アナのフリー転向と年収ランキング」など、下世話な要素と組み合わせることでインプレッションを伸ばす（メルマガ18）。
*   **マンガポスト**
    *   文字ポストで伸びなかったバレンタインのネタをマンガ化することで、**240万インプレッション、586名増**に（メルマガ29）。ChatGPTでシナリオ作成、専用ツールでマンガ化。
    *   「自分で紹介したいものがある人、マンガで説明するととっつきやすくなる」（メルマガ58）。

### 2-4. 図解の視覚的工夫
図解は「パッと見」で内容がわかるように工夫することが重要です。
*   **パッと見でわかるデザイン**
    *   「パッと見でなんのポストかわかるようにするのが良い」（メルマガ30）。「アルファードのイラストを大きくした」事例。
    *   「トランプ大統領、高市首相のイラストは反応が良い」（メルマガ30）。
*   **知っているものとつなげる**
    *   「残クレアルファード」のポストで「通常のローンとの比較が入ってると『支払い方法の話ね』とわかる」ように工夫（メルマガ30）。
*   **細かすぎて見えない→拡大を促す**
    *   都道府県別の名門高校のポストでは、「細かすぎて見えないので、図解を拡大してくれる」という意図的な工夫が**44,654名増**に繋がった（メルマガ44）。

### 2-5. 動画の活用
Xのアルゴリズムが動画を優遇する傾向があるため、短尺動画の活用も効果的です。
*   **1秒動画の添付**
    *   「赤い矢印が点滅する1秒動画」を添付することで、「ポストが爆発的に伸びる」と解説。マイナンバーカードのポストで活用し、**595万インプレッション**に貢献（メルマガ36）。
    *   「テクニックは『有効だから』みんなが使うもの」。
*   **図解の動画化**
    *   Canvaの「リサイズ」機能で図解を簡単に動画化し、インスタグラムのリール動画として活用。これにより、**21日で21名→14000名**という爆発的なフォロワー増加を実現（メルマガ25, 28）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増加は必ずしも連動せず、それぞれ異なる要因で伸びる傾向があります。

### 3-1. インプレッションを伸ばす投稿の特徴
インプレッションは、より多くのユーザーに投稿が表示されることを意味し、X収益に直結します。
*   **トレンドとインパクト**
    *   「トレンドにのっている」「インパクトの強さ」がある投稿はインプレッションを大きく伸ばします。
    *   **事例：ナフサ不足とポテトチップスの白黒袋**
        *   インパクトの強さで、以前伸びなかったネタが**182万インプレッション**を記録（メルマガ10）。
*   **煽り気味の冒頭文と1秒動画**
    *   「書き出しのインパクトが弱いとどんな内容も見てもらえない」ため、「アンチを恐れずに強い言葉を使う」ことが重要（メルマガ36）。
    *   **事例：マイナンバーカードのポスト**
        *   「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という煽り気味の書き出しと「赤い矢印が点滅する1秒動画」で、**595万インプレッション**を達成（メルマガ36）。
*   **下世話なネタと意外性**
    *   「日経新聞に載ってるようなことより東スポに載ってることの方がいい」という原則が示す通り、ゴシップ性や好奇心を刺激するネタはインプレッションを伸ばしやすいです。
    *   **事例：女子アナのフリー転向と年収ランキング**
        *   「女子アナ」「フリー転向」「年収」という下世話なネタで、**92万インプレッション**を記録（メルマガ18）。
    *   **事例：都道府県知事の年収**
        *   「年収」という下世話な要素と、小池都知事の給与カットという「意外性」で、**550万インプレッション**（メルマガ50）。
*   **流行りの構文**
    *   メダル構文や会話構文など、流行りの型に乗せることでアルゴリズムに優遇され、インプレッションが伸びやすくなります。
    *   **事例：個人向け国債のメダル構文ポスト**
        *   「流行りのメダルを使った構文の力をかりることで多くの方に届けることができた」と述べ、**334万インプレッション**を記録（メルマガ6）。

### 3-2. フォロワー増加につながる投稿の特徴
フォロワー増加は、アカウントの「質」や「専門性」が評価された結果として現れます。
*   **発信軸との合致と有益性**
    *   フォロワー増加には、ユーザーが「このアカウントをフォローすれば、今後も有益な情報が得られる」と感じるような、発信軸に沿った有益な情報提供が不可欠です。
    *   **事例：選挙の「青木率」解説**
        *   「政治系の解説は、比較的フォロワー様も増える傾向にあります」と述べ、**1581名増**を達成（メルマガ1）。
    *   **事例：中東情勢の解説**
        *   「めんどくさそうだけど、ざっくり知っておいた方が良いよな～と思うニュース」を解説することで、**1075名増**（メルマガ23）。
*   **わかりやすさと「自分ごと」化**
    *   難解な情報を「やさしく解説」し、読者が「自分ごと」として捉えられるように工夫することが重要です。
    *   **事例：都道府県別の名門高校**
        *   「高校受験をしてる人は圧倒的に多い」「名門といわれる高校を卒業してる人は、このポストが気になる」といった「自分ごと」化の要素で、**1ポストで44,654名増**という驚異的な結果（メルマガ44）。
    *   **事例：全国のアウトレット**
        *   「対象者が広い」「みんな関心がある」「みんな知りたいと思ってる」「調べるのめんどくさそう」という要素を満たし、**5099名増**（メルマガ51）。
*   **図解ポストの活用**
    *   「図解を使った方がフォローいただく数は多くなる印象があります」（メルマガ8）。視覚的に分かりやすい図解は、内容の理解を助け、フォローに繋がりやすい傾向があります。
    *   **事例：エプスタイン事件の図解ポスト**
        *   「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」と述べ、**1652名増**（メルマガ4）。

### 3-3. インプレッションは伸びたがフォロワーは減った事例とその考察
インプレッションとフォロワー増加は必ずしも連動しないことを示す示唆的な事例です。
*   **事例1：AIにネタ出しをさせたポスト**
    *   **24万インプレッション**を記録したが、**フォロワー様が10名減**（メルマガ13）。
    *   **考察：** 「発信軸とのズレ」や、AIが提案したネタがアカウントのフォロワー層に合致しなかった可能性。てっぺい氏自身も「ネタ選びにAI、使えるのかもしれないけどやり方はもう少し考えなくては」と反省。
*   **事例2：発信軸から外れたエンタメ系ポスト**
    *   「お金・お得情報」でも「ニュース解説」でもないテーマのポストで、**113万インプレッション**を記録したが、**フォロワー様が69名減**（メルマガ17）。
    *   **事例3：女子アナのフリー転向と年収ランキング**
        *   「女子アナ」「フリー転向」「年収」という下世話なネタで、**92万インプレッション**を記録したが、**フォロワー様が30名ほど減**（メルマガ18）。
    *   **考察：** 「発信軸とのズレ」がフォロワー減少の大きな要因。インプレッションは伸びるものの、アカウントの専門性や期待値と異なる内容だったため、フォローには繋がらず、むしろ既存フォロワーの離脱を招いた可能性。てっぺい氏は「Xのアカウントを育てる」という意味では悪くないとしながらも、フォロワー増には軸の重要性を強調。
*   **事例4：ワールドカップ関連のネタ**
    *   ワールドカップネタはインプレッションが伸びるものの、フォロワー増減はまちまち。
    *   「優勝国が8カ国しかない」で**744名増**、「鎌田選手と大谷翔平の年俸」で**386名増**、「森保監督とドーハの悲劇」で**163名増**。
    *   一方で、「ワールドカップで４ゴール」で**17名減**、「日本代表の年俸」で**119名減**（メルマガ43）。
    *   **考察：** てっぺい氏自身も「こうして並べてもどうして増えてどうして減るのかよくわからないです」と述べており、エンタメ性の高い時事ネタはインプレッションは稼ぎやすいが、フォロワー増加への貢献は不安定な傾向がある。ただし、「収益にもなるので、しばらくこのままやってみる」と、インプレッションの重要性も認識。

### 3-4. リポスト・リプのインプレッション効果
*   **リプの重要性**
    *   「リプに行ってもらう」ことがアルゴリズムで重視されている（メルマガ3, 7, 14, 26, 39, 40, 41）。
    *   「伸びそうなポストにリプをしておくとリプのインプレッションが伸びる」現象も確認されており、早い時間にリプをすることはアカウントパワーを上げるのに有効（メルマガ42）。

### 3-5. 再投稿の効果
*   **同じポストの使い回し**
    *   「同じポストは何度も使い回してOK」という原則（メルマガ36）。
    *   **事例：マイナンバーカードのポスト**
        *   3回投稿で合計**1646名増**。初回**1114名増**、2回目**125名増**、3回目**407名増**。タイミングによって反応は変わるが、効果は持続（メルマガ36）。
    *   **事例：バレンタインのネタ**
        *   文字ポストで伸びなかったネタをマンガ化して再投稿し、**240万インプレッション、586名増**に成功（メルマガ29）。
    *   **事例：過去の図解ポストの再利用**
        *   「過去に伸びた図解ポストがある方は、最初のポストを文字の会話にしたことでいいね、インプレッション、フォローともに大きく伸ばすことができた」（メルマガ39）。

### 3-6. 他SNSとの連携効果
*   **インスタグラムの爆伸び**
    *   Xで作成した図解をCanvaのリサイズ機能で動画化し、インスタグラムのリール動画として投稿するだけで、**21日で21名→14000名**のフォロワー増加を達成（メルマガ25, 28）。
    *   「Xで伸びた投稿はやっぱりインスタでも伸びる傾向にある」（メルマガ25）。
    *   Xでフォロワーが減った「日本代表の年俸」のポストが、インスタでは**93万インプレッション**で一番伸びた事例も（メルマガ43）。
*   **その他SNS**
    *   スレッズ、TikTok、YouTubeショートにもXと同じ投稿を流用。インスタほどではないが、スレッズでは**1919名増**（メルマガ28）。
    *   「Xで図解投稿をしてる方、他のSNSもやってみた方がいいです。当たるかもです」（メルマガ19）。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗の分析から、再現性のある原則を導き出します。

### 4-1. 刺さった理由（成功の原則）
*   **「自分ごと」化と共感性**
    *   読者が「自分に関係がある」「自分も知っておきたい」と感じるテーマは、高い共感を生み、フォロワー増加に直結します。
    *   **事例：都道府県別の名門高校**
        *   「高校受験をしてる人は圧倒的に多い」「名門といわれる高校を卒業してる人は、このポストが気になる」という要素が「自分ごと」として捉えられ、**44,654名増**（メルマガ44）。
    *   **事例：ショッピングセンター比較**
        *   「ショッピングセンターは身近で好きな人が多い」ため、「自分ごとととらえてもらえた」ことで**7,428名増**（メルマガ57）。
*   **難解な情報の「やさしい解説」**
    *   「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってることをやさしく解説」する姿勢が、信頼とフォローに繋がります。
    *   **事例：選挙の「青木率」解説**
        *   政治系のとっつきづらい話を優しく解説し、**1581名増**（メルマガ1）。
*   **意外性と「下世話」な要素**
    *   読者の好奇心を刺激する意外な事実や、少し「下世話」なテーマは、インプレッションを大きく伸ばし、話題性を生みます。
    *   **事例：都道府県知事の年収**
        *   「年収」という下世話な要素と、小池都知事が最下位という「意外性」が組み合わさり、**16,940名増**（メルマガ50）。
*   **トレンドとタイムリーな情報**
    *   鮮度の高い情報や、世間の関心が高いトレンドに乗ることで、多くの人にリーチできます。
    *   **事例：エプスタイン事件**
        *   「現在進行形」の事件で、**1652名増**（メルマガ4）。
*   **視覚的なわかりやすさ（図解・マンガ）**
    *   複雑な情報も図解やマンガにすることで、Xの流し読み文化にマッチし、理解を促進します。
    *   **事例：バレンタインのマンガポスト**
        *   文字ポストで伸びなかったネタをマンガ化することで、**240万インプレッション、586名増**に（メルマガ29）。
*   **「楽しんで発信できる」こと**
    *   てっぺい氏自身が「自分の勉強にもなるので発信も楽しくなる」「ポストを作っていて楽しくてそれを喜んでもらえる人がいる」と語るように、発信者が楽しんで取り組むことが、質の高いコンテンツと継続に繋がります（メルマガ1, 11, 23, 22）。

### 4-2. 刺さらなかった理由（失敗と反省点から学ぶ原則）
*   **発信軸とのズレ**
    *   インプレッションは伸びても、アカウントの発信軸と大きく異なるテーマは、フォロワー増加に繋がりにくく、既存フォロワーの離脱を招く可能性があります。
    *   **事例：女子アナの年収ランキング**
        *   「発信軸とのズレ」が原因で、**92万インプレッション**ながら**30名減**（メルマガ18）。「ギャップがあったのかも」と反省。
    *   **事例：AIにネタ出しをさせたポスト**
        *   **24万インプレッション**で**10名減**。これも発信軸とのズレが原因と推測（メルマガ13）。
*   **1枚目の情報過多**
    *   Xのアルゴリズムは「リプにいってもらう」ことを重視するため、最初のポストに情報を詰め込みすぎると、読み飛ばされたり、リプへの誘導が弱まったりします。
    *   **事例：為替介入のポスト**
        *   「1枚目の図解に文字を多く入れすぎた」ことが反省点。もっと「スマホを離さずに」「最後の退避勧告」ぐらいにしておけば、リプにいってもらえたかも（メルマガ11）。
*   **ネタの対象範囲の狭さ**
    *   特定の地域に限定しすぎたり、ニッチすぎるテーマは、多くの人に「自分ごと」として捉えられず、伸び悩むことがあります。
    *   **事例：関東の住みやすい街ランキング**
        *   「関東だけなので全国を網羅してない」「自分ごと化が弱くなる」ことが原因で、思ったほど伸びなかった（**81万インプレッション、1584名増**だが、全国版よりは弱い印象）（メルマガ56）。
*   **用語の簡単すぎ/少なすぎ**
    *   専門性が低すぎたり、情報量が少なすぎると、読者に物足りなさを感じさせ、エンゲージメントが低下する可能性があります。
    *   **事例：投資用語の手書きメモ風図解**
        *   「用語が簡単すぎた」「用語が８つしかないのは少な過ぎた」ことが反省点。次回は「もう少し難しい用語も入れて18個の投資用語で図解を作成する予定」（メルマガ34）。
*   **迷いによる機会損失**
    *   「AIを使ってそっくりな図解が簡単に作れてしまうので迷ったらやらないと」とてっぺい氏が述べるように、良いネタだと思ったら迷わず投稿することが重要です。
    *   **事例：関東の家賃比較**
        *   「関西もやろうかな？でも、弱いかなと思ってるうちに他の方が、私の引用リポストをして209万インプレッションを出してました。迷わずにやれば良かった」（メルマガ54）。

## 5. 投稿前チェックリスト（具体的な確認項目）

てっぺい氏の成功法則と反省点を踏まえ、投稿前に確認すべき具体的な項目をリストアップします。

### 5-1. ネタ・テーマに関するチェック
*   [ ] **「みんなの知りたい」欲求を満たしているか？**
    *   「聞いたことあるけどよくわからない」「大切そう」「でもよくわからない」要素があるか？
    *   「めんどくさそうだけど、ざっくり知っておいた方が良い」ニュースや情報か？
    *   「言われてみれば不思議」な現象や仕組みの解説か？
*   [ ] **「自分ごと」として捉えられるか？**
    *   対象者が広く、多くの人が関心を持つテーマか？
    *   読者の生活や興味に直結する身近な話題か？
    *   特定の地域や属性に限定しすぎていないか？（全国版の方が強い傾向）
*   [ ] **トレンドやタイムリーな情報か？**
    *   XのトレンドワードやYahoo!ニュースなど、今話題になっていることか？
    *   季節やイベントに合わせたタイムリーな情報か？
*   [ ] **意外性や「下世話」な要素があるか？**
    *   リサーチ結果に「えっ」と思うような意外な事実が含まれているか？
    *   年収やランキングなど、読者の好奇心を刺激する「下世話感」があるか？
*   [ ] **一次情報や専門知識を活かしているか？**
    *   自身の経験、ポッドキャスト、YouTube、身近な会話から得た独自の情報か？
    *   自分が「へー」と思った、楽しく発信できる内容か？
*   [ ] **既存の伸びたネタの周辺を攻めているか？**
    *   一度当たったネタの関連テーマや、異なる切り口で深掘りできるか？
*   [ ] **「パクリ」ではないか？**
    *   他者の投稿と酷似していないか？同じネタを使う場合は、可能であれば事前に確認を取る。
*   [ ] **AIはリサーチに活用し、ネタ出しは自分で判断しているか？**
    *   AIにネタ候補を出させるだけでなく、最終的なネタ選定は自分の目で判断しているか？

### 5-2. 投稿の構成・型に関するチェック
*   [ ] **冒頭文にインパクトがあるか？**
    *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」のような興味を引く言葉を使っているか？
    *   煽り気味の文言で、読者の目を引きつけているか？
*   [ ] **「1枚目を文字ポスト、2枚目以降を図解」の型を採用しているか？**
    *   特に図解ポストの場合、1枚目に文字ポストを配置し、リプへの誘導を意識しているか？
    *   1枚目の文字ポストは「メダル構文」や「会話構文」など、流行りの型を取り入れているか？
*   [ ] **リプへの誘導が明確か？**
    *   最初のポストの情報量は少なめにし、「続きはリプで」など、次のアクションを促しているか？
    *   会話ポストの場合、気になるところで会話を区切っているか？
*   [ ] **図解は視覚的にわかりやすいか？**
    *   「パッと見でなんのポストかわかる」デザインになっているか？
    *   イラストや画像で内容を直感的に伝えているか？（例：アルファードのイラスト）
    *   知っているものとつなげて、理解のハードルを下げているか？
    *   細かすぎて見えない部分を意図的に作り、拡大を促しているか？
*   [ ] **流行りの構文（会話、メダル、ランキングなど）を効果的に使っているか？**
    *   アルゴリズムの変化に合わせて、見せ方を柔軟に変えているか？
*   [ ] **1秒動画を添付しているか？**
    *   Xが動画を優遇する傾向を考慮し、可能な場合は1秒動画を添付しているか？
*   [ ] **マンガポストも検討したか？**
    *   文字で伝えにくいストーリー性のあるネタや、親しみやすさを出したい場合にマンガ化を検討したか？
*   [ ] **文字は読みやすく、漢字の比率は適切か？**
    *   「読みやすく、文字は少なめ」を意識し、漢字を多用しすぎていないか？（直接言及はないが、てっぺい氏の投稿から推測される原則）
*   [ ] **固有名詞や数字を効果的に使っているか？**
    *   具体的な数字（例：55億円、2017年）や固有名詞（例：Netflix、トランプ大統領）でリアリティや興味を引いているか？

### 5-3. 投稿後の運用に関するチェック
*   [ ] **投稿後30分～60分の交流を意識しているか？**
    *   リプへの返信をできるだけ早く行い、エンゲージメントを高めているか？
    *   伸びそうなポストには、自分自身もリプをしてインプレッションを伸ばすことを意識しているか？
*   [ ] **他SNSへの展開を検討しているか？**
    *   Xの図解ポストをCanvaで動画化し、インスタグラム（リール、ストーリー）、TikTok、YouTubeショート、スレッズなどにも投稿しているか？
*   [ ] **再投稿を計画しているか？**
    *   一度伸びたポストは、1ヶ月程度期間を空けて再投稿することを検討しているか？
    *   再投稿の際は、冒頭文や構文など「見せ方」を変えて試しているか？
