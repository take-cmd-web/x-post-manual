# X投稿マニュアル

X(旧Twitter)運用の専門家であるてっぺい氏のメルマガ群を横断分析し、再現性のあるX投稿マニュアルを作成しました。てっぺい氏の成功事例と反省点から抽出された原則を参考に、効果的なX運用を目指しましょう。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びるネタには共通の法則があります。自身の発信軸にとらわれず、ユーザーの興味関心に深く刺さるテーマを見つけることが重要です。

*   **「とっつきづらいけど、ちょっと知っておいた方がいいよな」テーマを優しく解説する**
    *   例：「政治系の、とっつきづらい話をやさしく解説する発信は、一定の需要がある」（メルマガ1）
    *   例：「めんどくさそうだけど、ざっくり知っておいた方が良いよな～と思うニュース」（メルマガ23）
    *   **実例:** 「選挙の『青木率』」（234万インプレッション、1581名増、メルマガ1）、「為替介入」（7万インプレッション、90名増、メルマガ11）など。インプレッションが伸びなくても「わかりやすい」と評価され、フォローにつながるケースもあります。
*   **「なんとなく聞いたことあるけど、よくわからない」テーマを選ぶ**
    *   例：「闇が深いエプスタイン事件。『なんとなく聞いたことあるけどよくわからない』もの」（メルマガ4, 33）
    *   例：「『ナフサ』という単語は『聞いたことある』『大切そう』『でもよくわからない』を満たしてるので、いいネタ」（メルマガ10）
    *   例：「『残クレ』アルファード。よく聞くけどよくわからない、ちょっと気になること」（メルマガ30）
    *   **実例:** 「エプスタイン事件」（144万インプレッション、1652名増、メルマガ4, 32, 33）。
*   **トレンドに乗った時事ネタ・ニュース解説（特に海外ニュース）**
    *   てっぺい氏の「1000名様以上フォロー増加ポスト5本」は全て「トレンドにのっている」「ニュース解説」という共通点があります。（メルマガ8）
    *   「海外のニュースが多い」傾向も指摘されています。（メルマガ8）
    *   **実例:**
        *   「高市首相の解散総選挙」（1581名増、メルマガ8）
        *   「エプスタイン事件」（1652名増、メルマガ8）
        *   「海外メディアのイラン攻撃報道」（2951名増、メルマガ8, 26）
        *   「中東情勢の解説」（1075名増、メルマガ8, 23）
        *   「UAEがOPECを脱退」（3067名増、メルマガ8, 12）
        *   「ナフサ不足」（182万インプレッション、603名増、メルマガ10）
        *   「韓国大統領の逮捕」（78万インプレッション、447名増、メルマガ27）
    *   **ポイント:** 朝起きてトレンドワードを確認し、伸びそうなネタがあれば優先的に発信します。（メルマガ10）
*   **インパクトの強さや「闇の深さ」「陰謀論的な要素」があるネタ**
    *   例：「ポテトチップスの袋が白黒になるニュースがあったのでインパクトの強さから、これで発信することを決めました」（メルマガ10）
    *   例：「闇が深いエプスタイン事件」「陰謀論的な要素を入れたのも良かった」（メルマガ4, 33）
    *   **実例:** 「エプスタイン事件」（144万インプレッション、1652名増、メルマガ4, 32, 33）。
*   **本業のちょっとした知識で誰かの役に立つ情報**
    *   例：「ホテルで宿泊の担当をしていた人にとって、オフシーズンの情報は常識。ただ、普通の人はあまり知らない情報」（メルマガ9）
    *   **実例:** 「ゴールデンウィーク明けはホテルが一番空く時期」（60万インプレッション、206名増、メルマガ9）。
*   **「下世話なネタ」はインプレッションを伸ばしやすい**
    *   例：「女子アナ」「フリー転向」「年収」という下世話なネタを3つ盛り込んだランキングは伸びる。（メルマガ18）
    *   **実例:** 「女子アナのフリー転向後の年収ランキング」（92万インプレッション、30名減、メルマガ18）。ただし、発信軸とのズレが大きいとフォロワー減につながる可能性もあります。
*   **固有名詞や数字を含める**
    *   「トランプ大統領」「高市首相」などの固有名詞や、「年収」などの具体的な数字は反応が良い傾向にあります。（メルマガ18, 30）
*   **AIを活用したネタ探し**
    *   過去に伸びたポストをAIに読み込ませて分析させ、ネタ候補を出してもらうことも有効です。（メルマガ13）
    *   **実例:** AIに500名以上にフォローされた12個のポストを分析させ、ネタを出してもらった結果、「24万インプレッション、10名減」のポストが生まれました。（メルマガ13）
*   **「楽しんで発信できる」テーマを選ぶ**
    *   自分が「そうなんだ」「学んだこと」をわかりやすく発信することは、自分の学びにもなり、楽しく発信を続けるコツです。（メルマガ11, 22, 23）

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭のインパクトと、ユーザーを次のアクション（リプへ誘導など）に繋げる構成が重要です。

### 冒頭文の作り方
*   **インパクト勝負の断言・煽り文句**
    *   読み手の興味を引き付ける強い言葉を使います。
    *   **例:** 「断言します」「これを知らないと大損します」「私コレで月10万円得しました」（メルマガ2, 35）
    *   **実例:** 「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という煽り気味の文言で「595万インプレッション、407名増」を達成。（メルマガ36）
    *   アンチのリプが増える可能性もありますが、それが拡散につながる「チャンス」と捉え、恐れずに強い言葉を使うことが推奨されています。（メルマガ36）
*   **リプへの誘導を意識した冒頭文**
    *   最近のアルゴリズムは「リプに行ってもらう」ことを重視しているため、冒頭文は短く、気になるところで切ってリプへ誘導する構成が効果的です。（メルマガ3, 7, 14, 26）

### 投稿の型
*   **図解ポスト（フォロワー増の鍵）**
    *   てっぺい氏が「13万フォロワーを達成した最大の秘密」と語るのが図解ポストです。（メルマガ5, 37）
    *   「アルゴリズム的に『図解は伸びづらい』と言われているが、図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）
    *   **ポイント:** 図解は「パッと見でなんのポストかわかるようにする」ことが大切です。例えば、アルファードのイラストを大きくするなど。（メルマガ30）
    *   **実例:**
        *   「高市首相の解散総選挙」図解ポスト：234万インプレッション、1581名増（メルマガ1）
        *   「海外メディアのイラン攻撃報道」図解ポスト：184万インプレッション、2951名増（メルマガ26）
        *   「UAEのOPEC脱退」図解ポスト：60万インプレッション、2010名増（メルマガ12）
*   **文字ポスト（インプレッション増の傾向）**
    *   最近は「図解のポストよりも文字のポストの方がインプレッションが伸びやすい傾向」があります。（メルマガ3, 8）
    *   X収益を伸ばしたい場合は、文字ポストも有効な選択肢です。（メルマガ3, 8）
*   **「ロールキャベツ系ポスト」（1枚目文字＋2枚目以降図解）**
    *   「1枚目を文字ポストにして2枚目から図解にする」という新しい試みです。（メルマガ3, 6, 8）
    *   1枚目で「流行りの構文」を使い、リプで有益な図解を見せることで、インプレッションとフォロワー増の両方を狙います。（メルマガ6）
    *   **実例:** 「個人向け国債 変動10年」のメダル構文ポスト：334万インプレッション、417名増（メルマガ6）
    *   **ポイント:** 1枚目の文字ポストは「メダルの構文」か「会話構文」が良いとされています。（メルマガ3）
*   **会話ポスト**
    *   1枚目を会話の文字ポスト、2枚目以降を図解ポストにする構成です。（メルマガ7）
    *   会話は極力シンプルに、気になるところで切ってリプへ誘導することを意識して作成します。（メルマガ7）
    *   **実例:** 「社会保険の扶養」に関する会話ポスト：170万インプレッション、307名増（メルマガ7）
*   **マンガポスト**
    *   文字ポストをマンガ化することで、過去に伸びなかったネタが爆伸びする可能性があります。（メルマガ29）
    *   AI（ChatGPTなど）で文字ポストを読み込ませ、マンガのシナリオを作成できます。（メルマガ29）
    *   **実例:** バレンタインの文字ポスト（7.4万インプレッション、34名減）をマンガ化したら「240万インプレッション、586名増」を達成。（メルマガ29）
*   **その他構文**
    *   メダル構文、◯×構文、国旗構文、Tier、ランキングなど、流行りの構文を試すことも有効です。（メルマガ6）
    *   「手書きメモ風」の図解など、見せ方を変えることで既視感のあるネタでも目新しく見せられます。（メルマガ34）
*   **リプへの誘導**
    *   「いかにリプにいってもらうか」がアルゴリズムで重視されています。（メルマガ26）
    *   最初のポストにつける図解の情報量は少なめにして、リプで詳細を解説するなど、誘導を意識した構成にします。（メルマガ26）
    *   1枚目の画像はインパクト重視で、難しいことは書かず、ほぼ画像にしてリプで解説する手法も有効です。（メルマガ10）
*   **AI活用による作成効率化**
    *   複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）に質問し、回答の良い部分を組み合わせて原稿を作成します。（メルマガ10, 12, 14, 20, 22, 26）
    *   Nano Banana Pro/2などのツールを活用することで、図解作成のスピードが圧倒的に早くなります。（メルマガ1, 4, 5, 10, 12, 14, 16, 20, 21, 26, 27, 30, 32, 33, 37）
    *   AIの恩恵により「発信したいことが発信できるようになった」とてっぺい氏は語っています。（メルマガ12, 20）
*   **飽きさせない工夫**
    *   Xは「飽きを嫌う傾向がある」ため、同じようなポストや構文ばかりでなく、たまには図解を使ってみるなど、見せ方を変えることが重要です。（メルマガ16）
*   **他SNSへの展開**
    *   Xで作成した図解は、Canvaのリサイズ機能で簡単にインスタグラムのリール動画に変換でき、他のSNS（Threads, TikTok, YouTubeショート）にも流用可能です。（メルマガ16, 19, 25, 28, 29）
    *   **実例:** てっぺい氏のインスタグラムは「21日間で21名→14000名」に増加。X用の投稿をそのまま動画に変えただけで爆伸びしました。（メルマガ25）

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも一致せず、それぞれを伸ばすための戦略が異なります。

### インプレッションを伸ばす投稿の傾向
*   **トレンド性・時事性**
    *   トレンドに乗ったポストは爆発的なインプレッションを生み出します。
    *   **実例:** 「個人向け国債 変動10年」のメダル構文ポストは「334万インプレッション」（メルマガ6）。「マイナンバーカード」の名称変更ネタは「595万インプレッション」（メルマガ36）。
*   **インパクトの強いネタ・画像**
    *   「ポテチの白黒袋」のような視覚的インパクトの強い画像や、「女子アナの年収」のような下世話なネタはインプレッションを伸ばしやすいです。（メルマガ10, 18）
*   **流行りの構文・見せ方**
    *   メダル構文や1秒動画など、Xのアルゴリズムをハックするようなテクニックはインプレッションを大きく伸ばします。（メルマガ6, 36）
    *   **実例:** 赤い矢印が点滅する1秒動画を添付した「マイナンバーカード」のポストは「595万インプレッション」を達成。（メルマガ36）
*   **文字ポストの優位性**
    *   最近は「図解よりも文字の方が伸びやすいような気がする」とてっぺい氏も述べており、X収益を狙う場合は文字ポストも有効です。（メルマガ3, 8, 16）
*   **動画の優遇**
    *   X社は動画を優遇する傾向があるため、1秒動画の添付はインプレッションを加速させます。（メルマガ36）

### フォロワー増につながる投稿の傾向
*   **「とっつきづらいけど知っておきたい」テーマの「わかりやすい」解説**
    *   ユーザーが「知りたい」と思っているが、自分で調べるのが面倒な情報を、図解などで噛み砕いて提供するポストはフォローにつながりやすいです。（メルマガ1, 11, 23）
    *   **実例:** 「為替介入」のポストは「7万インプレッション」と伸びは控えめでしたが、「90名増」とフォロー獲得につながりました。これは「わかりやすい」と評価されたためと分析されています。（メルマガ11）
*   **ニュース解説（特に海外の時事ネタ）**
    *   てっぺい氏の「1000名様以上フォロー増加ポスト5本」は全てニュース解説であり、特に海外の時事ネタが多いです。（メルマガ8）
    *   **実例:**
        *   「海外メディアのイラン攻撃報道」：184万インプレッション、**2951名増**（メルマガ26）
        *   「UAEのOPEC脱退」：60万インプレッション、**2010名増**（メルマガ12）
        *   「エプスタイン事件」：144万インプレッション、**1652名増**（メルマガ4, 32, 33）
        *   「高市首相の解散総選挙」：234万インプレッション、**1581名増**（メルマガ1）
        *   「中東情勢の解説」：58万インプレッション、**1075名増**（メルマガ23）
*   **発信軸との整合性**
    *   発信軸と大きくズレたポストは、インプレッションが伸びてもフォロワー増にはつながりにくい、あるいはフォロワーが減る傾向があります。（メルマガ1, 17, 18）
    *   ただし、政治系の解説は、てっぺい氏の「お金とお得情報」という軸から少し外れてもフォロワーが増える傾向がある、という例外も指摘されています。（メルマガ1）
*   **図解ポストの有効性**
    *   「図解を使った方がフォローいただく数は多くなる印象がある」とてっぺい氏は述べています。（メルマガ8）
    *   図解ポストは「1ポストで1581フォロワー増加」も可能とされています。（メルマガ5）
*   **「他の人があまり発信してない」ネタ**
    *   競合が少ないユニークな視点のネタは、フォロー獲得に繋がりやすいです。（メルマガ32）
*   **「リプにいってもらう」工夫**
    *   リプへの誘導がアルゴリズムで優遇されるため、結果的にフォロワー増にも貢献します。（メルマガ3, 7, 14, 26）

### インプレッションとフォロワー増の関係性
*   **両者は別物として捉える**
    *   てっぺい氏自身も「インプレッションは伸びてもフォローはされない」ケースを経験しており、両者は必ずしも連動しません。（メルマガ1）
*   **インプレッションは伸びたがフォロワーは減った事例**
    *   **事例1:** 「AIにネタを出してもらったポスト」
        *   24万インプレッション、**10名減**（メルマガ13）
        *   **考察:** ネタ選びにAIを使ってみたものの、質が伴わなかった可能性。フォロワーが減る原因として、フォロー数が増えると毎日一定数減る傾向があること、Xの凍結増加も挙げられています。（メルマガ13, 17）
    *   **事例2:** 「お金・お得情報」でも「ニュース解説」でもないポスト
        *   113万インプレッション、**69名減**（メルマガ17）
        *   **考察:** 発信軸とのズレが主な要因。インプレッションは伸びても、アカウントの専門性と合わないとフォローにはつながりません。
    *   **事例3:** 「女子アナのフリー転向後の年収ランキング」
        *   92万インプレッション、**30名減**（メルマガ18）
        *   **考察:** 「下世話なネタ」でインプレッションは伸びたものの、普段の「お金とお得情報」「ニュース解説」という発信軸とのギャップが大きすぎたため、フォロワー減につながったと分析されています。
*   **インプレッションを伸ばすことの意義**
    *   フォロワー増に直結しなくても、インプレッションを伸ばすことは「Xのアカウントを育てる」という意味で悪くありません。（メルマガ18）
    *   X収益を狙う場合は、インプレッションは直接的な収益につながります。（メルマガ3, 8）

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

てっぺい氏の経験から、投稿の成功と失敗には明確な理由があります。これらを原則として理解し、自身の投稿に活かしましょう。

### 刺さった理由（成功事例）
*   **ネタの選定**
    *   **「なんとなく知ってるけど、よくわからない」を優しく解説:**
        *   **実例:** 「エプスタイン事件」は「なんとなく聞いたことあるけどよくわからない」ものとして、144万インプレッション、1652名増を達成。（メルマガ4, 33）
        *   **原則:** 多くの人が興味を持ちつつも、調べる手間を惜しむようなテーマは、わかりやすく解説することで高いエンゲージメントとフォローにつながります。
    *   **トレンド・時事性:**
        *   **実例:** 「1月23日の国会の冒頭解散」に合わせて「青木率」を解説し、234万インプレッション、1581名増。（メルマガ1）
        *   **原則:** タイムリーな話題は、ユーザーの関心が高く、拡散されやすい傾向があります。朝のトレンドチェックは必須です。（メルマガ10）
    *   **インパクト・意外性:**
        *   **実例:** 「ナフサ不足」というニュースに「ポテトチップスの袋が白黒になる」というインパクトのある要素を組み合わせ、182万インプレッション、603名増。（メルマガ10）
        *   **原則:** 視覚的なインパクトや、意外性のある情報は、ユーザーの目を引き、ポストを読んでもらうきっかけになります。
    *   **一次情報・自身の経験:**
        *   **実例:** 元ホテル勤務の経験から「ゴールデンウィーク明けはホテルが一番空く時期」という情報を発信し、60万インプレッション、206名増。（メルマガ9）
        *   **原則:** 自身の専門知識や経験に基づく一次情報は、他にはない価値を提供し、信頼性を高めます。
    *   **共感・興味を引く要素:**
        *   **実例:** 「懐かしい番組」を並べることで、フジテレビの栄枯盛衰のポストが140万インプレッション、565名増。（メルマガ20）
        *   **原則:** ユーザーの記憶や感情に訴えかける要素は、エンゲージメントを高めます。
    *   **固有名詞や数字:**
        *   **実例:** 「女子アナ」「フリー転向」「年収」といった固有名詞や数字は、下世話なネタでもインプレッションを伸ばす力があります。（メルマガ18）
        *   **原則:** 具体的な固有名詞や数字は、情報の具体性を高め、興味を引きつけます。
*   **投稿の構成・表現**
    *   **冒頭文のインパクト:**
        *   **実例:** 「『マイナンバーカード』がなくなることを知らない人が多すぎる。」という煽り文句で595万インプレッション、407名増。（メルマガ36）
        *   **原則:** 冒頭で読み手の興味を掴むことが、ポストが読まれるかどうかの分かれ目です。（メルマガ2, 35）
    *   **図解による「わかりやすさ」:**
        *   **実例:** 「為替介入」という難しいテーマを図解でわかりやすく解説した結果、インプレッションは控えめでも90名増とフォローにつながった。（メルマガ11）
        *   **原則:** 複雑な情報を視覚的に整理し、簡潔に伝えることで、ユーザーの理解を深め、有益だと感じてもらいやすくなります。
    *   **リプへの誘導:**
        *   **実例:** 「海外メディアの立ち位置」ポストで、詳細情報をリプに回すことで184万インプレッション、2951名増。（メルマガ26）
        *   **原則:** 最初のポストで全てを語らず、続きをリプに置くことで、ユーザーの滞在時間を延ばし、アルゴリズムに評価されやすくなります。
    *   **見せ方の工夫（構文・形式の変更）:**
        *   **実例:** 過去に伸びなかったバレンタインの文字ポスト（7.4万インプレッション、34名減）をマンガ化したら、240万インプレッション、586名増を達成。（メルマガ29）
        *   **原則:** 同じネタでも、メダル構文、会話構文、マンガ、手書き風図解など、見せ方を変えることで、新鮮さを与え、再評価されることがあります。（メルマガ6, 16, 29, 34）
    *   **1秒動画の活用:**
        *   **実例:** 「マイナンバーカード」のポストに赤い矢印が点滅する1秒動画を添付し、595万インプレッションを達成。（メルマガ36）
        *   **原則:** Xが動画を優遇する傾向があるため、短い動画を添付することでポストの露出が増加します。
*   **AIの活用**
    *   **実例:** 複数のAI（ChatGPT, Gemini, Perplexity, Grok, Claude）を使い分け、リサーチから図解作成までを効率化。（メルマガ10, 12, 14, 20, 22, 26）
    *   **原則:** AIはネタのリサーチ、構成案作成、図解の原稿作成など、投稿作成のあらゆる段階で強力な味方となります。

### 刺さらなかった理由（失敗・反省点ありの回）
*   **ネタの選定**
    *   **「自分とは関係なさそう」と感じるテーマ:**
        *   **実例:** 「為替介入」という言葉が、多くの人にとって「自分とは関係なさそう」と感じられたため、あまり伸びなかった。（メルマガ11）
        *   **原則:** 専門的なテーマでも、いかに自分ごととして捉えてもらえるか、身近な例えで説明できるかが重要です。
    *   **発信軸とのズレ:**
        *   **実例:** 「お金・お得情報」でも「ニュース解説」でもないポストは、113万インプレッションと伸びたものの、69名減となった。（メルマガ17）
        *   **実例:** 「女子アナのフリー転向後の年収ランキング」は92万インプレッションと伸びたが、30名減。（メルマガ18）
        *   **原則:** インプレッションは稼げても、アカウントの専門性やフォロワー層と大きく乖離した内容は、フォロー解除につながる可能性があります。
*   **投稿の構成・表現**
    *   **1枚目の図解に文字を入れすぎた:**
        *   **実例:** 「為替介入」のポストで、1枚目の図解に文字を多く入れすぎたことが反省点として挙げられている。（メルマガ11）
        *   **原則:** 冒頭の画像や図解は、目に止まることを最優先し、情報量は最小限に抑え、詳細はリプで展開する方が効果的です。
    *   **図解の情報量が多すぎる（リプ誘導の妨げ）:**
        *   **実例:** 「海外メディアの立ち位置」ポストで、当初イラン攻撃の報道の仕方まで一覧に入れようとしたが、情報が多くなりすぎるためリプに回した。（メルマガ26）
        *   **原則:** 最初のポストで情報過多になると、ユーザーが離脱しやすくなります。リプへの誘導を意識し、情報を小分けに提供しましょう。
    *   **用語が簡単すぎた・数が少なすぎた:**
        *   **実例:** 「手書きメモ風」の投資用語図解で、「用語が簡単すぎた」「8つしかないのは少なすぎた」と反省点として挙げられている。（メルマガ34）
        *   **原則:** ターゲット層の知識レベルに合わせて、適切な難易度と情報量を提供することが重要です。
*   **その他**
    *   **フォロワーの自然減:**
        *   **実例:** フォロワーが増えても、基本的に毎日一定数は減る傾向があります。Xの凍結増加も影響している可能性。（メルマガ13, 17）
        *   **原則:** フォロワー数の増減に一喜一憂せず、長期的な視点で良いポストを作り続けることが大切です。

## 5. 投稿前チェックリスト

投稿前に以下の項目を確認し、てっぺい氏の成功法則を最大限に活用しましょう。

### ネタ・テーマ
*   [ ] **「なんとなく知ってるけど、よくわからない」テーマか？**
    *   例: エプスタイン事件、ナフサ不足、残クレアルファードなど。
*   [ ] **トレンドに乗った時事ネタ・ニュース解説か？**
    *   特に海外ニュースはフォロワー増に繋がりやすい傾向があります。
*   [ ] **インパクトの強さや「闇の深さ」「陰謀論的な要素」があるか？**
*   [ ] **自身の専門知識や経験に基づく一次情報か？**
*   [ ] **固有名詞や具体的な数字を含んでいるか？**
    *   例: 女子アナ、年収、特定の事件名など。
*   [ ] **ターゲットユーザーにとって「自分ごと」として捉えられるか？**
    *   専門用語を身近な例えで説明できるか。
*   [ ] **AI（ChatGPT, Gemini, Perplexity, Grok, Claudeなど）でリサーチし、多角的な情報を収集したか？**
*   [ ] **発信していて「楽しい」と感じる内容か？**
    *   楽しんで継続できるテーマは、長期的な運用に不可欠です。

### 投稿の構成・表現
*   [ ] **冒頭文はインパクトがあるか？**
    *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」のような強い言葉を使っているか。
    *   「あおり気味の文言」で興味を引き付けているか。
*   [ ] **「リプにいってもらう」ことを意識した構成か？**
    *   冒頭文は短く、気になるところで切っているか。
    *   1枚目の図解/画像の情報量は最小限に抑え、詳細はリプで展開する構成か。
*   [ ] **1枚目の図解/画像は目に止まるか？**
    *   パッと見で何のポストか分かるように、大きなイラストや画像を使っているか。
    *   文字を入れすぎていないか。
*   [ ] **図解はNano Banana Pro/2などのツールで作成したか？**
    *   「わかりやすさ」を追求したデザインになっているか。
*   [ ] **流行りの構文（メダル構文、会話構文、ランキングなど）を活用しているか？**
    *   マンガポストへの変換も検討したか。
*   [ ] **必要に応じて1秒動画を添付しているか？**
    *   Xのアルゴリズム優遇を意識しているか。
*   [ ] **発信軸と大きくズレていないか？（特にフォロワー増を狙う場合）**
    *   インプレッション目的とフォロワー増目的を明確に区別しているか。
*   [ ] **過去に伸びたポストの再投稿を検討したか？**
    *   同じネタでも、見せ方を変えたり、タイミングを変えたりすることで再評価される可能性があります。
*   [ ] **漢字の比率は適切か？**
    *   直接的な言及はないものの、「わかりやすさ」を重視するてっぺい氏のスタイルから、読みやすい漢字とひらがなのバランスを意識しましょう。

### 投稿後アクション
*   [ ] **投稿後の30分、60分はリプへの返信を多めにする準備はできているか？**
    *   アルゴリズムで交流が重視されるため、初期のエンゲージメントを高めることが重要です。
*   [ ] **Xだけでなく、Instagram、Threads、TikTok、YouTubeショートなど、他のSNSへの展開を検討しているか？**
    *   Canvaのリサイズ機能などで、Xの図解を動画形式に変換し、効率的に多角展開できるか。
