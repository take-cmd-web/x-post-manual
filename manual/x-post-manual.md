# X投稿マニュアル

X(旧Twitter)運用でフォロワー13万人を達成した「てっぺい」氏のメルマガ分析に基づき、再現性のある投稿マニュアルをまとめました。てっぺい氏の成功事例と反省点から抽出された原則を、具体的な数値実績とともに解説します。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏のポストが伸びるかどうかは「ネタの選別がもっとも大切」と繰り返し述べられています。以下の法則を意識してネタを選びましょう。

### 1-1. ターゲットの「知りたい」を刺激するテーマ
多くの人が「なんとなく聞いたことはあるけど、よくわからない」「とっつきづらいけど、ちょっと知っておいた方がいいよな」と感じるテーマは、インプレッションとフォロワー増の両方につながりやすい傾向があります。
- **事例**:
    - **選挙の「青木率」解説** (メルマガ1): 「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってることをやさしく解説」し、**234万インプレッション、1581名増**。
    - **エプスタイン事件解説** (メルマガ4, 32, 33): 「なんとなく聞いたことあるけど、よくわからない」闇の深い事件を解説し、**144万インプレッション、1652名増**（メルマガ4）。
    - **UAEのOPEC脱退解説** (メルマガ12): 「聞いたことある、大切そう、でも、よくわからない」を満たし、**60万インプレッション、2010名増**。
    - **残クレアルファード解説** (メルマガ30): 「よく聞くけど、よくわからない、ちょっと気になること」をテーマにし、**65万インプレッション、532名増**。

### 1-2. トレンド・時事ネタを捉える
XのトレンドワードやYahoo!ニュースから、世間の関心が高い時事ネタを積極的に取り入れることで、爆発的なインプレッションとフォロワー増が期待できます。特に「海外のニュース」はフォロワーが増えやすい傾向にあります。
- **事例**:
    - **海外メディアのイラン攻撃報道** (メルマガ8, 26): トレンドに乗り、ニュース解説として**184万インプレッション、2951名増**を記録。
    - **高市首相の解散総選挙** (メルマガ8): トレンドに乗り、ニュース解説として**1581名増**。
    - **エプスタイン事件** (メルマガ32): 「1月30日に新たな文書が公開されたトレンド」に乗り、**110万インプレッション、1652名増**。
    - **ナフサ不足とポテトチップスの白黒袋** (メルマガ10): 「トレンドワードに『ナフサ不足』があり、ポテトチップスの袋が白黒になるニュースがあったのでインパクトの強さから発信」し、**182万インプレッション、603名増**。
    - **韓国大統領が逮捕される理由** (メルマガ27): 「みんなも『どうして？』と思ってることをトレンドに乗せて発信」し、**78万インプレッション、447名増**。

### 1-3. 「下世話」な要素や意外性を加える
多くの人が興味を持つ「下世話」な要素（年収、ランキングなど）や、意外な事実を盛り込むことで、ポストの注目度を飛躍的に高めることができます。
- **事例**:
    - **女子アナフリー転向年収ランキング** (メルマガ18): 「女子アナ」「フリー転向」「年収」という「下世話なネタを3つ盛り込んだランキング」で**92万インプレッション**を記録。ただし、発信軸とのズレからフォロワーは**30名減**。
    - **都道府県知事の年収ランキング** (メルマガ50): 「『年収』という『下世話』な感じ」を意識し、「東京の小池都知事が、給与をカットしていて47都道府県で最下位」という意外性も加わり、**550万インプレッション、16,940名増**。
    - **新内閣の解説** (メルマガ52): 大臣の「年収」「資産額」という下世話な要素と、大臣の年収が意外と低いという驚きを加え、**141万インプレッション、7805名増**。

### 1-4. 一次情報や自身の経験から生まれる「共感」
自身の経験や身近な出来事から得た一次情報、または「自分も『へー』と思った」内容は、読者の共感を呼びやすく、質の高いポストにつながります。
- **事例**:
    - **妻のパート探しと社会保険の扶養** (メルマガ7): 「あまり働きたくない妻が今、パートを探してます」というリアルな一次情報から発信し、**170万インプレッション、307名増**。
    - **ホテルのオフシーズン情報** (メルマガ9): 「本業のちょっとした知識で誰かの役に立つような情報」を発信し、**60万インプレッション、206名増**。
    - **為替介入** (メルマガ11): 自身が「はっきりわかってなかった」ことを調べて発信し、インプレッションは**7万**と伸びなかったものの、フォロワーは**90名増**。「わかりやすい」と思われた結果と考察。
    - **バレンタインの漫画ポスト** (メルマガ29): 「娘から聞いた実話」を漫画化し、**240万インプレッション、586名増**。

### 1-5. 過去の成功ネタの再利用と見せ方の工夫
一度伸びたネタは、形を変えて再投稿することで、再び大きな反響を得られる可能性があります。「Xは飽きを嫌う傾向がある」ため、同じ内容でも見せ方を変えることが重要です。
- **事例**:
    - **マイナンバーカードの名称変更** (メルマガ36): 「来年マイナンバーカードの名前とデザインが変わる」というネタを3回投稿。
        - 1回目: **655万インプレッション、1114名増**
        - 2回目: **213万インプレッション、125名増**
        - 3回目: **595万インプレッション、407名増**
        合計で**1646名増**。
    - **バレンタインの漫画ポスト** (メルマガ29): 以前文字ポストで**74000インプレッション、34名減**だったものが、漫画にすることで**240万インプレッション、586名増**に「よみがえった」。
    - **過去の図解ポストを1枚目文字ポストに再投稿** (メルマガ3): 「過去の伸びたポストを1枚目だけ文字ポストにして再投稿」し、**59万インプレッション、283名増**。

### 1-6. AIはリサーチに活用し、ネタ出しは自分で
てっぺい氏はAI（ChatGPT, Gemini, Perplexity, Grok, Claudeなど）をリサーチ時間の短縮に活用していますが、ネタ出し自体は「自分で考えたい」という意向が強いです。AIにネタを出させても「いいかも」と思うのは一部であり、最終的な判断は自身の感覚に頼っています。
- **事例**:
    - **ナフサ不足の解説** (メルマガ10): 5つのAIに質問し、回答を元に図解を作成。
    - **UAEのOPEC脱退** (メルマガ12): 5つのAIに質問し、Claudeの方向でChatGPTにまとめさせ図解に。
    - **AIにネタ出しをさせたポスト** (メルマガ13): 500名以上フォローされたポストをAIに分析させネタを出させたが、「いいかも」と思ったのは20個中1つだけで、フォロワーは**10名減**。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭のインパクトと読者の行動を促す構成が重要です。

### 2-1. 冒頭文（書き出し）のインパクト
ポストの書き出しは「命」であり、読み手の興味を引き付けることが最重要です。
- **原則**:
    - 「断言します」「これを知らないと大損します」「私コレで月10万円得しました」などの強い言葉で興味を引く (メルマガ2, 35)。
    - 「あおり気味の文言」も有効だが、アンチのリプが増える可能性もある（ただし、アンチは拡散のチャンスと捉える） (メルマガ36)。
    - 固有名詞や数字を冒頭に盛り込むことで、具体性と興味を引く力を高める (メルマガ38)。
        - **事例**: 「『55億円』『地面師』の文字」「Netflixというパワーワード」「2017年という具体的な数字」を冒頭に盛り込み、**368万インプレッション、1425名増**。

### 2-2. 「1枚目文字ポスト＋リプで図解」の型
最近のアルゴリズムでは「リプにいってもらう」ことが重視されています。そのため、1枚目を文字ポストにし、詳細な図解や解説をリプライツリーに誘導する型が効果的です。
- **原則**:
    - 1枚目の文字ポストは「題名」ぐらいの気持ちで、軽く読みやすく、文字数を少なめにする (メルマガ40, 41)。
    - 「メダルの構文」や「会話構文」など、流行りの構文を1枚目に使う (メルマガ3, 6, 38)。
    - **事例**:
        - **過去の伸びた図解ポストを1枚目文字ポストに再投稿** (メルマガ39): 以前フォロワー**10名減**だったポストが、1枚目を文字の会話にしたことで**204万インプレッション、170名増**に。
        - **社会保険の扶養解説** (メルマガ7): 「1枚目 会話の文字ポスト、2枚目～4枚目 図解ポスト」で**170万インプレッション、307名増**。
        - **個人向け国債の解説** (メルマガ6): 「流行りのメダルを使った構文」を1枚目に使い、図解をリプに誘導することで、普段伸びなかった内容が**334万インプレッション**に。

### 2-3. 図解ポストの活用
てっぺい氏が「13万フォロワーを達成した最大の秘密」と語るのが図解ポストです。文字だけのポストでは想像できないほどのインプレッション数が得られます。
- **原則**:
    - **Nano Banana Pro**や**Canva**などのツールを活用し、図解作成のハードルを下げる (メルマガ1, 5, 16, 30)。
    - 図解は「パッと見でなんのポストかわかるようにする」ことが重要（例: アルファードのイラストを大きくする） (メルマガ30)。
    - 「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」 (メルマガ4, 32)。
    - 細かすぎて見えない図解は、拡大して見てもらう行動を促し、エンゲージメントを高める (メルマガ44)。
        - **事例**: **高校受験の難関校ランキング** (メルマガ44): 「細かすぎて見えないので、図解を拡大してくれる」という狙いで、**1ポストで44,654名増**。

### 2-4. 会話構文・メダル構文などの流行りの型
Xのアルゴリズムは変化するため、その時々の流行りの構文（メダル構文、会話構文、◯×構文、国旗構文、Tier、ランキングなど）を取り入れることが有効です。
- **原則**:
    - 流行りの構文は「ややアルゴリズムをハックしてる感」があるが、有益な内容と組み合わせることで効果を発揮する (メルマガ6)。
    - 会話構文は「極力シンプルに、気になるところで切って、リプへ」誘導する (メルマガ7)。
    - **事例**:
        - **個人向け国債の解説** (メルマガ6): 「流行りのメダルを使った構文」で**334万インプレッション**。
        - **ワールドカップネタ** (メルマガ42): 「会話構文＋箇条書き＋図解」の組み合わせで**532万インプレッション、315名増**。

### 2-5. 1秒動画の活用
Xが動画を優遇する傾向にあるため、1秒の短い動画を添付することでポストが爆発的に伸びる可能性があります。
- **原則**:
    - 赤い矢印が点滅するようなシンプルな1秒動画でも効果がある (メルマガ36)。
    - **事例**: **マイナンバーカードの名称変更** (メルマガ36): 1秒動画を添付したことで「インプレッション数が大きく伸びる」要因となり、**595万インプレッション、407名増**。

### 2-6. マンガポストの活用
文字ポストで伸び悩んだ内容も、マンガ化することで大きく再生されることがあります。
- **原則**:
    - ChatGPTで文字ポストを読み込ませ、漫画のシナリオを作成する (メルマガ29)。
    - マンガ作成ツールを活用することで、誰でも簡単に作成可能 (メルマガ29)。
    - **事例**: **バレンタインの文字ポスト** (メルマガ29): 以前**7.4万インプレッション、34名減**だったものが、マンガ化することで**240万インプレッション、586名増**に。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

インプレッションとフォロワー増は必ずしも一致しません。それぞれの目的を意識した投稿戦略が必要です。

### 3-1. 高インプレッションにつながる投稿
- **トレンド性の高いネタ**: 時事ネタや世間の関心が高い話題は、広範囲にリーチしやすく、インプレッションを大きく伸ばします。
    - **事例**:
        - **マイナンバーカードの名称変更** (メルマガ36): **655万インプレッション**（1回目）。
        - **都道府県知事の年収ランキング** (メルマガ50): **550万インプレッション**。
        - **ワールドカップネタ** (メルマガ42): **1077万インプレッション**。
- **「下世話」な要素や意外性**: 人間の好奇心を刺激する内容は、多くの人の目に留まりやすいです。
    - **事例**:
        - **都道府県知事の年収ランキング** (メルマガ50): 「年収」という下世話な要素と「小池都知事が最下位」という意外性で**550万インプレッション**。
        - **女子アナフリー転向年収ランキング** (メルマガ18): 「下世話なネタを3つ盛り込んだランキング」で**92万インプレッション**。
- **流行りの構文や1秒動画**: アルゴリズムに優遇される見せ方は、インプレッションを加速させます。
    - **事例**:
        - **個人向け国債の解説** (メルマガ6): 「流行りのメダルを使った構文」で**334万インプレッション**。
        - **マイナンバーカードの名称変更** (メルマガ36): 「1秒動画」を添付し、**595万インプレッション**。
- **「リプに行ってもらう」構成**: 1枚目で興味を引き、リプに誘導する構成は、滞在時間を延ばし、アルゴリズムに評価されやすいです。
    - **事例**:
        - **海外メディアの立ち位置** (メルマガ26): 「いかにリプにいってもらうか」を意識し、**184万インプレッション**。

### 3-2. フォロワー増につながる投稿
- **「とっつきづらいけど知っておきたい」有益な情報**: 読者の課題解決や知識欲を満たす内容は、フォローにつながりやすいです。
    - **事例**:
        - **海外メディアのイラン攻撃報道** (メルマガ26): 「有益になるかも」という視点で**2951名増**。
        - **UAEのOPEC脱退解説** (メルマガ12): 「聞いたことある、大切そう、でも、よくわからない」を満たし、**2010名増**。
        - **選挙の「青木率」解説** (メルマガ1): 「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってることをやさしく解説」し、**1581名増**。
- **発信軸との一貫性**: 普段の発信軸と合致する有益な情報は、アカウントの専門性を高め、質の高いフォロワーを獲得します。
    - **事例**: てっぺい氏の基本軸である「お金とお得情報」や、それに近い「ニュース解説」はフォロワー増に繋がりやすい。
- **「まだ見たことない」一次情報や独自視点**: 他の人が発信していない独自の切り口や、一次情報に基づいた解説は、希少価値が高く、フォローを促します。
    - **事例**:
        - **全国のアウトレット** (メルマガ51): 「アウトレット、あまり見たことないように思います」というネタで**123万インプレッション、5099名増**。
        - **高校受験の難関校ランキング** (メルマガ44): 「良いネタで良い図解を作成できたらとんでもない数の方にフォローいただく」という確信のもと、**1ポストで44,654名増**。
- **図解ポスト**: 「図解を使った方がフォローいただく数は多くなる印象がある」とてっぺい氏も述べており、視覚的な分かりやすさがフォロー行動を促します (メルマガ8)。

### 3-3. インプレッションは伸びたがフォロワーは減った事例
インプレッションが伸びてもフォロワーが減るケースは、以下の要因が考えられます。
- **発信軸との大きなズレ**: 普段の投稿内容と大きく異なるテーマは、一時的に注目を集めても、アカウントの専門性と合致しないためフォローにつながらず、既存フォロワーの離脱を招くことがあります。
    - **事例**:
        - **女子アナフリー転向年収ランキング** (メルマガ18): 「下世話なネタ」で**92万インプレッション**と大きく伸びたが、「発信軸とのギャップ」によりフォロワーは**30名減**。
        - **お金・お得情報でもニュース解説でもない投稿** (メルマガ17): **113万インプレッション**を記録したが、フォロワーは**69名減**。「発信軸とのズレ」が要因と考察。
- **内容の質や期待値との乖離**: インパクトのある冒頭文で引き込んでも、内容が期待外れだったり、既存フォロワーにとって価値が低かったりすると、フォロー解除につながります。
- **Xのアルゴリズムや凍結の影響**: Xの凍結が増えている時期は、全体的にフォロワーが減りやすい傾向にあります。これは投稿内容とは直接関係ない外部要因です (メルマガ17, 18)。
- **アルゴリズムハック的な構文**: 流行りの構文はインプレッションを伸ばしやすい一方で、「ややアルゴリズムをハックしてる感」があり、フォロワー増にはつながりにくい場合があります (メルマガ6)。
    - **事例**: **個人向け国債の解説** (メルマガ6): メダル構文で**334万インプレッション**を達成したが、フォロワー増は**417名**と、インプレッションの割には少なめ。
- **再投稿時の反応低下**: 同じポストでもタイミングによって反応は変わります。再投稿を繰り返すうちに、インプレッションは伸びてもフォロワー増に繋がりにくくなることがあります。
    - **事例**: **ワールドカップネタ** (メルマガ43): 連続投稿する中で、インプレッションは伸びるが、フォロワーが**17名減**や**119名減**となるポストも発生。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗から学ぶことで、再現性のある投稿原則を確立できます。

### 4-1. 刺さった理由（成功原則）
- **「わかりやすさ」の徹底**: 「とっつきづらい」内容を「やさしく解説」することで、多くの人にリーチし、フォローを促します。図解はそのための強力なツールです。
    - **事例**: **選挙の「青木率」解説** (メルマガ1): 「とっつきづらいけど、『ちょっと知っておいた方がいいよな』と思ってることをやさしく解説」し、**1581名増**。
    - **為替介入** (メルマガ11): インプレッションは**7万**と伸びなかったが、フォロワーは**90名増**。「わかりやすい」と思われた結果と考察。
- **「知ってるものとつなげる」解説**: 専門的な内容でも、読者がすでに知っている身近な情報と関連付けて説明することで、理解度が高まります。
    - **事例**: **残クレアルファード解説** (メルマガ30): 「通常のローンとの比較が入ってると『支払い方法の話ね』とわかる」ように図解で説明し、**532名増**。
- **具体的な固有名詞や数字の活用**: 抽象的な表現ではなく、具体的な人名、地名、企業名、金額、日付などを盛り込むことで、リアリティと興味を引きます。
    - **事例**: **地面師事件** (メルマガ38): 「『55億円』『地面師』の文字」「Netflixというパワーワード」「2017年という具体的な数字」を盛り込み、**1425名増**。
- **結果の意外性**: 多くの人が「えっ」と思うような意外な結果や事実を提示することで、ポストへの反応（リプ、引用リポスト）が増え、拡散につながります。
    - **事例**: **都道府県知事の年収ランキング** (メルマガ50): 「東京の小池都知事が、給与をカットしていて47都道府県で最下位」という意外性が、リプや引用リポストを増加させ、**16,940名増**。
    - **全国のアウトレット** (メルマガ51): 「御殿場の売上だけやたら高い」「アウトレットがない都道府県がかなり多い」という意外な結果が、リプや引用リポストを増やす要因に。
- **「楽しむ」ことの重要性**: 自分が「そうなんだ」「へー」と思ったこと、楽しく発信できるテーマを選ぶことは、継続の秘訣であり、結果的に質の高いポストにつながります。
    - **事例**: **歴代の総理・大統領ランキング** (メルマガ22): 「個人的には、ドラマの視聴率よりもこういうテーマの方が作成していて楽しい」と述べ、**524名増**。
    - **為替介入** (メルマガ11): 「自分で学んだことを発信するというのは、発信が楽しくなっていいですね」という言葉から、楽しむことが継続のコツと再認識。

### 4-2. 刺さらなかった理由（反省点・失敗原則）
- **1枚目の図解に文字を入れすぎた**: 冒頭で情報量が多すぎると、読者は流し読みしづらく、リプへの誘導が弱まります。
    - **事例**: **為替介入** (メルマガ11): 「1枚目の図解に文字を多く入れすぎた」ことが伸び悩んだ原因と反省。
- **ターゲットにとって「関係なさそう」なテーマ**: 多くの人にとって自分事として捉えにくいテーマは、インプレッションが伸びにくいです。
    - **事例**: **為替介入** (メルマガ11): 「『為替介入』という言葉、自分とは関係なさそうに感じるのであまり伸びなかった」と考察。
- **インパクト不足**: 良いネタでも、見せ方や表現にインパクトがないと、多くの人に届きません。
    - **事例**: **ナフサ不足** (メルマガ10): 以前発信した際は「インパクトがないから」伸びなかったが、「ポテチの白黒袋」というインパクトを加えて再発信し成功。
- **用語が簡単すぎた/少なすぎた**: 専門家としての深みが足りない、または情報量が少ないと感じられると、エンゲージメントが低下します。
    - **事例**: **手書きメモ風の投資用語解説** (メルマガ34): 「用語が簡単すぎたこと」「用語が８つしかないのは少な過ぎたこと」を反省点として挙げ、次回はより難しい用語を18個入れる予定と改善策を提示。
- **発信軸とのズレ**: インプレッションは稼げても、アカウントの専門性と異なる内容だと、フォロワー増にはつながりにくく、既存フォロワーの離脱を招くことがあります。
    - **事例**: **女子アナフリー転向年収ランキング** (メルマガ18): インプレッションは伸びたが、「最近、中東情勢などのニュース解説が増えていたのでさすがにギャップがあったのかも」とフォロワー減の理由を考察。

## 5. 投稿前チェックリスト

てっぺい氏のメルマガから導き出された、投稿前に確認すべき具体的な項目です。

### 5-1. ネタ・テーマに関するチェック
- [ ] **トレンド性**: XのトレンドワードやYahoo!ニュースで話題になっているか？
- [ ] **関心度**: 多くの人が「聞いたことある」「興味がある」「知りたい」と感じるテーマか？
- [ ] **難易度**: 「とっつきづらいけど、知っておいた方がいい」内容を「やさしく解説」できるか？
- [ ] **意外性/下世話さ**: 読者が「えっ」と思うような意外な事実や、「年収」「ランキング」などの下世話な要素を盛り込めるか？
- [ ] **一次情報/独自性**: 自身の経験や学び、またはまだXで「見たことない」独自の切り口か？
- [ ] **自分も「へー」と思ったか**: 自分が楽しく発信できる、興味を持てる内容か？
- [ ] **過去の成功ネタ**: 以前伸びたネタを、見せ方を変えて再利用できないか？

### 5-2. 投稿の構成・型に関するチェック
- [ ] **冒頭文のインパクト**:
    - [ ] 「断言します」「これを知らないと大損します」などの強い言葉で興味を引いているか？
    - [ ] 固有名詞や数字を効果的に配置し、具体性を持たせているか？
    - [ ] Xの流し読み文化に対応できるよう、短く簡潔で、続きを読みたくなる内容か？
- [ ] **リプへの誘導**:
    - [ ] 1枚目のポストは情報量を抑え、リプライツリーで詳細を解説する構成か？
    - [ ] 読者が「リプに行きたくなる」ような工夫（続きが気になる、質問形式など）があるか？
- [ ] **図解の活用**:
    - [ ] 視覚的に「パッと見でなんのポストかわかる」デザインか？
    - [ ] Nano Banana ProやCanvaで効率的に作成されているか？
    - [ ] 細かすぎて拡大したくなるような要素を意図的に入れているか？
- [ ] **流行りの構文**:
    - [ ] 会話構文、メダル構文など、Xの最新トレンド構文を取り入れているか？
    - [ ] 会話構文の場合、極力シンプルに、気になるところで切ってリプへ誘導しているか？
- [ ] **1秒動画の添付**: Xのアルゴリズム優遇を狙い、1秒動画を添付しているか？
- [ ] **文字の読みやすさ**: 漢字の比率や改行を意識し、流し読みしやすい文章になっているか？

### 5-3. 数値実績・効果に関するチェック
- [ ] **インプレッション目的か、フォロワー増目的か**: 投稿の目的が明確か？（例: 下世話なネタはインプレッション向き、有益なニュース解説はフォロワー増向き）
- [ ] **発信軸との一貫性**: 普段の発信軸と大きくズレていないか？（フォロワー減のリスクを考慮）
- [ ] **他SNSへの展開**: 作成した図解や動画をInstagram, Threads, TikTok, YouTubeショートなど他のSNSにも流用できるか？

### 5-4. 投稿後のアクションに関するチェック
- [ ] **リプへの迅速な返信**: 投稿後30分〜60分は特に交流を意識し、リプにできるだけ早く返信できるか？（自身のインプレッション向上にも寄与）
- [ ] **効果測定と分析**: 投稿後、インプレッション、いいね、フォロワー増減を記録し、伸びた理由・伸びなかった理由を分析するか？
- [ ] **改善と再利用**: 分析結果に基づき、次の投稿に活かす、または見せ方を変えて再投稿する計画があるか？
