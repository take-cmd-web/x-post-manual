# X投稿マニュアル

X(旧Twitter)でフォロワー13万人を達成した「てっぺい」氏のメルマガを横断分析し、再現性のある投稿マニュアルを作成しました。てっぺい氏の成功と失敗の事例から、X運用における普遍的な原則と最新のアルゴリズムに合わせた戦略を抽出しています。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる最も重要な要素は「ネタ選び」であると繰り返し述べられています。以下の法則に基づき、ターゲット層に響くテーマを選定しましょう。

### 1-1. 主要な発信軸と需要のあるテーマ
てっぺい氏の主要な発信軸は「お金とお得情報」と「ニュース解説」です。これらを中心に、以下の特徴を持つテーマが伸びやすい傾向にあります。

*   **「なんとなく聞いたことあるけど、よくわからない」を優しく解説する**
    *   例1: 選挙の「青木率」解説ポストは、**234万インプレッション、1581名増**を記録。「とっつきづらいけど、ちょっと知っておいた方がいいよな」という情報に需要がある（メルマガ1）。
    *   例2: 「闇が深いエプスタイン事件」の解説は、**144万インプレッション、1652名増**（メルマガ4）および**63万インプレッション、1003名増**（メルマガ33）を達成。
    *   例3: 「残クレ」アルファードの解説は、**65万インプレッション、532名増**。「よく聞くけどよくわからない、ちょっと気になること」がテーマ（メルマガ30）。
*   **トレンドに乗った時事ネタ・ニュース解説**
    *   特に「海外のニュース」はフォロワーが増えやすい傾向にあります（メルマガ8）。
    *   例1: 「海外メディアのイラン攻撃報道」は、**1ポストで2951名増加**（メルマガ8）。
    *   例2: 「UAEのOPEC脱退」は、**1ポストで3067名増加**（メルマガ8）および**60万インプレッション、2010名増**（メルマガ12）。「みんなが知っていた方がいいニュース」という視点が重要（メルマガ12）。
    *   例3: 「ナフサ不足とポテトチップスの白黒袋」は、**182万インプレッション、603名増**。「インパクトの強さ」と「トレンド」が重なった良い例（メルマガ10）。
    *   例4: 「韓国大統領の逮捕歴」解説は、**78万インプレッション、447名増**。「みんなが『どうして？』と思ってることをトレンドに乗せて発信」した成功事例（メルマガ27）。
*   **「言われてみれば不思議」なことや、身近な疑問の解消**
    *   例: 「インドカレー屋さんの秘密」解説は、**317万インプレッション、492名増**。「自分でも不思議に思ってたのでなるほどと思った人が多かった」と考察（メルマガ41）。
*   **「自分ごと化」しやすい、対象者が広いテーマ**
    *   例1: 「高校受験の都道府県別名門校」のポストは、**1ポストで44,654名増加**という驚異的な実績。「高校受験をしている人、名門校を卒業している人」という広い対象者に刺さった（メルマガ44）。
    *   例2: 「都道府県別のショッピングセンター比較」は、**194万インプレッション、7,428名増**。「身近でみんなわかるもの、みんな好きなもの」が伸びる（メルマガ57）。
    *   例3: 「関東の家賃相場」のポストは、**81万インプレッション、1584名増**。ただし「全国を網羅してない」ため、全国版の方がより強い印象と反省点も挙げられている（メルマガ56）。
*   **「新しいネタ」「まだ見たことない」ネタ**
    *   誰かが発信して伸びているものをやるのも有効だが、てっぺい氏自身は「極力やらないようにしている」と述べています。自分で思いついた新しいネタが当たると「面白い」と感じるためです（メルマガ51）。
    *   例: 「全国のアウトレット」のポストは、**123万インプレッション、5099名増**。「アウトレット、あまり見たことない」という点が重要（メルマガ51）。

### 1-2. バズりやすい要素の追加
上記のテーマに加えて、以下の要素を盛り込むことで、さらにポストが伸びやすくなります。

*   **「下世話」な要素や意外性**
    *   例1: 「女子アナのフリー転向・年収ランキング」は、**92万インプレッション**を記録。「下世話なネタを3つ盛り込んだランキングなので伸びると思った」と分析（メルマガ18）。
    *   例2: 「都道府県知事の年収」のポストは、**550万インプレッション、16,940名増**。「あなたの県の知事の年収、知ってますか？」という切り口と、小池都知事が給与カットで最下位という「意外性」がヒットした（メルマガ50）。
    *   例3: 「新しい内閣の大臣の年収・資産額」解説は、**141万インプレッション、7805名増**。「有益っぽいポストに下世話な要素を入れている」成功例（メルマガ52）。
*   **固有名詞や具体的な数字**
    *   例: 「地面師たち」の元ネタ事件のポストは、冒頭文に「55億円」「地面師」「Netflix」「2017年」といった具体的な数字や固有名詞を盛り込み、**368万インプレッション、1425名増**を達成（メルマガ38）。
*   **インパクトの強さ**
    *   例: 「ポテトチップスの白黒袋」のニュースは、その「インパクトの強さ」から発信を決意（メルマガ10）。

### 1-3. ネタの探し方とリサーチ方法
*   **日常的な情報収集:**
    *   Xのトレンドワード、Yahoo!ニュース（トレンド系）（メルマガ49）。
    *   ポッドキャストの経済ニュース、Googleのレコメンドニュース（非トレンド系）（メルマガ49）。
    *   YouTube視聴中に思いつくことも（メルマガ38）。
    *   会話の中で思いついたネタはすぐにメモする（メルマガ51）。
*   **AIの活用:**
    *   AI（ChatGPT, Gemini, Perplexity, Grok, Claude）をリサーチに活用することで、リサーチ時間を大幅に短縮（メルマガ10, 12, 14, 20, 22, 38, 51, 55）。
    *   特にニュース解説のリサーチには「Gemini」が良いと感じている（メルマガ55）。
    *   AIに「ナフサってなに？」「今どういうものが不足してるのか」「最新の情報を教えて」「これからどういうものの不足が予想されるのか」といった具体的なプロンプトで質問（メルマガ10）。
    *   AIの回答で「意外な結果」や「みんなが『えっ』と思う結果」があると、ポストが伸びやすい（メルマガ51, 55）。
*   **過去ポストの再利用:**
    *   「同じポストは何度も使い回してOK」。反応が出たポストは1ヶ月置けば同じような反応が出る（メルマガ36）。
    *   例: 「マイナンバーカード」のポストは3回目の投稿で、初回は**655万インプレッション、1114名増**、2回目は**213万インプレッション、125名増**、3回目は**595万インプレッション、407名増**を記録（メルマガ36）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭のインパクトが重要です（メルマガ2, 35）。また、最近のアルゴリズムでは「リプに行ってもらう」ことが重視されています。

### 2-1. 冒頭文の作り方
*   **インパクト勝負:** 読み手の興味を引き付ける強い言葉を使う（メルマガ2, 35）。
    *   例: 「断言します」「これを知らないと大損します」「私コレで月10万円得しました」（メルマガ2, 35）。
    *   例: 「マイナンバーカード」がなくなることを知らない人が多すぎる（メルマガ36）。
*   **「題名」のような役割:** 最初のポストは、リプに誘導するための「題名」ぐらいの気持ちで、内容は少なめにする（メルマガ40）。
*   **固有名詞や数字:** 具体的なフックとなる固有名詞や数字を盛り込む（メルマガ38）。
    *   例: 「55億円」「地面師」「Netflix」「2017年」といった具体的な情報で興味を引く（メルマガ38）。
*   **読みやすさ:** とにかく読みやすく、気になるところで切る（メルマガ38）。

### 2-2. 投稿の構成パターン
てっぺい氏の投稿は、主に「図解ポスト」が中心ですが、アルゴリズムの変化に合わせて見せ方を工夫しています。

*   **1枚目を文字ポスト、2枚目以降を図解にする型（最新トレンド）**
    *   最近のアルゴリズムでは「1枚目に図解を置くと伸びづらくなっている印象」があるため、この型が有効（メルマガ3, 8, 39, 40, 41）。
    *   最初の文字ポストで興味を引きつけ、「リプに行ってもらう」ことを強く意識する（メルマガ3, 14, 26, 39, 40, 41）。
    *   例1: 「図解ポストの最初を文字ポストに」したことで、**59万インプレッション、283名増**を記録（メルマガ3）。
    *   例2: 「社会保険の扶養」に関するポストは、1枚目「会話の文字ポスト」、2枚目～4枚目「図解ポスト」の構成で、**170万インプレッション、307名増**を達成（メルマガ7）。
    *   例3: 過去に伸び悩んだ図解ポストも、1枚目を文字の会話ポストに変えて再投稿したところ、**204万インプレッション、170名増**と大きく伸びた（メルマガ39）。
*   **流行りの構文の活用**
    *   「メダル構文」「会話構文」「◯×構文」「国旗構文」「Tier」「ランキング」など、流行りの構文を積極的に試す（メルマガ3, 6, 38）。
    *   例1: 「個人向け国債 変動10年」のポストは、流行りの「メダル構文」を使うことで、これまで伸びなかった内容を**334万インプレッション、417名増**と多くの人に届けることに成功（メルマガ6）。
    *   例2: 「会話構文＋箇条書き＋図解」の組み合わせが現在伸びている型の一つ（メルマガ42）。
*   **図解ポストの工夫**
    *   **分かりやすさ最優先:** 「図解の方がわかりやすいことを図解でわかりやすく説明するポストは伸びる」（メルマガ4, 32）。
    *   **視覚的インパクト:** 「パッと見でなんのポストかわかるようにする」（メルマガ30）。例: アルファードのイラストを大きくする。
    *   **情報量の調整:** 最初の図解の情報量は少なめにして、リプに誘導する（メルマガ26）。
    *   **1枚目の重要性:** 複数枚の図解を使う場合、1枚目を特にこだわる（メルマガ38）。
    *   **「知ってるものとつなげる」:** 難しい内容も、身近なものと比較することで分かりやすくする（メルマガ30）。例: 残クレと通常のローンの比較。
    *   **AIとツール活用:** Nano Banana Pro/2とCanvaを駆使し、AI（ChatGPT, Gemini等）でリサーチ・シナリオ作成を行うことで、図解作成のスピードが劇的に向上（メルマガ10, 12, 14, 20, 22, 26, 30, 38, 51, 52）。
*   **マンガポストによる表現の多様化**
    *   「誰でも簡単にマンガが描けるツール」を活用し、文字ポストをマンガ化することで、過去に伸び悩んだネタを復活させる（メルマガ29）。
    *   例: バレンタインの実話ポストは、文字ポストでは**7.4万インプレッション、34名減**だったが、マンガ化で**240万インプレッション、586名増**に（メルマガ29）。
*   **1秒動画の活用**
    *   Xは動画を優遇する傾向があるため、赤い矢印が点滅するような「1秒動画」を添付することで、ポストが爆発的に伸びる（メルマガ36）。
    *   例: 「マイナンバーカード」のポストは、1秒動画を添付することで、**595万インプレッション、407名増**を記録（メルマガ36）。

### 2-3. 投稿後の交流
*   **リプへの迅速な返信:** ポスト発信後の30分、60分は特に交流が大切。できるだけ早く返信する（メルマガ7）。
*   **リプのインプレッション効果:** 伸びそうなポストに早くリプをしておくと、リプ自体のインプレッションも伸び、自分のアカウントパワーを上げるのに有効（メルマガ42）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

てっぺい氏は「インプレッション」と「フォロワー増」を別物として捉え、それぞれの傾向を分析しています。

### 3-1. インプレッションを伸ばす投稿
インプレッションはX収益に直結するため、てっぺい氏も重視しています（メルマガ3）。
*   **冒頭文のインパクト:** 読み手の興味を強く引き付ける書き出しは、インプレッションを数倍に伸ばす効果がある（メルマガ2, 35）。
*   **流行りの構文:** メダル構文、会話構文、1秒動画などの「流行りの型」を意識することで、アルゴリズムに優遇され、インプレッションが伸びやすい（メルマガ6, 36, 38, 42）。
    *   例: 個人向け国債のポストは「メダル構文」で**334万インプレッション**（メルマガ6）。
    *   例: マイナンバーカードのポストは「1秒動画」で**595万インプレッション**（メルマガ36）。
*   **「東スポ」要素の強いネタ:** 日経新聞に載るような真面目な内容よりも、下世話で興味を引くネタの方がインプレッションは伸びやすい（メルマガ18）。
    *   例: 女子アナのフリー転向・年収ランキングは**92万インプレッション**（メルマガ18）。
*   **トレンド性:** Xのトレンドワードに乗った投稿は、インプレッションを大きく伸ばす（メルマガ8, 10, 41）。
*   **リプへの誘導:** 最初のポストで内容を全て見せず、リプに誘導する構成は、ポストの滞在時間を延ばし、インプレッションに寄与する（メルマガ3, 14, 26, 39, 40, 41）。
*   **文字ポストの優位性:** 最近は図解よりも文字ポストの方がインプレッションが伸びやすい傾向がある（メルマガ8）。

### 3-2. フォロワー増につながる投稿
フォロワー増はアカウントの成長に不可欠です。
*   **発信軸に沿った有益な情報:** 普段の発信軸から大きく外れない、かつ「とっつきづらいけど知っておいた方がいい」ような有益な情報提供は、フォロワー増に繋がりやすい（メルマガ1）。
    *   例: 政治系の解説は、発信軸から少しズレてもフォロワーが増える傾向がある（メルマガ1）。「青木率」解説で**1581名増**（メルマガ1）。
    *   例: エプスタイン事件解説で**1652名増**（メルマガ4）。
*   **「難しいことをわかりやすく解説する」図解ポスト:** 図解はフォロー獲得に有効だと感じている（メルマガ8）。
*   **トレンドに乗ったニュース解説:** 特に海外のニュース解説はフォロワーが増えやすい（メルマガ8）。
    *   例: イラン攻撃報道で**2951名増**、UAEのOPEC脱退で**3067名増**（メルマガ8）。
*   **「自分ごと化」しやすいテーマ:** 多くの人が自分に関係あると感じるテーマは、フォローに繋がりやすい（メルマガ44, 57）。
    *   例: 高校受験の都道府県別名門校で**44,654名増**（メルマガ44）。
    *   例: ショッピングセンター比較で**7,428名増**（メルマガ57）。
*   **意外性のある結果:** リサーチ結果に「えっ」と思うような意外性があると、リプや引用リポストが増え、結果的にフォロワー増に繋がる（メルマガ51, 55）。
    *   例: 都道府県知事の年収ランキングで小池都知事が最下位という意外性で**16,940名増**（メルマガ50）。
*   **「有益＋下世話」の組み合わせ:** 有益な情報に下世話な要素（年収、資産額など）を加えることで、興味を引きつつフォローに繋げる（メルマガ52）。
    *   例: 大臣の年収・資産額解説で**7805名増**（メルマガ52）。
*   **マンガポスト:** 普段と違う表現方法で興味を引き、フォロワー増に繋がる（メルマガ29）。
    *   例: バレンタインの実話マンガで**586名増**（メルマガ29）。
*   **インプレッションは伸びなくても内容が「わかりやすい」場合:**
    *   例: 「為替介入」の解説ポストは**7万インプレッション**と伸び悩んだが、内容が「わかりやすい」と感じてもらえたため**90名増**を記録（メルマガ11）。

### 3-3. インプレッションとフォロワー増の乖離
両者は必ずしも連動せず、インプレッションが伸びてもフォロワーが減るケースがあります。
*   **発信軸とのズレ:**
    *   例1: 女子アナのフリー転向・年収ランキングは**92万インプレッション**を記録したが、普段のニュース解説やお得情報と「ギャップがあった」ため**30名減**（メルマガ18）。
    *   例2: 「お金・お得情報」でも「ニュース解説」でもないテーマのポストは**113万インプレッション**を記録したが、**69名減**（メルマガ17）。
*   **ネタ選びの精度:** AIにネタ出しをさせたポストは**24万インプレッション**だったが、**10名減**。ネタ選びのやり方を「もう少し考えなくては」と反省（メルマガ13）。
*   **アルゴリズムの変化への対応不足:** 過去に伸びた図解ポストをそのまま再投稿した際、アルゴリズムの変化で「図解を最初のポストにつけると伸びづらい」傾向にあったため、**15万インプレッション、10名減**となった（メルマガ39）。
*   **フォロワーの自然減:** 「基本的に、毎日フォロワー様は減る」ため、その日のポストでそれを上回るフォロー数を獲得しないと、フォロワー数は減少する（メルマガ13, 17, 18）。Xの凍結増加も影響している可能性（メルマガ17, 18）。
*   **インプレッションは収益に繋がる:** フォローに繋がらなくても、インプレッションが伸びていればX収益に繋がるため、一概に失敗とは言えない（メルマガ43）。
    *   例: ワールドカップネタのポストは、インプレッションは伸びるがフォロワーが増減するケースが混在。例えば「ワールドカップで4ゴール」は**17名減**、「日本代表の年俸」は**119名減**だったが、インプレッションは伸びているため継続（メルマガ43）。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

てっぺい氏の経験から、再現可能な成功原則と失敗から学ぶ反省点を抽出します。

### 4-1. 刺さった理由（成功原則）
1.  **ターゲットの「知りたい」を刺激するネタ選定**
    *   **「なんとなく知ってるけど、よくわからない」を解説:** 多くの人が漠然と興味を持っているが、調べるのが面倒なテーマは強い。
        *   例: エプスタイン事件、選挙の「青木率」、残クレアルファード（メルマガ1, 4, 30, 33）。
    *   **トレンド性・時事性:** 旬の話題やニュースは注目度が高い。特に海外ニュースはフォロワー増に繋がりやすい（メルマガ8, 10, 12, 26）。
    *   **意外性・下世話感:** 人の好奇心を刺激する「へー」という驚きや、年収・ランキングなどの「下世話」な要素は拡散力が高い（メルマガ18, 50, 51, 52）。
    *   **自分ごと化:** 多くの人が自分に関係あると感じるテーマは、共感や興味を引きやすい（メルマガ44, 57）。
    *   **一次情報・自身の学び:** 自分で調べて「そうなんだ」と思ったこと、自分の勉強になったことを発信すると、楽しさも伝わりやすい（メルマガ11, 23, 51）。
2.  **アルゴリズムに合わせた投稿の「見せ方」**
    *   **冒頭文のインパクト:** 流し読みされるXで足を止める「書き出しが命」。断言、大損、具体的な数字などで興味を引く（メルマガ2, 35, 36）。
    *   **リプへの誘導:** 最近のアルゴリズムは「リプに行ってもらう」ことを重視。最初のポストは文字で短く、続きはリプで図解を見せる構成が効果的（メルマガ3, 14, 26, 39, 40, 41）。
    *   **図解による分かりやすさ:** 複雑な内容も図解にすることで理解度が高まり、フォローに繋がりやすい（メルマガ4, 8, 16, 32）。
    *   **流行りの構文の活用:** メダル構文や会話構文など、その時々の流行を取り入れることで、インプレッションを最大化する（メルマガ6, 7, 38, 42）。
    *   **1秒動画の添付:** Xが動画を優遇する傾向にあるため、1秒動画はインプレッションを爆発的に伸ばすテクニックとして有効（メルマガ36）。
    *   **マンガポスト:** 文字だけでは伝えきれない内容や、過去のネタを新鮮に見せる手段として有効（メルマガ29）。
3.  **効率的な運用と継続性**
    *   **AIによるリサーチ・作成支援:** AI（ChatGPT, Gemini等）をリサーチや図解のシナリオ作成に活用することで、投稿作成の時間を大幅に短縮し、継続性を高める（メルマガ12, 14, 20, 51, 55）。
    *   **過去ポストの再利用:** 一度伸びたポストは、見せ方を変えるなどして何度も再投稿する（メルマガ36, 39）。
    *   **他SNSへの横展開:** Xで作成した図解を動画化し、Instagram, Threads, TikTok, YouTubeショートへ展開することで、少ない労力で多角的にフォロワーを増やす（メルマガ16, 19, 25, 28, 29）。
    *   **投稿後の交流:** 投稿直後のリプへの迅速な返信は、アルゴリズムに好影響を与え、インプレッションを伸ばす（メルマガ7, 42）。

### 4-2. 刺さらなかった理由（反省点から学ぶ原則）
1.  **ネタ選定のミスマッチ**
    *   **発信軸との大きなズレ:** インプレッションは伸びても、フォロワー増に繋がりにくい（メルマガ1, 17, 18）。
        *   例: 女子アナの年収ランキングはインプレッションは伸びたが、発信軸とギャップがありフォロワーは減少（メルマガ18）。
    *   **自分ごと化の弱さ:** 多くの人にとって遠い話題や、範囲が限定的すぎるテーマは伸び悩む（メルマガ11, 56）。
        *   例: 「為替介入」は内容が分かりやすくても「自分とは関係なさそう」と感じられ、インプレッションが伸び悩んだ（メルマガ11）。
        *   例: 「関東だけの家賃比較」は、全国版に比べて自分ごと化が弱く、伸びが限定的だった（メルマガ56）。
    *   **インパクト不足:** 良いネタでも、切り口や見せ方にインパクトがないと伸びない（メルマガ10）。
    *   **用語の難易度・量:** 簡単すぎる用語や少なすぎる情報量では、有益性が低く感じられる（メルマガ34）。
2.  **アルゴリズムの変化への対応遅れ**
    *   **1枚目に図解を置くことの不利:** 以前は有効だった1枚目図解が、最近は伸びづらい傾向にある。過去の成功パターンに固執すると伸び悩む（メルマガ3, 39）。
        *   例: 過去に伸びた図解ポストをそのまま再投稿した際、1枚目図解の構成が原因でフォロワーが減少した（メルマガ39）。
3.  **投稿の質の課題**
    *   **図解の情報過多:** 1枚目の図解に文字を入れすぎると、リプへの誘導が阻害され、ポストが伸び悩む（メルマガ11）。
    *   **図解の視覚的品質:** AIで作成した図解の品質が低い場合（例: 日本地図が歪む、顔が違うなど）は、手動で修正するなど品質を確保する努力が必要（メルマガ44, 50）。
4.  **外部環境の変化**
    *   **Xの凍結増加:** フォロワーの減少は、ポストの質だけでなく、X全体の凍結増加も影響している可能性がある（メルマガ17, 18）。
    *   **アフィリエイト規制:** 楽天アフィリエイトの規制強化など、プラットフォーム側のルール変更にも注意が必要（メルマガ17）。

## 5. 投稿前チェックリスト（具体的な確認項目）

以下のチェックリストを参考に、投稿の質を高め、バズる可能性を最大化しましょう。

### 5-1. ネタ・テーマの選定
*   [ ] **発信軸との整合性:** 「お金とお得情報」「ニュース解説」など、自分の主要な発信軸に合致しているか？（大きくズレる場合はインプレッションは伸びてもフォロワー増に繋がりにくいリスクを理解しているか？）
*   [ ] **ターゲットの興味関心:**
    *   [ ] 「なんとなく聞いたことあるけど、よくわからない」テーマか？
    *   [ ] トレンドに乗っているか？（Xトレンド、Yahoo!ニュースを確認）
    *   [ ] 多くの人が「自分ごと」として捉えられるか？（例: 高校受験、ショッピングセンター、家賃相場など）
    *   [ ] 意外性や「下世話感」のある要素が含まれているか？（例: 年収、事件の闇、ランキングなど）
    *   [ ] 固有名詞や具体的な数字が含まれているか？（例: 「55億円」「Netflix」「2017年」など）
    *   [ ] 自分自身が「へー」と思う、興味深い内容か？
    *   [ ] 「言われてみれば不思議」なことの解説か？
*   [ ] **既存ネタの確認:**
    *   [ ] 過去に同じネタで伸びたポストがあるか？（あれば見せ方を変えて再利用を検討）
    *   [ ] 他の人が既に発信していて伸びているネタではないか？（もしそうなら、差別化できるか、または元投稿者に確認したか？）

### 5-2. 投稿の構成・型
*   [ ] **冒頭文のインパクト:**
    *   [ ] 読み手の興味を引く強い書き出しになっているか？（例: 「断言します」「これを知らないと大損します」）
    *   [ ] 固有名詞や数字で具体的なフックがあるか？
    *   [ ] 文字数は少なめか？（リプへの誘導を意識し、長すぎないか）
*   [ ] **全体の構成（文字ポスト＋図解が推奨）:**
    *   [ ] 1枚目は文字ポスト（会話構文、メダル構文など）で、リプへ誘導する構成か？（図解を1枚目に置くと伸びづらい傾向を考慮）
    *   [ ] 有益な情報や面白い内容は2枚目以降の図解でしっかり伝えているか？
    *   [ ] 流行りの構文（メダル、会話、箇条書きなど）を取り入れているか？
*   [ ] **図解の品質と分かりやすさ:**
    *   [ ] 図解はパッと見で内容がわかるか？（イラストや画像で視覚的にアピール）
    *   [ ] 図解は「知ってるものとつなげる」説明で分かりやすいか？
    *   [ ] 図解の情報量は適切か？（1枚目に情報が多すぎないか）
    *   [ ] 図解のデザインは優れているか？（Nano Banana Pro/2やCanvaで作成）
    *   [ ] 図解に誤りや歪みがないか？（特に地図や顔など）
*   [ ] **動画の活用:**
    *   [ ] Xの動画優遇を意識し、1秒動画を添付しているか？
    *   [ ] 図解を動画化し、Instagram, TikTok, YouTubeショートなど他SNSへの横展開を検討しているか？

### 5-3. リサーチ・作成プロセス
*   [ ] **AI活用:**
    *   [ ] AI（ChatGPT, Gemini, Perplexity, Grok, Claude）で効率的にリサーチを行ったか？（特にニュース系はGeminiが有効）
    *   [ ] AIのリサーチ結果に「意外性」や「みんなが『えっ』と思う結果」が含まれているか？
    *   [ ] AIで図解のシナリオや構成案を作成したか？
*   [ ] **投稿時間:** 朝（5時55分～6時5分頃）の投稿を意識しているか？（メルマガ10）
*   [ ] **作成時間:** AI活用により、リサーチと図解作成の時間を短縮できているか？（例: 30分～1時間程度）

### 5-4. 投稿後のアクション
*   [ ] **交流の準備:** 投稿後30分～60分はリプへの返信を意識し、交流を深める準備はできているか？
*   [ ] **効果測定:** 投稿後、インプレッションとフォロワー増の両方の数値を記録し、次回の投稿に活かす計画があるか？
*   [ ] **再利用計画:** 伸びたポストは、見せ方を変えて再投稿する計画があるか？（1ヶ月程度の間隔）
