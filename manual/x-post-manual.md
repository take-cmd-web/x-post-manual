# X投稿マニュアル

X(旧Twitter)フォロワー13万人を誇る「てっぺい」氏のメルマガ分析に基づき、再現性のあるX投稿マニュアルを作成しました。てっぺい氏の成功事例と反省点から抽出された原則を、具体的な数値実績とともに解説します。

## 1. ネタ・テーマの選び方（伸びた事例から抽出した法則）

てっぺい氏の投稿が伸びる最も重要な要素は「ネタの選定」であると繰り返し述べられています。以下の法則を意識してネタを選びましょう。

### 1.1. ターゲットの「知りたい」を刺激するテーマ
*   **「とっつきづらいけど、ちょっと知っておいた方がいいよな」** という情報を優しく解説する。
    *   例: 政治系の「青木率」解説ポストは「234万インプレッション」「1581名増」（メルマガ1）。
    *   例: 「中東情勢の解説」は「1075名増」（メルマガ8, 23）。
*   **「なんとなく聞いたことあるけど、よくわからない」** テーマを選ぶ。
    *   例: 「闇が深いエプスタイン事件」は「144万インプレッション」「1652名増」（メルマガ4, 32, 33）。
    *   例: 「ナフサ不足」は「182万インプレッション」「603名増」（メルマガ10）。
    *   例: 「残クレアルファード」は「65万インプレッション」「532名増」（メルマガ30）。
    *   例: 「UAEのOPEC脱退」は「60万インプレッション」「2010名増」（メルマガ12）。
*   **「言われてみれば不思議」** と感じる内容を調べる。
    *   例: 「インドカレー屋さんの秘密」は「317万インプレッション」「492名増」（メルマガ41）。
*   **「うすうす思ってるけど、考えてみたらなんでなんだろう？」** という疑問を解決する。
    *   例: 「韓国大統領が逮捕される理由」は「78万インプレッション」「447名増」（メルマガ27）。

### 1.2. トレンド・時事ネタを積極的に取り入れる
*   **XのトレンドワードやYahoo!ニュース** からネタを探す。
    *   例: 「国会の冒頭解散」に合わせて「青木率」を解説（メルマガ1）。
    *   例: 「ナフサ不足」がトレンドワードにあったためポストを作成（メルマガ10）。
    *   例: 「OPEC」がトレンドになっていたため「UAEのOPEC脱退」を解説（メルマガ12）。
*   **特に海外のニュース** はフォロワー増加に繋がりやすい傾向がある。
    *   例: 「海外メディアのイラン攻撃報道」は「184万インプレッション」「2951名増」（メルマガ8, 26）。
    *   例: 「UAEのOPEC脱退」は「3067名増」（メルマガ8）。
*   **当たったネタは周辺ネタで「こすり続ける」**。
    *   例: ワールドカップネタが当たった際、6日連続で関連ネタを投稿。「優勝国が8カ国しかない」は「1077万インプレッション」「744名増」（メルマガ42）。

### 1.3. 意外性・共感性・インパクトを重視する
*   **本業のちょっとした知識** で、一般には知られていないが役に立つ情報を発信する。
    *   例: ホテル勤務経験から「ゴールデンウィーク明けはホテルが一番空く時期」というタイムリーな情報を提供し、「60万インプレッション」「206名増」（メルマガ9）。
*   **「自分も『へー』と思った」** ネタは伸びやすい。
    *   例: 為替介入の仕組みを自分自身が学んだことを発信し、「7万インプレッション」「90名増」（メルマガ11）。
*   **対象者が広く、興味を引くテーマ** を選ぶ。
    *   例: 「高校受験」や「名門高校」に関するポストは「44,654名増」という驚異的なフォロワー増加を記録（メルマガ44）。
*   **具体的な数字や固有名詞、パワーワード** を含める。
    *   例: 「地面師たち」の元ネタ事件で「55億円」「Netflix」「2017年」といった具体的な情報を盛り込み、「368万インプレッション」「1425名増」（メルマガ38）。
*   **「下世話なネタ」** はインプレッションを伸ばしやすい。
    *   例: 「女子アナのフリー転向と年収ランキング」は「92万インプレッション」を記録（メルマガ18）。ただし、発信軸とのズレが大きいとフォロワー減少に繋がる可能性もある。

### 1.4. ネタ探しの効率化
*   **AIはリサーチに活用し、ネタ出しは自分で判断する。**
    *   てっぺい氏は「Grok、ChatGPT、Gemini、Perplexity、Claude」などのAIを使い、複数の回答から良い部分をまとめて図解を作成している（メルマガ10, 12, 14, 20, 22, 26, 27, 38）。
    *   AIにネタ出しをさせたポストは「24万インプレッション」だったが「10名減」という結果に終わり、ネタ選びはまだ検証中（メルマガ13）。「ネタは自分で考えたい」という意向も示されている（メルマガ13, 49）。

## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

Xは「流し読みされる媒体」であるため、冒頭のインパクトが非常に重要です。また、アルゴリズムの変化に合わせて投稿の「見せ方」を柔軟に変えることが成功の鍵となります。

### 2.1. 冒頭文の作り方
*   **「書き出しが命」**。読み手の興味を引き付けるインパクトのある冒頭文にする。
    *   具体的な言葉の例: **「断言します」「これを知らないと大損します」「私コレで月10万円得しました」**（メルマガ2, 35）。
    *   煽り気味の文言も有効: **「マイナンバーカード」がなくなることを知らない人が多すぎる。** は「595万インプレッション」に貢献（メルマガ36）。
*   **文字数は少なく、簡潔に、しかし強く。**
    *   「題名」ぐらいの気持ちで最初のポストを作成し、リプへの誘導を意識する（メルマガ40, 41）。

### 2.2. 投稿の型：文字ポストと図解ポストの使い分け
*   **基本は「図解ポスト」** で、特にフォロワー増加を狙う。
    *   てっぺい氏の「13万フォロワー達成の最大の秘密はズバリ『図解ポスト』」と明言されている（メルマガ5, 37）。
    *   図解は「わかりやすいことをわかりやすく説明する」ために有効（メルマガ4, 32）。
    *   図解作成には「Nano Banana Pro/2」や「Canva」を活用し、効率化を図る（メルマガ1, 5, 10, 12, 14, 16, 21, 23, 26, 30, 32, 34, 38）。
*   **最近のアルゴリズムでは「1枚目を文字ポスト、2枚目以降を図解」が伸びやすい。**
    *   「1枚目に図解をおくと、伸びづらくなってる印象」があるため、この構成を推奨（メルマガ3）。
    *   文字ポストの方がインプレッションが伸びやすい傾向がある（メルマガ8）。
    *   例: 過去に伸び悩んだ図解ポストも、1枚目を文字の会話にした再投稿で「204万インプレッション」「170名増」と大きく伸びた（メルマガ39）。
    *   「リプに行ってもらう」ことがアルゴリズムで重視されているため、最初のポストはリプへの誘導を意識する（メルマガ3, 14, 26, 39, 40, 41）。
*   **図解の文字量は少なめにし、パッと見で内容がわかるようにする。**
    *   1枚目の図解に文字を多く入れすぎると伸び悩むことがある（メルマガ11）。
    *   「アルファードのイラストを大きくする」など、視覚的なインパクトを重視（メルマガ30）。
    *   「細かすぎて見えないので、図解を拡大してくれる」ような仕掛けも有効（メルマガ44）。

### 2.3. 会話ポスト・流行りの構文の活用
*   **会話構文** は、1枚目を会話の文字ポストにし、2枚目以降を図解にするパターンが有効。
    *   極力シンプルに、気になるところで切ってリプへ誘導する（メルマガ7, 38）。
    *   例: 妻のパート探しに関するリアルな会話ポストは「170万インプレッション」「307名増」（メルマガ7）。
    *   例: 「西松屋はいつもガラガラ」という会話調のポストは「148万インプレッション」「95名増」（メルマガ40）。
*   **メダル構文、◯×構文、ランキング** など、流行りの構文も積極的に試す。
    *   流行りの構文はインプレッションを伸ばしやすい傾向がある（メルマガ6）。
    *   ただし、流行りの構文はフォローに繋がりにくい傾向もあるため、「見る人が有益と感じる内容であればフォローはされる」という本質を忘れない（メルマガ6）。
    *   「一見、流行りにのってるようで、実は図解で有益なことを伝える」という「ロールキャベツ系ポスト」を推奨（メルマガ6）。
*   **マンガポスト** は、過去の文字ポストを復活させる力がある。
    *   例: 3年間伸び悩んでいたバレンタインの文字ポストをマンガ化したところ、「240万インプレッション」「586名増」と爆伸びした（メルマガ29）。ChatGPTでシナリオ作成が可能。

### 2.4. その他の表現方法
*   **1秒動画** を添付すると、X社が動画を優遇するため、ポストが爆発的に伸びる可能性がある。
    *   例: 「マイナンバーカード」のポストに赤い矢印が点滅する1秒動画を添付し、「595万インプレッション」を記録（メルマガ36）。
*   **懐かしい番組** を並べるなど、共感を呼ぶ要素を取り入れる。
    *   例: 「フジテレビの栄枯盛衰」のポストで懐かしい番組名を盛り込み、「140万インプレッション」「565名増」（メルマガ20）。
*   **知っているものとつなげて** 難しい内容をわかりやすく解説する。
    *   例: 「残クレアルファード」のポストで、通常のローンとの比較を入れることで理解を助ける（メルマガ30）。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

てっぺい氏の分析から、インプレッションとフォロワー増加は必ずしも連動しないことが示唆されています。それぞれの目標に応じた投稿戦略が必要です。

### 3.1. インプレッションを伸ばす投稿の傾向
*   **トレンド・時事ネタ:**
    *   「マイナンバーカード」の名称変更: **595万インプレッション**（メルマガ36）。
    *   ワールドカップネタ: **1077万インプレッション**（メルマガ42）。
    *   「個人向け国債 変動10年」をメダル構文で: **334万インプレッション**（メルマガ6）。
    *   「地面師たち」の元ネタ事件: **368万インプレッション**（メルマガ38）。
*   **興味を引く見せ方・構文:**
    *   流行りの構文（メダル構文、会話構文）はインプレッションを伸ばしやすい（メルマガ6, 40）。
    *   1枚目を文字ポスト、2枚目以降を図解にする構成は、リプへの誘導が促され、インプレッションが伸びやすい（メルマガ3, 14, 39, 40, 41）。
    *   1秒動画の添付は、Xの動画優遇アルゴリズムにより爆発的に伸びる可能性がある（メルマガ36）。
*   **下世話なネタ・意外性のあるネタ:**
    *   「女子アナのフリー転向と年収ランキング」: **92万インプレッション**（メルマガ18）。
    *   「生類憐れみの令」（有益と見せかけてネタ）: **75万インプレッション**（メルマガ19）。
    *   マンガポスト: 過去の文字ポストをマンガ化した「バレンタインネタ」は「240万インプレッション」（メルマガ29）。

### 3.2. フォロワー増加につながる投稿の傾向
*   **「トレンド」「ニュース解説」「すべて図解ポスト」の組み合わせ** がフォロワー増加に最も効果的。
    *   てっぺい氏が「今年1000名様以上の方にフォローいただいたポスト5本」の共通点として挙げている（メルマガ8）。
        *   「海外メディアのイラン攻撃報道」: **2951名増**（メルマガ8, 26）。
        *   「UAEがOPECを脱退」: **3067名増**（メルマガ8）。
        *   「エプスタイン事件」: **1652名増**（メルマガ4, 32, 33）。
        *   「高市首相の解散総選挙」: **1581名増**（メルマガ1）。
        *   「中東情勢の解説」: **1075名増**（メルマガ8, 23）。
*   **「聞いたことある」「大切そう」「でも、よくわからない」を優しく解説する** 内容。
    *   例: 「UAEのOPEC脱退」は「2010名増」（メルマガ12）。
*   **「わかりやすい」と評価される** 内容。
    *   例: 「為替介入」のポストはインプレッションは伸びなかったが、「90名増」とフォローに繋がった（メルマガ11）。
*   **「細かすぎて見えないので、図解を拡大してくれる」ような工夫** がある投稿。
    *   例: 「高校受験の都道府県別名門高校」のポストは「44,654名増」という過去最高のフォロワー増加を記録（メルマガ44）。
*   **発信軸から多少ズレていても、政治系の解説はフォロワーが増える傾向** がある（メルマガ1）。

### 3.3. インプレッションは伸びたがフォロワーは減った示唆的な事例
インプレッションが伸びてもフォロワーが減少する、または微増に留まる事例は、発信軸とのズレや内容の質、アルゴリズムへの対応が不十分である可能性を示唆しています。
*   **AIにネタ出しさせたポスト:** 「24万インプレッション」に対し「10名減」（メルマガ13）。
    *   **分析:** ネタの質やターゲットとのミスマッチが原因の可能性。AIによるネタ出しはまだ検証段階。
*   **発信軸から大きく外れたポスト:**
    *   「お金・お得情報」や「ニュース解説」ではないポスト: 「113万インプレッション」に対し「69名減」（メルマガ17）。
    *   「女子アナのフリー転向と年収ランキング」（下世話なネタ）: 「92万インプレッション」に対し「30名減」（メルマガ18）。
    *   **分析:** インプレッションは伸びるが、既存フォロワーの興味関心と合致しないため、フォローに繋がらず、むしろ離脱を招く。アカウントの「軸」を意識した投稿が重要。インプレッションはアカウントの「育成」には役立つという見方もある（メルマガ18）。
*   **アルゴリズムの変化に対応できていないポスト:**
    *   図解を最初のポストにした再投稿: 「15万インプレッション」に対し「10名減」（メルマガ39）。
    *   **分析:** 「最近は、図解を最初のポストにつけると伸びづらくなってる」というアルゴリズムの変化に対応せず、文字ポストでリプ誘導をしないとフォロワー減少に繋がる。
*   **ワールドカップネタの一部:** インプレッションは伸びるものの、フォロワー増減は様々。
    *   「ワールドカップで4ゴール」: 「17名減」（メルマガ43）。
    *   「日本代表の年俸」: 「119名減」（メルマガ43）。
    *   **分析:** 一過性のトレンドネタはインプレッションを稼ぎやすいが、アカウントの専門性や長期的な価値に繋がりにくい場合、フォローに結びつかない可能性がある。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

成功と失敗の事例から、再現可能な原則を抽出します。

### 4.1. 刺さった理由（成功原則）
1.  **「とっつきづらいけど、知っておくべき」を優しく解説:**
    *   例: 政治や経済の専門用語を分かりやすい図解や言葉で解説することで、多くの「知りたい」層にリーチし、フォロワー増加に繋がる（メルマガ1, 23）。
2.  **トレンド・時事ネタに素早く乗る:**
    *   Xのトレンドワードやニュースを毎日チェックし、タイムリーな情報を提供する（メルマガ8, 10, 49）。特に海外ニュースはフォロワー増に貢献（メルマガ8）。
3.  **「なんとなく知ってるけど、よくわからない」を深掘り:**
    *   多くの人が抱く漠然とした疑問や興味を具体的に解説することで、共感と理解を深める（メルマガ4, 12, 30）。
4.  **冒頭文で強烈なフックを作る:**
    *   **「断言します」「これを知らないと大損します」** などの言葉や、煽り気味の問いかけで読み手の興味を一瞬で引きつける（メルマガ2, 35, 36）。
5.  **「1枚目文字ポスト＋2枚目以降図解」の構成:**
    *   現在のXアルゴリズムで「リプに行ってもらう」ことが重視されるため、導入を軽くし、本質的な情報をリプ（図解）で提供する形が効果的（メルマガ3, 7, 14, 39, 40, 41）。
6.  **図解で視覚的に分かりやすく:**
    *   複雑な内容も図解にすることで、直感的に理解しやすくなる（メルマガ4, 16, 30）。「Nano Banana Pro/2」や「Canva」を活用し、高品質な図解を効率的に作成する。
7.  **マンガポストでストーリー性を付加:**
    *   文字だけでは伝わりにくい体験談やストーリーをマンガにすることで、感情に訴えかけ、高いエンゲージメントと拡散を生む（メルマガ29）。
8.  **具体的な数字・固有名詞・パワーワードの活用:**
    *   「55億円」「地面師」「Netflix」「2017年」など、具体的な情報でポストの信頼性と興味を向上させる（メルマガ38）。
9.  **「自分も『へー』と思った」一次情報の発信:**
    *   自分が調べて「そうなんだ」と思ったことを発信することで、楽しんで継続でき、その熱量が読者にも伝わる（メルマガ1, 11, 22）。
10. **当たったネタは「こすり続ける」:**
    *   一度反応が良かったネタは、見せ方を変えたり、周辺情報を深掘りしたりして、繰り返し発信する（メルマガ36, 42）。

### 4.2. 刺さらなかった理由（失敗・反省点）
1.  **発信軸との大きなズレ:**
    *   インプレッションは伸びても、アカウントの専門性や既存フォロワーの期待と異なる内容だと、フォローに繋がらず、むしろフォロワー減少を招く（メルマガ13, 17, 18）。
2.  **1枚目の図解に文字を入れすぎ:**
    *   「スマホを離さずに」「最後の退避勧告」のように、冒頭で情報を詰め込みすぎると、読み手が離脱しやすくなる（メルマガ11）。リプへの誘導を意識し、1枚目は簡潔に。
3.  **テーマが「自分とは関係なさそう」と感じられる:**
    *   専門的すぎる、または日常とかけ離れたテーマは、インプレッションが伸びにくい（メルマガ11: 為替介入）。
4.  **インパクト不足:**
    *   内容が良くても、視覚的なインパクトや導入のフックが弱いと、流し読みされてしまう（メルマガ10: ナフサ不足の初期投稿）。
5.  **図解の質が低い:**
    *   特に重要な図解（例: 日本地図）の質が低いと、本来伸びるはずのネタでも効果が半減する（メルマガ44）。手間をかけてでも高品質な図解を作成する価値がある。
6.  **用語が簡単すぎ、または少なすぎた:**
    *   ターゲット層の知識レベルに合わない、または情報量が少なすぎると、有益性が感じられず、フォローに繋がりにくい（メルマガ34）。
7.  **アルゴリズムの変化への対応遅れ:**
    *   「図解が伸びづらい」「リプ誘導が重要」といったXのアルゴリズム変化に気づかず、従来の投稿スタイルを続けると伸び悩む（メルマガ3, 39）。

## 5. 投稿前チェックリスト

以下の項目を投稿前に確認し、投稿の質を高めましょう。

### 5.1. ネタ・テーマに関するチェック
*   [ ] **ターゲットの「知りたい」を刺激するか？**
    *   「とっつきづらいけど、知っておいた方がいい」情報か？
    *   「なんとなく聞いたことあるけど、よくわからない」テーマか？
    *   「言われてみれば不思議」と感じる内容か？
    *   「うすうす思ってるけど、考えてみたらなんでなんだろう？」という疑問を解決するか？
*   [ ] **トレンド・時事ネタに乗っているか？**
    *   XのトレンドワードやYahoo!ニュースで話題になっているか？
    *   特に海外のニュースか？
    *   当たったネタの周辺テーマを「こすり続けて」いるか？
*   [ ] **意外性・共感性・インパクトがあるか？**
    *   自分の専門性や経験からくる「へー」という意外な発見があるか？
    *   対象者が広く、共感を呼ぶテーマか？
    *   具体的な数字や固有名詞、パワーワードが含まれているか？
    *   「下世話なネタ」でインプレッションを狙う場合は、発信軸とのズレを許容できるか？
*   [ ] **「自分も『へー』と思った」内容か？**
    *   自分が調べていて楽しかった、学びがあった内容か？

### 5.2. 冒頭文に関するチェック
*   [ ] **読み手の興味を引きつけるインパクトのある書き出しになっているか？**
    *   **「断言します」「これを知らないと大損します」「私コレで月10万円得しました」** などの強い言葉を使っているか？
    *   **「〜を知らない人が多すぎる」** など、煽り気味の文言でフックを作っているか？
*   [ ] **Xは「流し読みされる媒体」であることを意識した、短く強い言葉か？**
*   [ ] **1枚目を文字ポストにする場合、リプへの誘導を意識した内容か？**
    *   会話構文の場合、極力シンプルに、気になるところで切ってリプへ誘導しているか？

### 5.3. 投稿形式（文字/図解/動画）に関するチェック
*   [ ] **1枚目は文字ポスト（会話構文、メダル構文など）で、リプに誘導する構成か？**
    *   2枚目以降は図解で、内容をわかりやすく解説しているか？
*   [ ] **図解の文字量は適切か？** （多すぎると冒頭で離脱される可能性）
*   [ ] **図解はパッと見で何のポストか分かるデザインか？** （イラストや画像を活用）
*   [ ] **1秒動画を添付して、Xの動画優遇アルゴリズムを活用しているか？**
*   [ ] **マンガポストなど、視覚的に魅力的な表現を試しているか？**
*   [ ] **難しい内容を「知っているものとつなげて」解説しているか？**
*   [ ] **「細かすぎて見えないので、図解を拡大してくれる」ような仕掛けがあるか？**
*   [ ] **AI（Nano Banana Pro/2, ChatGPT, Geminiなど）を活用し、効率的に高品質な図解を作成しているか？**

### 5.4. その他（投稿後の運用含む）に関するチェック
*   [ ] **発信軸から大きくズレていないか？** （インプレッションは伸びてもフォロワーは減る可能性を理解しているか？）
*   [ ] **投稿後30分～60分はリプへの返信など、交流を意識しているか？** （メルマガ7）
*   [ ] **同じネタを使い回す場合、見せ方を変えるなど工夫しているか？**
*   [ ] **他のSNS（Instagram, Threads, TikTok, YouTubeショート）への流用を検討しているか？** （特に図解は動画化して流用しやすい）
*   [ ] **投稿作成を楽しめているか？** （長く続けるコツ）
