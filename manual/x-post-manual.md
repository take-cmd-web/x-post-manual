## 2. 投稿の構成・型（冒頭文/文字ポストvs図解/会話ポスト等のパターン）

てっぺい氏の投稿は、Xのアルゴリズムやユーザーの行動特性を深く理解した上で、様々な構成・型を試しています。

*   **冒頭文のインパクト勝負**
    *   **原則**: Xは「流し読みされる媒体」であるため、冒頭の数行で読み手の興味を強く引き付け、スクロールを止めさせることが最も重要です（メルマガ2, 35）。
    *   **具体例**:
        *   「断言します」「これを知らないと大損します」「私コレで月10万円得しました」といった、読み手に直接語りかけ、強いメリットや危機感を提示する言葉（メルマガ2, 35）。
        *   「マイナンバーカードがなくなることを知らない人が多すぎる。」という、あおり気味の文言で関心を引く（メルマガ36）。
    *   **効果**: 冒頭文を変えるだけで、インプレッション数やいいね数が数倍になるケースも多い（メルマガ2, 35）。
    *   **原則**: アンチのリプも「チャンス」と捉え、拡散のきっかけと考える（メルマガ36）。

*   **「1枚目文字ポスト + 2枚目以降図解」の型**
    *   **原則**: 最近のXアルゴリズムは「リプに行ってもらう」ことを重視しており、1枚目に図解を置くと伸びづらい傾向があります。そのため、最初のポストは文字で興味を引き、詳細や図解はリプに誘導する構成が効果的です（メルマガ3, 7, 8, 14, 15, 39）。
    *   **具体的なパターン**:
        *   **会話構文**: 1枚目を会話形式の文字ポストにし、極力シンプルに、気になるところで切ってリプへ誘導します（メルマガ7, 38, 39）。
            *   **実例**: 社会保険の扶養に関するポスト（メルマガ7）は、1枚目会話の文字ポスト、2～4枚目図解で、**170万インプレッション、307名増**。地面師事件のポスト（メルマガ38）も会話調の文字ポストで、**368万インプレッション、1425名増**。
        *   **メダル構文/流行りの構文**: 1枚目に流行りの構文（メダル構文など）を使い、2枚目以降で有益な図解を伝える「ロールキャベツ系ポスト」が有効です（メルマガ6, 38）。インプレッションを伸ばしつつ、有益な内容でフォローを狙います。
            *   **実例**: 個人向け国債のポスト（メルマガ6）は、1枚目メダル構文、2枚目以降図解で、**334万インプレッション、417名増**。
        *   **シンプルな文字誘導**: 「日本が10人の村だったら」のポスト（メルマガ14）のように、最初のポストは文字のみで、リプで図解を見せる構成も効果的で、**50万インプレッション、264名増**。

*   **図解ポストの活用**
    *   **原則**: 図解ポストは文字だけのポストでは想像できないほどのインプレッション数を獲得し、フォロワー増加の最大の秘密とされています（メルマガ5, 37）。Nano Banana ProなどのAIツールを活用することで、図解作成の難易度が劇的に下がります（メルマガ1, 5, 12, 16, 21, 23, 26, 30, 32, 33, 34）。
    *   **工夫**:
        *   **パッと見の分かりやすさ**: 図解はパッと見で何のポストか分かるように、主要なイラストやキーワードを大きく配置する（メルマガ30）。
        *   **情報量の調整**: 最初のポストの図解は情報量を少なめにして、リプへの誘導を促す（メルマガ26）。
        *   **見せ方の工夫**: 「手書きメモ風」図解で既視感のあるネタを新鮮に見せるなど、飽きさせない工夫も重要（メルマガ34）。

*   **漫画ポストの活用**
    *   **原則**: 過去に文字ポストでは伸びなかった内容も、漫画化することで爆発的に伸びる可能性があります（メルマガ29）。
    *   **実例**: 娘の実話バレンタインポストは、文字ポストでは**7.4万インプレッション、34名減**だったものが、漫画化で**240万インプレッション、586名増**に「よみがえり」ました（メルマガ29）。
    *   **作成方法**: ChatGPTで文字ポストを漫画のシナリオに変換し、専用ツールで簡単に作成できます（メルマガ29）。

*   **1秒動画の添付**
    *   **原則**: Xは動画を優遇する傾向があるため、ポストに1秒動画を添付することで、インプレッションを爆発的に伸ばすことができます（メルマガ36）。
    *   **実例**: マイナンバーカードのポスト（メルマガ36）で、赤い矢印が点滅する1秒動画を添付した結果、**595万インプレッション、407名増**という驚異的な成果を記録しました。

## 3. 数値実績の傾向（どんな投稿がインプレッションを伸ばし、どんな投稿がフォロワー増につながるか。両者は別物として分析）

てっぺい氏のメルマガ分析から、インプレッションとフォロワー増は必ずしも連動せず、それぞれ異なる要因で伸びる傾向が見られます。

### インプレッションを伸ばす投稿の傾向

インプレッションは、ポストの「表示回数」であり、Xのアルゴリズムに評価され、より多くのユーザーのタイムラインに表示されることで伸びます。

*   **インパクトの強い冒頭文や煽り文句**: 読み手の興味を瞬時に引きつけ、スクロールを止めさせる力が強いポスト。
    *   **実例**:
        *   「マイナンバーカードがなくなることを知らない人が多すぎる。」という書き出しと1秒動画を組み合わせたポスト（メルマガ36）：**595万インプレッション、407名増**。
*   **流行りの構文や見せ方の工夫**: Xのアルゴリズムが優遇する形式や、視覚的に目新しい工夫が施されたポスト。
    *   **実例**:
        *   個人向け国債の「メダル構文」ポスト（メルマガ6）：**334万インプレッション、417名増**。
        *   地面師事件の「会話構文」ポスト（メルマガ38）：**368万インプレッション、1425名増**。
        *   バレンタインの「漫画ポスト」（メルマガ29）：**240万インプレッション、586名増**。
        *   「手書きメモ風」図解の投資用語解説（メルマガ34）：**25万インプレッション**。
*   **「東スポ」要素の強いネタ**: 大衆の好奇心を刺激する、ややゴシップ的・下世話な話題。
    *   **実例**:
        *   女子アナ・フリー転向・年収ランキング（メルマガ18）：**92万インプレッション**を記録したが、フォロワーは**30名減**。
*   **リプ誘導を意識した構成**: 最初のポストで興味を引き、詳細をリプに置くことで、ポストへの滞在時間やエンゲージメントを高める。
    *   **実例**:
        *   社会保険の扶養に関する「1枚目会話の文字ポスト + 2枚目以降図解」のポスト（メルマガ7）：**170万インプレッション、307名増**。
        *   海外メディアの立ち位置解説で、情報を絞りリプに誘導したポスト（メルマガ26）：**184万インプレッション、2951名増**。

### フォロワー増につながる投稿の傾向

フォロワー増は、ポストの内容が読者にとって「有益である」「もっと知りたい」と感じさせ、アカウントをフォローする行動に繋がることで発生します。

*   **「とっつきづらいが知っておいた方がいい」有益なニュース解説**: 難解な政治・経済・社会情勢などを分かりやすく解説するポストは、知識欲を満たし、信頼性を高めるため、フォローに繋がりやすい。
    *   **実例**:
        *   UAEがOPECを脱退の解説（メルマガ8, 12）：**3067名増加**（メルマガ8）、**2010名増加**（メルマガ12）。
        *   海外メディアのイラン攻撃報道の解説（メルマガ8, 26）：**2951名増加**（メルマガ8, 26）。
        *   エプスタイン事件の解説（メルマガ4, 32）：**1652名増加**（メルマガ4, 32）。
        *   高市首相の解散総選挙の解説（メルマガ1）：**1581名増加**。
        *   中東情勢の解説（メルマガ8, 23）：**1075名増加**（メルマガ8, 23）。
*   **トレンドに乗った時事ネタ**: 話題性のあるニュースは、一時的な関心だけでなく、継続的な情報収集のニーズに繋がり、フォローを促します。
    *   **実例**:
        *   上記「有益なニュース解説」の多くがトレンドに乗った時事ネタと重なります（メルマガ8, 10）。
*   **発信軸との一貫性**: アカウントの専門性やテーマと合致した内容のポストは、質の高いフォロワー獲得に繋がりやすい。
    *   **実例**: 「お金とお得情報」が軸のてっぺい氏が、政治系の解説をしてもフォロワーが増える傾向がある（メルマガ1）。これは「とっつきづらいが知っておいた方がいい」というニーズが、てっぺい氏の「分かりやすく解説する」という軸と合致したためと考えられます。
*   **図解ポスト**: 情報を視覚的に分かりやすく伝える図解は、内容の理解を深め、有益性を感じさせるため、フォロー行動に繋がりやすい（メルマガ5, 8, 37）。

### インプレッションは伸びたがフォロワーは減った事例

インプレッションとフォロワー増は別物であり、インプレッションが伸びてもフォロワーが減少するケースがあります。

*   **発信軸との大きなズレ**: アカウントの主要なテーマから大きく外れたポストは、一時的に注目を集めても、期待する情報と異なるためフォロー解除に繋がります。
    *   **実例**:
        *   不明なテーマのポスト（メルマガ17）：**113万インプレッション**を記録したが、フォロワーは**69名減**。これは「お金・お得情報」でも「ニュース解説」でもなかったことが要因と分析されています。
        *   女子アナ・フリー転向・年収ランキング（メルマガ18）：**92万インプレッション**と大きく伸びたものの、フォロワーは**30名減**。これは「発信軸とのギャップ」が原因と考察されています。
*   **AIによるネタ出しの検証段階**: AIにネタ出しをさせたポスト（メルマガ13）：**24万インプレッション**とまずまずだったが、フォロワーは**10名減**。ネタ選びにAIを活用する際は、まだ検証と工夫が必要であることが示唆されます。
*   **アルゴリズムの変化への対応不足**: 過去に伸びた図解ポストをそのまま再投稿した際、1枚目に図解を置く形式が現在のアルゴリズムと合わず、インプレッションは15万、フォロワーは**10名減**となったケース（メルマガ39）。

**示唆**: インプレッションはアカウントの露出を増やす上で重要ですが、フォロワーを増やすには、アカウントの専門性や読者が求める有益な情報を提供し続けることが不可欠です。インプレッションとフォロワー増のバランスを意識し、目的に応じた投稿戦略を立てる必要があります。

## 4. 刺さった理由・刺さらなかった理由（成功と失敗(反省点ありの回)の両面から、再現可能な原則として）

てっぺい氏のメルマガには、成功事例だけでなく、反省点や伸び悩んだ事例も含まれており、これらから再現性のある原則を抽出できます。

### 刺さった理由（成功の原則）

1.  **「知りたいけど難しい」を優しく解説する**
    *   **原則**: 多くの人が興味を持つが、自分で調べるにはハードルが高いと感じるテーマを、専門用語を使わず、具体的な例えを用いて分かりやすく解説することで、高いエンゲージメントとフォロワー獲得に繋がります。
    *   **実例**:
        *   選挙の「青木率」解説（メルマガ1）：とっつきづらい政治ネタを優しく解説し、**234万インプレッション、1581名増**。
        *   エプスタイン事件解説（メルマガ4, 33）：闇が深く、日本のメディアで取り扱いが少ない事件を解説し、**144万インプレッション、1652名増**。
        *   UAEのOPEC脱退（メルマガ12）：聞いたことはあるがよくわからないニュースを優しく解説し、**60万インプレッション、2010名増**。

2.  **トレンド・時事性を捉えたタイムリーな情報発信**
    *   **原則**: 話題になっているニュースやイベントに合わせたタイムリーな情報発信は、読者の関心が高く、インプレッションとフォロワー増の両方に貢献します。
    *   **実例**:
        *   国会冒頭解散に合わせた選挙の青木率（メルマガ1）。
        *   エプスタイン事件の新たなファイル公開（メルマガ4, 33）。
        *   「ナフサ不足」がトレンドワードになった際に、ポテトチップスの白黒化と結びつけて解説（メルマガ10）：**182万インプレッション、603名増**。

### 刺さらなかった理由・反省点（失敗からの学び）

1.  **発信軸との大きなズレ**
    *   **原則**: アカウントの主要なテーマや専門性から大きく外れたポストは、一時的にインプレッションが伸びても、フォロワーの期待と異なるため、フォロー解除やフォロワー減少に繋がります。
    *   **実例**:
        *   「お金・お得情報」や「ニュース解説」ではない不明なテーマのポスト（メルマガ17）：**113万インプレッション**に対し、フォロワーは**69名減**。
        *   女子アナ・フリー転向・年収ランキング（メルマガ18）：「下世話なネタ」で**92万インプレッション**を記録したが、フォロワーは**30名減**。これは発信軸とのギャップが原因と分析されています。

2.  **1枚目の情報過多**
    *   **原則**: 最初の図解や画像に文字を多く入れすぎると、読み手が流し読みしづらくなり、ポストの詳細を見る前に離脱してしまう可能性があります。リプ誘導の妨げにもなります。
    *   **実例**:
        *   「為替介入」のポスト（メルマガ11）：1枚目の図解に文字を多く入れすぎたことが反省点として挙げられ、**7万インプレッション**と伸び悩んだ。

3.  **テーマの親近感不足・専門用語の多用**
    *   **原則**: 読者にとって「自分とは関係なさそう」と感じられるテーマや、専門用語が多すぎる内容は、関心を引きにくく、インプレッションが伸び悩む傾向があります。
    *   **実例**:
        *   「為替介入」という言葉が、一般の読者には遠く感じられたため、インプレッションが伸びなかった（メルマガ11）。

4.  **情報の深さ・量不足**
    *   **原則**: 有益性を謳うポストでも、提供される情報が簡単すぎたり、量が少なすぎたりすると、読者は物足りなさを感じ、フォローに繋がりません。
    *   **実例**:
        *   投資用語解説のポスト（メルマガ34）：「用語が簡単すぎた」「用語が8つしかないのは少な過ぎた」ことが反省点として挙げられています。

5.  **同じ見せ方の繰り返しによる飽き**
    *   **原則**: Xは「飽きを嫌う傾向がある」ため、常に同じようなポストや構文ばかりを使っていると、読者の関心が薄れ、アルゴリズムの評価も下がる可能性があります。
    *   **実例**:
        *   バレンタインの実話ポスト（メルマガ29）：以前は文字ポストで反応が良かったが、昨年は**7.4万インプレッション、34名減**と伸び悩んだ。これを漫画化することで「よみがえった」。

6.  **AIによるネタ出しの精度（初期段階）**
    *   **原則**: AIはネタ出しの強力なツールですが、初期段階では必ずしも最適なネタを生成するとは限りません。AIの提案を鵜呑みにせず、自身の判断で選別し、検証を重ねる必要があります。
    *   **実例**:
        *   AIに過去の伸びたポストを読み込ませてネタ出しをさせたが、20個の候補から「いいかも」と思ったのは1つだけだった（メルマガ13）。このポストは**24万インプレッション**だったが、フォロワーは**10名減**となった。
